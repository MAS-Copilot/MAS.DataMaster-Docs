画布选择

操作 说明
左键单击控件 选中该控件；若控件属于组合，则整组一起被选中
Shift + 左键单击 加选 / 减选（已选中的再点一次即取消）
Ctrl + 左键单击 在多选或组合中指定焦点控件
空白处从左往右拖拽 框选（完全包含）：只有整体落在框内的控件才会被选中
空白处从右往左拖拽 框选（相交）：只要与选框有重叠就会被选中
Shift + 框选 在现有选区基础上追加
空白处单击 清空选区（按住 Shift 单击则保留原选区）
Esc 第一次取消焦点控件，第二次清空选区

框选沿用 CAD 的经典规则：从左往右要求完全包含，从右往左只要相交。密集区域里精细挑选时，从左往右拖可以避免蹭到旁边的控件；想快速捞一片时，从右往左拖即可

组合（Group）在设计器里是一个整体：选中任一成员即选中整组，移动、对齐、分布都按整组计算；框选也按整组判定——完全包含模式下要整组都在框内才会命中，组内单个成员被框住不算

焦点控件

多选或组合中，按住 Ctrl 单击其中某一个控件，即可把它设为焦点控件，选区本身保持不变。焦点控件带橙色高亮边框，作用有：

  1. 单独查看属性：右侧属性面板从"多选批量编辑"切换为只显示这一个控件的属性，方便查看组合内某个成员的设置
  2. 作为对齐参考：对齐、统一宽 / 高时以焦点控件（所在单元）为基准。未指定焦点时，基准是最先选中的那个
操作 说明
Ctrl + 左键单击选区内控件 设为焦点控件
Ctrl + 左键单击未选中的组合成员 先整体选中该组合，再定位到该成员
Esc 取消焦点，属性面板回到整体选区视图

拖动过程中按住 Ctrl 仍然是"临时免吸附"，两者不冲突：焦点只在按下鼠标那一刻确定

移动与吸附

操作 说明
左键拖动控件 移动；多选 / 组合按整体移动
拖动中按住 Ctrl 临时关闭吸附，自由移动
↑ ↓ ← → 按网格步长移动（默认 10 px）
Ctrl + 方向键 精调，每次 1 px
拖动八个控制点 调整大小（仅单选且未锁定时显示控制点）

吸附行为：

  • 默认开启，参考对象为页面边界 / 页面中心与其他控件的边和中心
  • 采用迟滞手感：距离小于 5 px 吸住，拉开超过 9 px 才脱开
  • 网格吸附默认关闭，网格大小 10 px
  • 已锁定的控件不能移动、不能调整大小，选中时显示锁定角标

选中控件超过 10 个时，拖动与方向键微调改用"虚拟框"预览，松开鼠标（或停止按键片刻）后一次性写回真实位置，避免大批量控件卡顿

编辑与剪贴板

快捷键 说明
Ctrl + C 复制选中控件
Ctrl + X 剪切选中控件
Ctrl + V 粘贴（带偏移，粘贴后自动选中新控件）
Ctrl + Z 撤销
Ctrl + Y 重做
Delete 删除选中控件（锁定的控件不会被删除）

缩放与平移

操作 说明
鼠标滚轮 以光标位置为中心缩放
按住鼠标中键拖动 平移画布
顶部缩放条 / + - 按钮 / 比例下拉框 设置缩放比例
顶部"恢复视图"按钮 缩放复位并居中

绘图（图元）

在页面空白处右键 → 绘图，选择要画的图元；画完自动切回选择模式

图元 画法
矩形、圆角矩形、椭圆、圆弧 按住左键拖出包围框
直线、箭头 按住左键从起点拖到终点
折线、多边形 左键逐点单击，双击 或 Enter 或 右键结束
贝塞尔曲线 左键依次落 4 个点，落满自动结束
取消绘制 Esc

图元选中后拖动顶点即可改形状
