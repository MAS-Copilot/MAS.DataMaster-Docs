形态学

腐蚀、膨胀、开闭运算等，清理二值图

端口

方向 名称 类型 说明
输入 图像 图像 待处理的图像，通常为二值图
输出 图像 图像 处理后的图像，尺寸不变

参数

参数 默认值 说明
操作 开运算（去小点） 腐蚀收缩白色区域，膨胀扩张白色区域。**开运算（去小点）**去除小亮点，**闭运算（填孔）**填补小孔洞。梯度提取轮廓。顶帽提取比背景亮的小目标，黑帽提取比背景暗的小目标
结构元素 矩形 矩形、椭圆 或 十字
核大小 3 结构元素边长（px），范围 1 ~ 51，取奇数，偶数按加 1 处理
迭代次数 1 重复执行的次数，范围 1 ~ 10

参数访问

参数名 含义 类型 范围 / 可选值 访问
Operation 操作 枚举 Erode、Dilate、Open、Close、Gradient、TopHat、BlackHat Get/Set
Shape 结构元素 枚举 Rectangle、Ellipse、Cross Get/Set
KernelSize 核大小 int 1～51 px，仅奇数 Get/Set
Iterations 迭代次数 int 1～10 Get/Set

连续运行时可在两轮之间修改，执行中返回失败需重试。调用方式与限制

典型搭配

场景 链路
定位孔位 滤波去噪 → 阈值二值化 → 形态学（开运算）→ Blob 分析
