滤波去噪

平滑图像、降低噪声，常放在二值化或检测之前

端口

方向 名称 类型 说明
输入 图像 图像 待处理的图像，灰度或彩色
输出 图像 图像 平滑后的图像，尺寸与通道不变

参数

参数 默认值 说明
滤波方式 高斯 高斯通用去噪，边缘略有模糊。**中值（椒盐噪声）**去椒盐噪声并保边。**双边（保边）**保边平滑，较慢。均值为邻域平均
核大小 5 滤波窗口边长（px），范围 1 ~ 31，取奇数，偶数按加 1 处理。1 为不滤波。越大越平滑，细节损失越多
西格玛 0 仅高斯、双边显示，范围 0 ~ 50。高斯为模糊程度；双边同时用作颜色与空间 σ。0 为按核大小自动计算

典型搭配

场景 链路
定位边缘 滤波去噪 → 直线定位
定位孔位 滤波去噪 → 阈值二值化 → 形态学 → Blob 分析
