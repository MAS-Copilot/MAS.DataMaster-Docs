阈值二值化

转成黑白二值图，支持固定、自动与自适应阈值

端口

方向 名称 类型 说明
输入 图像 图像 待处理的图像，彩色图先转灰度
输出 图像 图像 单通道二值图，像素为 0 或 255

参数

参数 默认值 说明
方式 大津法（自动） 固定阈值用设定的阈值。**大津法（自动）**适合双峰直方图。**三角法（自动）**适合单峰直方图。自适应（均值）、**自适应（高斯）**按邻域计算每个像素的阈值，适合光照不均
阈值 128 仅固定阈值显示，范围 0 ~ 255。灰度高于阈值的像素变白
邻域大小 31 仅自适应显示，范围 3 ~ 201（px），取奇数。应大于目标尺寸
常数 C 5 仅自适应显示，范围 -50 ~ 50。从邻域均值中减去该值作为阈值，越大保留的像素越少
反相 关 让暗目标变成白色
Tip

光照不均时改用自适应

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
UsedThreshold 实际使用的阈值。自动方式为算法选出的值，自适应方式为 -1
Note

自动方式每帧重新选阈值，可从 UsedThreshold 观察是否稳定

典型搭配

场景 链路
定位孔位 滤波去噪 → 阈值二值化（大津法，反相）→ 形态学（开运算）→ Blob 分析
