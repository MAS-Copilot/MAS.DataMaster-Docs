ROI 选择器

按感兴趣区域裁剪图像，可跟随定位结果移动（ROI 随动）

端口

方向 名称 类型 说明
输入 图像 图像 待裁剪的图像
输入 跟随定位 定位 可选。接工件 Mark、边等定位结果后 ROI 随工件移动
输出 图像 图像 裁剪后的图像
输出 坐标变换（输出→原图） 坐标变换 接坐标映射，把裁剪图上的结果换回原图坐标
Warning

接了跟随定位但未设跟随基准时 ROI 固定不动，节点显示警告。已设基准而上游本次没有定位结果时管道失败，不会裁到错误的位置

Note

矩形直接裁剪；旋转矩形摆正后输出 宽 × 高；圆、椭圆、圆环、多边形裁剪到外接矩形，形状外的像素置黑。不跟随时，除旋转矩形外，区域超出图像的部分被裁掉，输出随之变小

使用

  1. 上游接好相机或图像源，运行一次，让设置窗口拿到一帧图像
  2. 打开设置窗口，在顶部选择形状：矩形、旋转矩形、圆、椭圆、圆环、多边形。换形状时新形状尽量保持原区域的位置与大小
  3. 在图上拖动画出区域，拖动内部移动、拖动控制点缩放或旋转；多边形逐点单击，双击、回车或点回首个顶点完成。也可在右侧输入精确参数，点 整幅图像 让区域占满整幅图
  4. 需要随动时，把定位结果接到跟随定位，卡片上出现ROI 随动区
  5. 工件放在示教位置运行一次，点 设为跟随基准（需工程师权限）。之后 ROI 随工件平移、旋转，输出与示教时取景一致
Note

跟随时设置窗口显示的是映射回示教姿态的画面，在上面框选的就是示教姿态下的区域

参数

区域

参数 默认值 说明
ROI X / ROI Y 100 / 100 矩形的左上角（px）
宽 / 高 200 / 200 矩形、旋转矩形的宽高；椭圆为两轴全长（px）
中心 X / 中心 Y 200 / 200 旋转矩形、圆、椭圆、圆环的中心（px）
旋转角度 0° 旋转矩形、椭圆的角度，顺时针为正，范围 -360° ~ 360°
半径 100 圆的半径；圆环的外半径（px）
内半径 50 圆环的内半径，须小于外半径（px）
多边形顶点 — 每行一个点 x,y，也可用 ; 分隔，至少 3 个顶点

ROI 随动

参数 默认值 说明
跟随旋转 开 关闭则只跟随平移，用于定位结果没有可靠角度的情况，如圆定位、Blob 分析

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
OffsetX / OffsetY 输出图原点在输入图中的坐标（像素）。无旋转时输出图坐标加上它即为输入图坐标
Angle 输出图相对输入图的旋转（度），旋转矩形或跟随旋转时不为 0
IsFollowing 本次是否跟随定位
FollowDX / FollowDY 跟随时基准点的平移（像素）
FollowDAngle 跟随时的旋转（度）
Shape ROI 形状
Roi ROI 参数（示教姿态下）
Warning

有旋转时不能只加 OffsetX / OffsetY 换算，要用坐标变换输出接坐标映射

典型搭配

场景 链路
缩小检测范围 图像源 → ROI 选择器 → 滤波去噪 → 直线定位
ROI 随动 形状匹配 → ROI 选择器（跟随定位）→ 精测 → 坐标映射
