缩放

按比例或到指定尺寸缩放；先缩小再粗定位可提速，结果用变换输出换回原图

端口

方向 名称 类型 说明
输入 图像 图像 待缩放的图像
输出 图像 图像 缩放后的图像
输出 坐标变换（输出→原图） 坐标变换 接坐标映射，把缩放图上的结果换回原图坐标，按像素中心对齐

参数

参数 默认值 说明
方式 按比例 按比例，或到指定尺寸
比例 0.5 仅按比例显示。输出 / 输入尺寸，范围 0.01 ~ 20
宽 / 高 640 / 0 仅到指定尺寸显示。目标尺寸，范围 0 ~ 20000（px），0 表示按另一边等比
插值 区域平均 缩小用区域平均（抗锯齿），放大用双线性或双三次
Warning

到指定尺寸时宽、高不能都为 0

Note

到指定尺寸时两边都填，按填写值输出，宽高比可能改变，X、Y 比例不同

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Width / Height 输出尺寸（像素）
ScaleX / ScaleY X、Y 方向实际比例（输出 / 输入）
Transform 输出图 → 输入图的变换

典型搭配

场景 链路
先缩小再精测 缩放 → 形状匹配 → 坐标映射（接变换输出）→ 原图精测
