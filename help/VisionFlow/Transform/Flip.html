翻转

水平或垂直镜像（相机装反、经反射镜取像时摆正画面）

端口

方向 名称 类型 说明
输入 图像 图像 待翻转的图像
输出 图像 图像 翻转后的图像，尺寸不变
输出 坐标变换（输出→原图） 坐标变换 接坐标映射，把翻转图上的结果换回原图坐标

参数

参数 默认值 说明
翻转方式 水平 水平为左右镜像，垂直为上下镜像，水平 + 垂直等于旋转 180°

参数访问

参数名 含义 类型 范围 / 可选值 访问
Mode 翻转方式 枚举 Horizontal、Vertical、Both Get/Set

连续运行时可在两轮之间修改，执行中返回失败需重试。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Mode 翻转方式：Horizontal、Vertical 或 Both
Transform 输出图 → 输入图的变换（镜像）
