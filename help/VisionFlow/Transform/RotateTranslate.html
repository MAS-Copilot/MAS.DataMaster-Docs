旋转平移

按固定角度、比例、平移量重采样图像，输出图像与“输出 → 原图”变换

端口

方向 名称 类型 说明
输入 图像 图像 待变换的图像
输出 图像 图像 变换后的图像
输出 坐标变换（输出→原图） 坐标变换 接坐标映射，把输出图上的结果换回原图坐标

参数

参数 默认值 说明
旋转角度 0° +X 转向 +Y 为正（画面上顺时针），与定位角度同向，范围 -360° ~ 360°
比例 1 输出 / 输入尺寸，1 为不缩放，范围 0.01 ~ 20
旋转中心 绕图像中心 旋转与缩放的中心。切到 指定中心 后填写 中心 X / 中心 Y（输入图像素坐标）
水平偏移 / 垂直偏移 0 / 0 旋转后再平移的量（px）。开启保留整幅图时无效
保留整幅图 禁用 输出放大到装下转完的整幅输入，四角不被裁掉。此时输出紧贴内容，平移不起作用
插值 双线性 一般用双线性；二值图、标签图用最近邻；放大时用双三次或 Lanczos
边界填充 填黑 落在输入图外的像素：填黑，或复制边缘像素（不给卡尺、差分造假边）
Note

未开启保留整幅图时输出与输入同尺寸，转出画面的部分被裁掉

Tip

角度、比例是固定值。要按定位结果把工件转正，用定位转正

参数访问

参数名 含义 类型 范围 / 可选值 访问
Angle 旋转角度 double -360～360 °（有限数值） Get/Set
Scale 比例 double 0.01～20（有限数值） Get/Set
IsImageCenter 绕图像中心 bool true / false Get/Set
CenterX 中心 X double 有限数值，无额外上下限 px Get/Set
CenterY 中心 Y double 有限数值，无额外上下限 px Get/Set
TranslateX 水平偏移 double 有限数值，无额外上下限 px Get/Set
TranslateY 垂直偏移 double 有限数值，无额外上下限 px Get/Set
IsWholeImageKept 保留整幅图 bool true / false Get/Set
Interpolation 插值 枚举 Nearest、Linear、Cubic、Area、Lanczos Get/Set
Border 边界填充 枚举 Black、Replicate Get/Set

连续运行时可在两轮之间修改，执行中返回失败需重试。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Angle 旋转角（度）
Scale 缩放比例
Width / Height 输出尺寸（像素）
OffsetX / OffsetY 输出图原点在输入图中的坐标（像素）
Transform 输出图 → 输入图的变换

典型搭配

场景 链路
固定角度摆正画面 相机 → 旋转平移 → 形状匹配 → 坐标映射（接变换输出）
