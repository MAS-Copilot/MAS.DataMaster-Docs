畸变校正

用相机内参资源把整幅图拉直；预计算映射表，适合连续运行

Warning

上游已有畸变校正时，2D 标定不要再选畸变校正内参，避免重复校正

Tip

只需校正 Mark 坐标时，改用 2D 标定里的畸变校正内参更快

端口

方向 名称 类型 说明
输入 图像 图像 待校正的图像
输出 图像 图像 校正后的图像
Note

没有坐标变换输出，校正图上的结果不能经坐标映射换回原图坐标

参数

参数 默认值 说明
资源键 — 「相机标定」生成的相机内参资源，展开下拉框列出当前可用的资源
保留范围 0 范围 0 ~ 1。0 只保留有效像素（无黑边），1 保留原图全部像素（四周留黑边）
方式 重映射 重映射预计算映射表，连续运行快；直接校正每帧重算，偶尔用一次时省内存

参数访问

参数名 含义 类型 范围 / 可选值 访问
IntrinsicsKey 资源键 string 相机内参资源键，候选来自当前工程资源 Get/Set
Alpha 保留范围 double 0～1（有限数值） Get/Set
Mode 方式 枚举 Remap、Direct Get/Set

连续运行时可在两轮之间修改，执行中返回失败需重试。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
ResourceKey 使用的相机内参资源键
NewFx / NewFy 校正后图像的焦距（像素）
NewCx / NewCy 校正后图像的主点（像素）
ValidX / ValidY 有效像素范围左上角
ValidWidth / ValidHeight 有效像素范围的宽、高
Note

校正后的像素坐标对应新相机矩阵（NewFx、NewCx 等），不再是标定内参。下游姿态解算会自动改用新内参
