定位转正

按定位结果把目标转到固定姿态，可只裁出目标周围的局部图，是“定位 → 转正 → 精测”的中间一步

端口

方向 名称 类型 说明
输入 图像 图像 待转正的图像
输入 定位 定位 目标的定位结果，角度直接使用
输出 图像 图像 转正后的整幅图或局部图
输出 坐标变换（输出→原图） 坐标变换 接坐标映射，把输出图上的测量结果换回原图坐标
Warning

定位没有结果（上游未找到目标）时管道失败

Note

定位结果的角度直接使用。圆定位的角度为 0，接入后只跟随平移

参数

参数 默认值 说明
输出范围 整幅图 整幅图与输入同尺寸，绕定位点旋转。裁剪只输出定位点周围 宽 × 高 的局部图
目标角度 0° 转正后目标的方向，0 为水平，范围 -180° ~ 180°
固定位置 禁用 仅整幅图显示。再把定位点平移到 目标 X / 目标 Y，每次输出里目标都在同一处
目标 X / 目标 Y 0 / 0 定位点在输出图中的位置（px）
宽 / 高 200 / 200 仅裁剪显示。裁剪窗口的大小，范围 1 ~ 20000（px）
沿向偏移 / 横向偏移 0 / 0 仅裁剪显示。窗口中心相对定位点的偏移，在目标坐标系里量：沿目标方向、垂直目标方向（px）
插值 双线性 一般用双线性；二值图、标签图用最近邻；放大时用双三次或 Lanczos
边界填充 填黑 落在输入图外的像素：填黑，或复制边缘像素（不给卡尺、差分造假边）
Tip

后面接卡尺或金样比对时，边界填充选复制边缘，避免填黑的边界被当成边缘或缺陷

参数访问

参数名 含义 类型 范围 / 可选值 访问
OutputMode 输出范围 枚举 FullImage、Crop Get/Set
TargetAngle 目标角度 double -180～180 °（有限数值） Get/Set
IsPositionFixed 固定位置 bool true / false Get/Set
TargetX 目标 X double 有限数值，无额外上下限 px Get/Set
TargetY 目标 Y double 有限数值，无额外上下限 px Get/Set
Width 宽 int 1～20000 px Get/Set
Height 高 int 1～20000 px Get/Set
OffsetX 沿向偏移 double 有限数值，无额外上下限 px Get/Set
OffsetY 横向偏移 double 有限数值，无额外上下限 px Get/Set

连续运行时可在两轮之间修改，执行中返回失败需重试。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
DAngle 本次旋转量（度）
TargetX / TargetY 定位点在输出图中的坐标（像素）
Width / Height 输出尺寸（像素）
Transform 输出图 → 输入图的变换

典型搭配

场景 链路
定位后精测 形状匹配 → 定位转正（裁剪）→ 卡尺 → 坐标映射
缺陷检测 形状匹配 → 定位转正（裁剪）→ 金样比对
金样差分前对齐 形状匹配 → 定位转正（整幅图，固定位置）→ 金样比对
