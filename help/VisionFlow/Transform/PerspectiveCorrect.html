透视矫正

把斜拍的四边形区域拉成正矩形（4 点单应变换），角点在图上点选或接定位的 Mark

端口

方向 名称 类型 说明
输入 图像 图像 斜拍的图像
输入 角点定位 定位列表 可选。接入后每次取列表前 4 个点作为角点，如四个 Mark
输出 图像 图像 拉正后的图像
Warning

接了角点定位后只用它：结果少于 4 个，或上游本次没有结果时节点执行失败，不会退回图上点选的角点

Note

透视不是刚体变换，没有坐标变换输出，不能接坐标映射换回原图坐标；需要时用结果里的 Homography

使用

  1. 上游接好相机或图像源，运行一次，让设置窗口拿到一帧图像
  2. 打开设置窗口，在图上依次点 4 个角点，双击、回车或点回首个顶点完成；拖动顶点可调整
  3. 叠加标记显示本次实际使用的角点顺序，粗边为上边（左上 → 右上）
  4. 角点会随工件移动时，改为把 4 个 Mark 的定位列表接到角点定位，不再使用图上点选的角点

参数

参数 默认值 说明
源四边形 — 输入图上的 4 个角点，在设置窗口的图上点选
自动排序角点 开 按几何把四点排成左上、右上、右下、左下。四边形接近 45° 倾斜时关掉，按此顺序自己点
输出宽 / 输出高 0 / 0 范围 0 ~ 20000（px）。0 表示按四边形边长自动估计，约等于不缩放
插值 双线性 一般用双线性；二值图、标签图用最近邻；放大时用双三次或 Lanczos
边界填充 填黑 落在输入图外的像素：填黑，或复制边缘像素（不给卡尺、差分造假边）
Important

关闭自动排序时，角点（含角点定位列表的前 4 个）必须按左上、右上、右下、左下的顺序给出

参数访问

参数名 含义 类型 范围 / 可选值 访问
SourceQuad.PointsText 源四边形 string 四个角点 x,y; x,y; x,y; x,y Get/Set
Width 输出宽 int 0～20000 px Get/Set
Height 输出高 int 0～20000 px Get/Set
IsAutoOrdered 自动排序角点 bool true / false Get/Set

连续运行时可在两轮之间修改，执行中返回失败需重试。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Width / Height 输出尺寸（像素）
Corners 本次使用的四个角点，左上、右上、右下、左下，输入图像素坐标
Homography 单应矩阵（输入 → 输出），3×3 按行展开

典型搭配

场景 链路
斜拍拉正 相机 → 透视矫正 → 后续流程
Mark 自动取角 Blob 分析（4 个 Mark）→ 透视矫正（角点定位）→ 后续流程
