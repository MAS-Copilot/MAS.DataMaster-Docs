机器位姿

通过通讯实例从设备读取当前位姿

端口

方向 名称 类型 说明
输出 位姿 位姿 本次读到的 X、Y、Z、Yaw、Pitch、Roll

参数

每次执行读取一次，目前仅支持 Modbus TCP。填了 IP 地址时直接连接，不依赖数据采集；未填时按通讯设备名取数据采集登记的连接

参数 默认值 说明
IP 地址 — 设备 IP，与端口一起在卡片上填写
端口 502 设备端口，范围 1 ~ 32767
通讯设备 — 数据采集中的设备名，未填 IP 时使用，数据采集项目需在运行中
读取起始地址 0 位姿数据的首个寄存器地址，范围 0 ~ 65523。顺序为 X、Y、Z、Yaw、Pitch、Roll，每个分量为 32 位浮点数，占 2 个寄存器，共 12 个连续寄存器
从站地址 0 Modbus 从站地址，范围 0 ~ 247
Note

节点没有字节序设置：同一地址已有组态或数据采集的连接时，沿用该连接的数据格式

Note

填了 IP 时与组态、数据采集共用同一地址的连接，不会另开一条

参数访问

参数名 含义 类型 范围 / 可选值 访问
PoseConfig.Ip IP 地址 string Modbus TCP 地址；空时使用通讯设备名称 Get/Set（需停管道）
PoseConfig.Port 端口 ushort 0～65535 Get/Set（需停管道）
PoseConfig.CommunicationInstance 通讯设备 string 数据采集中的通讯设备名称 Get/Set（需停管道）
PoseConfig.StartAddress 读取起始地址 ushort 0～65535 Get/Set
PoseConfig.UnitId 从站地址 byte 0～255 Get/Set

普通参数可在两轮之间修改；标为「需停管道」的参数先停止管道。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Pose 机器位姿
X / Y / Z 位置（mm）
Yaw / Pitch / Roll 姿态角（度）

典型搭配

场景 链路
眼在手上引导 相机 → 姿态解算 → 手眼坐标转换（本节点接其机器位姿输入）
相机随动龙门 定位 → 像素转机械坐标（本节点接其机器位姿输入）
