实例分割

分割图像中的全部目标，输出各目标的掩码，并基于掩码测量质心、面积及最小外接矩形

端口

方向 名称 类型 说明
输入 图像 图像 待分割的图像
输出 图像 图像 输入原图直通，供下游算法使用
输出 定位 定位 置信度最高的目标；没有目标时无输出
输出 定位列表 定位列表 全部目标，按置信度从高到低。每项为掩码质心，带类别、置信度、掩码面积，以及最小外接矩形的长边、短边与长边方向
输出 掩码 图像 全部目标合成的掩码，与原图同尺寸，目标为 255、背景为 0
输出 标注图 标注图 叠加目标轮廓、类别与置信度，仅供查看。类别名含中文等非 ASCII 字符时显示为 #序号，设置窗口里仍显示原名
Warning

没有目标不算失败，只是定位端口没有值，接在它后面的节点会因缺少输入而报错

Warning

掩码中相互重叠的目标会合并成一个区域。测量单个目标的长度、面积请用定位列表或结果数据，不要在掩码上再做 Blob 分析

Tip

需要按数量判定时接定位列表

使用

  1. 双击卡片打开设置窗口，在模型中点 导入模型，选择 Ultralytics 导出的 ONNX 分割模型（format=onnx）。模型随工程保存，原文件删除不影响运行
  2. 导入后在类别中取消勾选不需要输出的类别
  3. 上游接好相机或图像源，点标题栏的「运行到此节点（F5）」，在图上查看目标轮廓，在结果表里查看类别、置信度、面积与尺寸
  4. 按误检、漏检情况调整置信度阈值
Note

只接受分割模型，检测、旋转框模型请用「目标检测」节点

参数

检测参数

参数 默认值 说明
置信度阈值 0.25 置信度高于此值的目标才输出，范围 0.01 ~ 1。误检多就调高，漏检多就调低
IoU 阈值 0.7 同类框重叠超过此值时只留置信度最高的，范围 0.01 ~ 1。只对需要 NMS 的模型（默认导出）有效，端到端模型忽略
最多数量 100 最多输出的目标数，范围 1 ~ 300
推理设备 CPU CUDA（NVIDIA） 需要 NVIDIA 显卡和 GPU 版 ONNX Runtime，不可用时自动用 CPU
Important

推理设备选 CUDA 时需先安装 GPU 运行时：主程序「设置 → 依赖的组件」中的 ONNX Runtime GPU (CUDA)，点 安装 从更新源下载（约 1 GB），重启软件后生效；NVIDIA 驱动需支持 CUDA 13.0 及以上

类别

参数 默认值 说明
类别勾选 全部勾选 取消勾选的类别不输出；颜色与标注图一致。类别较多时可按类别名或序号搜索。重新导入模型后恢复为全部勾选

参数访问

参数名 含义 类型 范围 / 可选值 访问
ConfidenceThreshold 置信度阈值 double 0.01～1（有限数值） Get/Set
IouThreshold IoU 阈值 double 0.01～1（有限数值） Get/Set
MaxCount 最多数量 int 1～300 Get/Set
Device 推理设备 枚举 Cpu、Cuda Get/Set（需停管道）
DisabledClasses 不输出的类别 string 模型类别名或序号，逗号分隔；空字符串表示不排除类别 Get/Set

普通参数可在两轮之间修改；标为「需停管道」的参数先停止管道。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Count 目标数
TotalArea 全部目标的掩码面积之和（像素²）
Label 第一个目标（置信度最高）的类别名
ClassId 第一个目标的类别序号，没有目标时为 -1
Score 第一个目标的置信度
X / Y 第一个目标的掩码质心（像素）
Area 第一个目标的掩码面积（像素²）
Width / Height 第一个目标掩码最小外接矩形的长边 / 短边（像素）
Angle 第一个目标长边方向（度）
Items 全部目标，含轮廓点
Count.<类别名> 该类别的目标数，每个类别一项
Area.<类别名> 该类别的掩码面积之和（像素²），每个类别一项

典型搭配

场景 链路
缺陷尺寸判定 相机 → 实例分割 → 列表筛选（面积 / 宽度）→ 计数判定
缺陷面积换算 相机 → 实例分割 → 像素转机械坐标 → 列表筛选
