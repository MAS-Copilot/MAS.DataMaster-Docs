图像分类

识别整张图像的类别，并支持通过勾选合格类别判定 OK/NG

端口

方向 名称 类型 说明
输入 图像 图像 待分类的图像，整张参与分类
输出 图像 图像 输入原图直通，供下游算法使用
输出 置信度 数值 概率最高的类别的置信度
输出 标注图 标注图 叠加类别与置信度，判定时另加 OK / NG，仅供查看。类别名含中文等非 ASCII 字符时显示为 #序号
Tip

只检查图像局部时，先在上游裁剪出该区域再接入，否则整张图都参与分类

使用

  1. 双击卡片打开设置窗口，在模型中点 导入模型，选择 Ultralytics 导出的 ONNX 分类模型（format=onnx）。模型随工程保存，原文件删除不影响运行
  2. 上游接好相机或图像源，点标题栏的「运行到此节点（F5）」，在结果表里查看概率最高的几个类别
  3. 需要判定时，在合格判定中勾选算合格的类别，并设置最低置信度
  4. 按需勾选不合格时中止流程

参数

参数 默认值 说明
推理设备 CPU CUDA（NVIDIA） 需要 NVIDIA 显卡和 GPU 版 ONNX Runtime，不可用时自动用 CPU
Important

推理设备选 CUDA 时需先安装 GPU 运行时：主程序「设置 → 依赖的组件」中的 ONNX Runtime GPU (CUDA)，点 安装 从更新源下载（约 1 GB），重启软件后生效；NVIDIA 驱动需支持 CUDA 13.0 及以上

合格判定

参数 默认值 说明
最低置信度 0.5 第一名的置信度低于此值视为模型拿不准，判为不合格，范围 0 ~ 1
不合格时中止流程 不勾选 勾选：不合格时中止管道；不勾选：只报警告并继续
合格类别 都不勾选 勾选算合格的类别；都不勾选时不判定，只输出结果。重新导入模型后清空
Note

合格条件是第一名属于合格类别，且置信度不低于最低置信度；两者缺一即判不合格

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Label 概率最高的类别名
ClassId 概率最高的类别序号
Score 概率最高的类别的置信度
IsOk 是否合格；没勾选合格类别时恒为 true
Top 概率最高的几个类别，最多 5 个
Score.<类别名> 该类别的概率，每个类别一项

典型搭配

场景 链路
整图 OK / NG 相机 → 图像分类 → Web 发布
局部分类 相机 → 形状匹配 → 定位转正（裁剪）→ 图像分类
