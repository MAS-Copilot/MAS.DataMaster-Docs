位姿生成

按下位机请求生成采样位姿（手眼标定用）。工具节点，不参与管道，没有端口，通过 Modbus TCP 与下位机交互，自带启停

使用

  1. 在卡片上填写下位机的 IP 地址与端口；不填 IP 时，在设置窗口的通讯设备填写数据采集中的设备名
  2. 打开设置窗口，按机器人的可达范围设置范围边界，确认通讯设置中的地址与下位机一致
  3. 点卡片上的 切换运行状态 启动。节点状态为运行中，持续读取下位机的请求
  4. 下位机按协议逐个请求位姿，节点状态显示当前编号与总数，如 #3/30
  5. 采样完成后再点 切换运行状态 停止
Caution

运行期间设置窗口里通讯设置以外的参数可以改，下一次请求时生效

Note

运行期间卡片上的字段与设置窗口的通讯设置不可修改

参数

基本设置

参数 默认值 说明
生成的位姿数量 30 范围 5 ~ 999。实际数量以下位机请求里的为准
随机种子 空 留空为真随机；填固定值可复现同一组位姿
采样调优模式 自动保守模式 自动保守模式 优先生成满数量；自动激进模式 间距更大更均匀，但可能生成不满；手动模式 使用下方采样参数
欧拉角旋转顺序 Zyx 默认先 Yaw(Z)，再 Pitch(Y)，再 Roll(X)

范围边界

参数 默认值 说明
X / Y (mm) -200 ~ 200 采样位置范围，Min 必须小于 Max
Z (mm) 0 ~ 300
Roll / Pitch (deg) -30 ~ 30 采样姿态范围，Min 必须小于 Max
Yaw (deg) -180 ~ 180

采样参数（仅手动模式可改）

参数 默认值 说明
随机候选池大小 300 每轮随机生成的候选数，越大分布越均匀，范围 99 ~ 9999
最小位置间距 (mm) 40 任意两个位姿的最小空间距离，防止聚集
最小姿态间距 (deg) 8 任意两个位姿的最小角度差
姿态等效距离权重 5 角度差折算为空间距离的系数（mm/deg）
最大生成尝试次数 10000 范围过小或约束过严时防止长时间生成

通讯设置

参数 默认值 说明
从站地址 1 范围 0 ~ 247
通讯设备 空 数据采集设备名，未填 IP 时使用。目前仅支持 Modbus TCP
休眠时间 (ms) 250 轮询间隔，范围 10 ~ 9999
基地址 7000 以下各偏移都相对基地址
任务执行 1002 触发值偏移
任务完成 1052 完成值偏移
请求体 1120 请求体偏移
位姿结果 1360 结果偏移
位姿编号起点 0 下位机请求第一个位姿时用的编号：0 或 1
Important

位姿编号起点必须与下位机一致，编号越界按失败应答

下位机协议

均为保持寄存器，地址 = 基地址 + 偏移

区域 方向 内容
任务执行（触发值） 下位机写 16 位整数，1 ~ 32767；0 表示复位
任务完成（完成值） 视觉写 成功 = 触发值；失败 = 触发值的相反数；复位确认 = 0
请求体 下位机写 RequestMode（1 按设置生成，2 按请求里的种子生成）、PoseIndex、Seed（-1 为真随机）、PoseCount，均为 16 位整数
位姿结果 视觉写 X、Y、Z、Yaw、Pitch、Roll（float），PoseCount、Seed、PoseIndex（16 位整数）
  1. 下位机写好请求体，再把触发值改成一个新的正数（加 1，或置 1）
  2. 视觉读到新的触发值，先写位姿结果，再把完成值写成触发值。下位机等到完成值等于触发值再读结果
  3. 请求无效（编号超出范围、位姿数量 ≤ 0、请求模式无效、生成失败）时不写结果，完成值写成触发值的相反数，节点显示警告并继续处理后续请求
  4. 触发值写 0 表示复位，视觉回写完成值 0。下位机必须等完成值变成 0 后才能再次置 1
  5. 同一个请求要重试，必须换一个触发值；触发值不变不会重复处理
  6. 触发值递增到 32767 后回到 1，不经过 0、不用负数
Warning

在一个轮询间隔内完成的 1 → 0 → 1，视觉看不到中间的 0，会当成同一次请求不处理

Warning

触发值为负数时视觉不处理也不应答，节点显示错误。下位机按 16 位整数递增时 32767 + 1 会溢出为负数，务必回绕到 1

Warning

读写寄存器出错时节点停止并显示错误，需要重新启动

Note

种子为 -1 时，编号回到起点才重新抽取一组，下位机重试起点编号不会中途换组
