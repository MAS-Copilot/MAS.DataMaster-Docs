在节点卡片上点更多或右键 → 帮助，打开该节点的帮助

添加节点

操作 说明
从左侧组件库拖到画布 在松开处添加节点
双击组件库中的节点 添加到视图中央
组件库搜索框，或按 / 按名称或说明筛选组件
工具栏组件按钮 显示或隐藏组件库
Ctrl + F 查找画布上已有的模块：↑ ↓ 选择，Enter 定位，Esc 关闭

选择与移动

操作 说明
左键单击卡片 选中该节点
Ctrl / Shift + 单击 加选或减选
空白处从左往右拖拽 框选（完全包含）：整个卡片在框内才选中
空白处从右往左拖拽 框选（相交）：与选框有重叠即选中
Ctrl / Shift + 框选 追加到现有选区
Ctrl + A 全选
空白处单击 / Esc 清空选区
左键拖动卡片 移动；拖动已选中的节点时整个选区一起移动
↑ ↓ ← → 微调 1 px，按住 Shift 每次 10 px

编辑

操作 说明
Ctrl + C / X / V 复制、剪切、粘贴选中节点及其之间的连线；鼠标在画布上时粘贴到光标处
Ctrl + D 创建副本，不影响剪贴板
Delete / Backspace 删除选中的节点与连线
Ctrl + Z 撤销
Ctrl + Y / Ctrl + Shift + Z 重做
双击标题，或右键 → 重命名 Enter 确认，Esc 取消；标题在画布内不能重复
卡片上的折叠按钮，或右键 → 折叠 / 展开 收起或展开卡片内容，多选时作用于全部选中节点

右键空白处还有粘贴、全选、撤销、重做、自适应视图、还原视图

连线

操作 说明
从一个端口拖到另一个端口 连线；拖动时可连接的端口高亮，靠近自动吸附
拖动中按 Esc 取消连线
单击连线 选中，按 Delete 删除
右键连线 → 删除连线 断开
  • 只能从输出连到输入；类型不兼容、重复、连到自身或会成环的连线不允许
  • 每个输入只接一条线，再接一条会替换原来的线

视图

操作 说明
鼠标滚轮 以光标为中心缩放，范围 15% ~ 300%
中键拖动 / 右键拖动 / 按住 Space 左键拖动 平移画布；右键不拖动则打开右键菜单
工具栏放大视图 / 缩小视图 以视图中心缩放
工具栏或右键 → 自适应视图 把全部节点放进视图
工具栏或右键 → 还原视图 恢复 100% 并居中
工具栏小地图 显示或隐藏小地图；在小地图上单击或拖动跳转，滚轮缩放
工具栏锁定控件 画布只读，不能增删、移动、连线、撤销；解锁需要工程师权限

运行与调试

操作 说明
卡片上的运行按钮，或右键 → 运行到此节点 只执行该节点及其上游一次
双击卡片标题以外的位置，或右键 → 设置 打开设置窗口；F5 运行到此节点，Esc 关闭，点节点 Id 复制到剪贴板
输出端口旁的查看输出 打开查看窗口：「输出」页看端口最近一次的值，「结果数据」页看结果键与值；可同时打开多个，F5 运行到此节点
卡片右上角状态点、底部耗时 最近一次执行的状态与耗时；悬停状态点查看说明

工具节点（位姿生成、脚本执行）不参与管道，没有运行按钮，用卡片上的切换运行状态启停

管道

每组至少两个相连的节点就是一条管道，图一变自动重新划分。点画布右上角管道打开管道面板，每条管道一行：

按钮 说明
名称 直接修改，Enter 确认，Esc 取消
执行一次 整条管道执行一次
切换运行状态 启动或停止，按管道脚本循环运行
初始化 手动初始化管道内的节点（打开相机、加载图像等）
脚本代码 编辑管道脚本
定位 在画布上定位到该管道
复制管道 Id 复制管道标识

行下方显示节点数、最近耗时、每秒次数与累计次数；状态点绿色为运行中，红色为上次执行失败。工作台顶部也可选择管道并执行相同操作

  • 管道内按连线顺序执行，同时就绪的节点并行；任一节点失败则整条管道失败，下游不再执行
  • 节点在第一次执行或启动时按需初始化，参数改动后自动重新初始化
  • 运行中的管道结构锁定：其节点不能删除、连线或断线，也不能运行到此节点；界面参数按节点状态编辑，脚本与 Web 的修改限制见节点设置

管道脚本与结果读取

管道启动后按 FixedIntervalMs 循环：TriggerSignalAsync 返回 true 时执行一次管道（例如读 PLC 触发位），HandleResultAsync 处理结果（例如写回 PLC），CompleteAsync 结束本轮。执行失败时也会先调用 HandleResultAsync，便于回写 NG

结果按「节点标题 + 结果键」读取，标题与键都不区分大小写：

var score = result.GetValue<double>("颜色识别", "Score");
方法 取不到时
result.GetValue<T>(节点, 键) 抛异常，消息中列出可用的节点或键
result.TryGetValue<T>(节点, 键, out value) 返回 false
result.GetValueOrDefault(节点, 键, 默认值) 返回默认值
result.GetNode(节点) 抛异常；同一节点取多个值时使用
  • 节点本次执行失败时取不到它的值，不会拿到上一次的结果
  • 各节点的结果键见节点帮助，或查看窗口的「结果数据」页
  • 节点改名后，脚本里的标题要同步修改

脚本与 Web 修改设置

脚本通过 IVisionFlowRuntime.GetNodeParameter / SetNodeParameter 访问设置；Web 在清单 visionParameters 中声明别名后，通过 dv.getVisionParameter / dv.setVisionParameter 调用

常用调用名见各节点帮助的「参数访问」，调用示例、权限与运行限制 统一说明。执行中写入会失败并提示重试，修改后仍需保存工程

端口连接规则

  • 单个定位可以直接连到定位列表输入，当作只有一个元素的列表
  • 定位列表不能直接连到只收单个定位的输入，要经过取元素指定取第几个
  • 标注图只供查看，只能连到图像浏览器、Web 发布的图像输入
