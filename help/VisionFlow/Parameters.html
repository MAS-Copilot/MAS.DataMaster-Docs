脚本与 Web 修改节点设置

按需读取或修改常用设置，参数调用名见各节点帮助的「参数访问」。只访问已声明的设置，不支持用 Get/Set 调用示教、学习模板、采样等命令

各表列出参数名、含义、类型、范围 / 可选值与访问方式。范围包含类型上限和参数校验约束，实际运行还需满足图像尺寸、资源和算法要求；动态候选随当前工程变化

管道脚本

在处理器构造函数中注入 IVisionFlowRuntime，以下用 vision 表示该实例：

var current = vision.GetNodeParameter("二值化", "Threshold");
if (!current.Found || current.Message.Length != 0){
    throw new InvalidOperationException(current.Message);
}

var changed = vision.SetNodeParameter("二值化", "Threshold", 150);
if (!changed.Success){
    throw new InvalidOperationException(changed.Message);
}
方法 参数 返回
GetNodeParameter 节点标题、参数调用名 Found 是否找到、Value 参数值、Message 消息
SetNodeParameter 节点标题、参数调用名、值 Success 是否成功、Message 消息
  • 节点标题和参数调用名不区分大小写；节点改名后，脚本和 Web 清单中的标题也要修改
  • 成功时 Message 为空字符串；Value 为 null 不代表未找到
  • 枚举读出为枚举名，写入也用枚举名，不用界面上的中文标签。例如二值化 Mode 可写 Fixed、Otsu、Triangle、AdaptiveMean、AdaptiveGaussian
  • 嵌套设置填写完整路径，例如 ImageSourceModel.FilePath。路径是 DataMaster 所在电脑上的路径
  • 固定阈值仅在 Mode 为 Fixed 时参与运算，自动模式下修改 Threshold 只改变保存的设置

Web 页面

在工程的 Web/manifest.json 中声明需要快捷调整的设置：

{
  "visionParameters": {
    "threshold": {
      "node": "二值化",
      "parameter": "Threshold",
      "writable": true
    }
  }
}

页面使用别名，不直接传节点标题。writable 默认 false；读取遵循应用查看角色，写入还需满足应用写入角色，默认需操作员及以上登录。参数编辑不要求添加「Web 发布」节点

SDK 方法 返回
await dv.getVisionParameter("threshold") { success, value, message }
await dv.setVisionParameter("threshold", 150) { success, value, message }；成功时 value 为服务端读回值

下面的输入框适用于固定阈值模式，页面引入 SDK 后即可使用：

<label>阈值 <input id="threshold" type="number" min="0" max="255" step="1"></label>
<button id="apply">应用</button>
<span id="message"></span>
<script src="/_sdk/dynamic-views.js"></script>
<script type="module">
  const input = document.getElementById("threshold");
  const button = document.getElementById("apply");
  const message = document.getElementById("message");
  try {
    const dv = await DynamicViews.connect();
    const current = await dv.getVisionParameter("threshold");
    if (!current.success) throw new Error(current.message);
    input.value = current.value;
    button.onclick = async () => {
      if (!input.reportValidity() || input.value === "") return;
      button.disabled = true;
      try {
        const result = await dv.setVisionParameter("threshold", Number(input.value));
        message.textContent = result.success ? "已应用" : result.message;
        if (result.success) input.value = result.value;
      } catch (error) {
        message.textContent = error.message;
      } finally {
        button.disabled = false;
      }
    };
  } catch (error) {
    message.textContent = error.message;
  }
</script>

未声明、无权限或连接异常时 Promise 拒绝；设置值无效、节点不存在或正在执行时，检查返回的 success 和 message。成功消息为空字符串。Web 值仅支持数字、布尔、字符串或允许的 null，不支持对象、数组

生效与限制

情况 Set 行为
节点空闲、管道已停止 按参数类型、范围、奇数和枚举约束校验后修改
普通可写参数 连续运行时可在两轮之间修改，无需按节点类型区分
表中标为「需停管道」的参数 先停止管道，例如模型文件、推理设备、图像来源和通讯连接设置
正在初始化、执行、预览，或管道正在启动/停止 返回失败，稍后重试；不会排队自动应用
点图移动、2D 标定、相机标定、手眼标定、工具节点 Set 不开放，使用专用设置界面；已声明的标量仍可 Get

相机驱动和采集模式修改前还需关闭相机，包含未运行管道但单独打开的相机。开发节点时，普通参数不需额外注册；涉及设备连接或资源替换的参数在 VisionParameter 上标注 RequiresStopped = true，节点自身的独立活动限制由节点检查

修改仅作用于当前内存，成功后在下一次执行前按需重新初始化；仍需保存工程。多个 Set 分别提交，不保证一起成功。脚本中适合在 TriggerSignalAsync、HandleResultAsync 或 CompleteAsync 调用，失败时检查消息，不要在循环里无间隔重试

两点距离、点线距离、列表合并、图像信息当前没有可访问设置；相机标定、手眼标定、位姿生成和脚本执行也未声明可 Get 的参数。各节点帮助只列常用调用名，界面参数不一定已开放
