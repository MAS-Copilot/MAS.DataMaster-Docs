图像信息

显示图像尺寸、通道与 HSV 范围，用于调参时查看图像属性

端口

方向 名称 类型 说明
输入 图像 图像 要统计的图像
Warning

HSV 按输入为 BGR 彩色图换算。接颜色空间转换输出的 HSV 图时结果没有意义，应接原图或 ROI 裁剪后的彩色图

卡片上列出全部统计项，除下表的结果键外还有总像素、每行字节、数据类型、图像矩 M00、透明通道、标准差等

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Width / Height 宽度、高度（像素）
ChannelCount 通道数
Depth 像素深度代码，0 为 8 位无符号整数
HMin / HMax H 最小值、最大值
SMin / SMax S 最小值、最大值
VMin / VMax V 最小值、最大值
MeanColor 平均颜色，按 B、G、R 顺序给出
Note

单通道图像不计算 HSV，H、S、V 各键为 NaN；平均颜色只有第一个分量有效
