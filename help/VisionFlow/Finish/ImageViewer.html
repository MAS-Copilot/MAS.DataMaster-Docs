图像浏览器

显示结果图像，可选保存到磁盘，按天数与容量自动清理

端口

方向 名称 类型 说明
输入 图像 图像 要显示的图像，可接原图或标注图

使用

  1. 把要查看的图像连到输入，运行后卡片上显示最近一帧
  2. 需要留图时勾选卡片上的保存图像，或在设置窗口打开图像保存
  3. 在设置窗口选择保存路径、保存格式，按需填写文件夹名称与文件前缀
  4. 长期运行时打开存储策略，设置保留天数与最大占用空间

图像按 保存路径\文件夹名称\年月\日\前缀_时分秒毫秒.扩展名 存放；卡片上的文件夹按钮打开当前保存目录

参数

图像保存

参数 默认值 说明
图像保存 关闭 与卡片上的保存图像是同一个开关
保存路径 数据目录下的 Images 点 … 选择文件夹
文件夹名称 空 留空则使用模块名称，改模块名后会存到新文件夹
保存格式 PNG PNG 无损、文件较大；JPEG 有损、文件较小；BMP 无压缩、文件最大
文件前缀 Image 文件名开头
Warning

保存在后台排队进行。写盘跟不上时节点显示警告「图像保存队列已满，本帧未保存」，该帧不保存

存储策略

参数 默认值 说明
自动清理 开启 存储策略标题右侧的开关
保留天数（天） 7 保留最近 N 个自然日（含当天），范围 0 ~ 3650。0 表示不按天数清理
最大占用空间（MB） 1024 总大小超过后由旧到新删除，直到低于它。0 表示不按容量清理
定时清理周期（分钟） 60 两次清理检查的间隔，范围 1 ~ 10080
Note

自动清理只处理本模块文件夹里的图像，且只在保存图像期间按周期检查；关闭保存后不再清理

典型搭配

场景 链路
查看检测结果 定位 / 测量节点 → 标注图 → 图像浏览器
留存原图 相机 → 图像浏览器（打开图像保存）
