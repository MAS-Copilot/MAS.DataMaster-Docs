Web 发布

把图像与结果数据发布到 Web 视图展示，合格与否由网页判断

Note

视觉只发布，不判定。OK / NG 由网页按字段值判断；上游节点失败时发布一帧失败结果，网页显示为异常而不是 NG

端口

方向 名称 类型 说明
输入 图像 图像 要展示的图像，可接原图或标注图

使用

  1. 把要展示的图像连到输入。节点必须连进管道，才能引用这条管道里其他节点的结果
  2. 打开设置窗口，填写通道名；Web 视图清单中声明同名通道，网页按此名订阅
  3. 点 添加字段，每行填写别名，选择来源节点与结果键，按需填写显示名称、单位、小数位数。一行相当于「别名 = 节点标题.结果键」，结果键选 * 发布该节点全部数据
  4. 运行管道，网页收到图像与各字段的值
Tip

结果键下拉框列出来源节点最近一次运行的结果键，先运行一次再选更方便

参数

图像发布

参数 默认值 说明
通道名 vision 由点分隔的若干段，每段以字母或下划线开头，只含字母、数字、下划线、连字符，总长不超过 64
图像最长边 1280 px 原图更大时按比例缩小，范围 160 ~ 4096 px。只供展示，细看请用图像浏览器
JPEG 质量 75 范围 30 ~ 95
图像帧率上限 5 fps 连续运行时每秒最多发布的图像数，范围 0.2 ~ 30。结果数据每轮都发
Warning

通道名不合法时节点执行失败

Note

连续运行时没有网页订阅就不编码图像

发布字段

列 说明
别名 网页引用该字段的名称。以字母或下划线开头，只含字母、数字、下划线，总长不超过 64，不能重复
来源节点 同一管道里节点的标题
结果键 来源节点的结果键，* 为该节点全部数据
显示名称 / 单位 网页显示用，可留空
小数位数 数值保留的小数位，范围 0 ~ 15，留空不处理
Important

字段按来源节点的标题引用，节点改名后要同步修改

Warning

不合法的字段不发布，问题汇总显示在节点警告里

Note

字段在整轮结束后取值，可以引用同一管道里的任何节点，包括本节点下游的

参数访问

参数名 含义 类型 范围 / 可选值 访问
Channel 通道名 string 发布通道名，应与 Web 清单中的视觉通道一致 Get/Set
MaxImageEdge 图像最长边 int 160～4096 px Get/Set
JpegQuality JPEG 质量 int 30～95 Get/Set
MaxImageRate 图像帧率上限 double 0.2～30 fps（有限数值） Get/Set

连续运行时可在两轮之间修改，执行中返回失败需重试。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Channel 发布通道名
FieldCount 有效的发布字段数

典型搭配

场景 链路
结果显示到网页 相机 → 定位 / 测量节点 → 标注图 → Web 发布
