金样比对

与金样逐像素比较，超出容差的区域按面积判缺陷；可用多张好件建模

端口

方向 名称 类型 说明
输入 图像 图像 待检图，须与金样同尺寸、同取景。8 位灰度或彩色，彩色先转灰度
输出 图像 图像 输入原图直通，供下游算法使用
输出 缺陷 定位列表 全部缺陷，按面积从大到小。位置为质心，宽高为外接矩形，带面积，得分为超出量 / 255
输出 缺陷区域 图像 缺陷区域二值图，可接轮廓分析按形状再筛
输出 标注图 标注图 叠加缺陷轮廓、序号与 OK/NG，仅供查看
Warning

待检图与金样尺寸不同时节点报错，管道失败。前面没有对齐、相机分辨率或裁剪尺寸改过时，先对齐或重设金样

使用

  1. 上游先定位再用定位转正裁剪，保证每次送进来的图与金样同尺寸、同取景
  2. 在好件上运行一次，打开设置窗口，在金样分组点 设为金样。只用这一张，每个像素的容差就是灰度容差
  3. 需要更抗正常波动时，每换一个好件运行一次后点 加入好件，按每个像素的均值与标准差建模。没有金样时点它等同于设为金样
  4. 好件较多时打开 连续采集好件，用图像源（文件夹，开启读取后移走）逐张触发，每次运行都把输入加入金样，期间不判定；采完关闭
  5. 切到 差异图 查看与金样之差（不扣容差），对照像素读数定灰度容差；切到 金样 查看金样（多张好件时为均值）
  6. 运行，在结果表里查看每个缺陷的位置、面积、外接尺寸、超出量与极性，按需调整容差与判定参数
Warning

点 清除金样 后需重新设金样，否则运行时报「未设金样：先在好件上运行，再点「设为金样」」

Warning

采完忘记关闭连续采集好件时，后续每张图都会被当作好件加入金样且不判定

Note

金样随工程保存在工程文件夹内，不依赖外部文件

Note

连续采集好件不随工程保存，重开工程后为关闭

参数

容差

参数 默认值 说明
极性 都检 偏亮只检比金样亮的（多料、反光、异物），偏暗只检比金样暗的（缺料、脏污、划痕）
灰度容差 30 与金样相差超过该灰度才算异常，范围 0 ~ 255；多张好件建模后为容差下限
标准差倍数 3 范围 0 ~ 20。多张好件建模后，每个像素的容差取 max(灰度容差, 倍数 × 该像素标准差)，边缘、纹理、反光这类本来就会变的地方自动放宽
对位容差 1 px 范围 0 ~ 10 px。吸收该像素数以内的对位误差，边缘不报假缺陷；越大越不敏感

缺陷判定

参数 默认值 说明
去噪尺寸 0 px 范围 0 ~ 15 px。异常区域先做开运算去掉零散噪点，0 不做；比它细的划痕也会被抹掉
最小缺陷面积 20 px² 连通后面积不到它的不算缺陷
允许缺陷数 0 缺陷数超过它判不合格，0 表示不允许有缺陷
不合格时中止管道 关闭 开启时不合格管道失败；关闭时只警告，结果里 IsOk 为 false
Tip

要检细划痕时去噪尺寸保持 0，靠最小缺陷面积滤掉噪点

参数访问

参数名 含义 类型 范围 / 可选值 访问
Polarity 极性 枚举 Both、Bright、Dark Get/Set
Tolerance 灰度容差 double 0～255（有限数值） Get/Set
DeviationFactor 标准差倍数 double 0～20（有限数值） Get/Set
AlignTolerance 对位容差 int 0～10 px Get/Set
DenoiseSize 去噪尺寸 int 0～15 px Get/Set
MinDefectArea 最小缺陷面积 double ≥ 1 px²（有限数值） Get/Set
AllowedDefects 允许缺陷数 int 0～2147483647 Get/Set
IsAbortOnFailure 不合格时中止管道 bool true / false Get/Set

连续运行时可在两轮之间修改，执行中返回失败需重试。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
IsOk 是否合格（缺陷数不超过允许缺陷数）
Count 缺陷数
TotalArea 缺陷总面积（像素²）
MaxArea 最大缺陷面积（像素²）
MaxDeviation 缺陷超出容差的最大灰度
SampleCount 金样模型的好件数
Items 全部缺陷，按面积从大到小

典型搭配

场景 链路
缺陷检测 形状匹配 → 定位转正（裁剪）→ 金样比对，管道脚本按 IsOk 回写 OK/NG
按形状筛缺陷 金样比对（缺陷区域）→ 轮廓分析 → 列表筛选 / 计数判定
按大小筛缺陷 金样比对（缺陷）→ 列表筛选（面积）→ 计数判定
