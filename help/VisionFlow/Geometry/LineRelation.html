两线关系

两条直线的夹角、交点、平行/垂直判定与间距；两条边的交点可作角点定位

端口

方向 名称 类型 说明
输入 直线 A 定位 当作过该点、沿其角度的无限长直线，直接接直线定位、卡尺找线的输出
输入 直线 B 定位 同直线 A
输出 夹角 数值 两线夹角，0° ~ 90°
输出 交点 定位 两线交点，角度与直线 A 相同；平行时不输出
Warning

夹角在角度容差内判为平行时不计算交点，节点显示警告「两线平行，没有交点」，接在交点输出上的下游因缺少输入而报错

Tip

量平行边间距用 Distance

参数

参数 默认值 说明
角度容差 1° 范围 0° ~ 45°。夹角不超过该值判为平行，与 90° 相差不超过该值判为垂直

参数访问

参数名 含义 类型 范围 / 可选值 访问
AngleTolerance 角度容差 double 0～45 °（有限数值） Get/Set

连续运行时可在两轮之间修改，执行中返回失败需重试。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Angle 夹角（0 ~ 90 度）
DirectedAngle B 相对 A 的方向角差（-180 ~ 180 度）
IsParallel 是否平行（容差内）
IsPerpendicular 是否垂直（容差内）
Distance B 的参考点到直线 A 的距离，平行时即两线间距
IntersectionX / IntersectionY 交点坐标，平行时为 0
Note

单位跟随输入：接像素坐标得到像素，接像素转机械坐标之后的结果得到 mm

典型搭配

场景 链路
角点定位 卡尺找线 ×2 → 两线关系（交点）→ 位置补正
垂直度检查 卡尺找线 ×2 → 两线关系（夹角）→ 数值判定
