点集拟合

把一组点（卡尺边缘点、孔中心等）拟合成直线、圆、椭圆或最小外接矩形

端口

方向 名称 类型 说明
输入 点集 定位列表 只取每个定位结果的 X、Y
输出 拟合结果 定位 拟合出的形状。直线为内点范围中点加方向，可直接当直线用；圆带半径
输出 内点 定位列表 参与拟合的点，顺序与输入相同
输出 残差 数值 内点到形状距离的均方根，可作直线度、圆度参考
输出 主尺寸 数值 直线长度、圆直径、椭圆长轴或矩形长边，可接数值判定
Warning

点数不够、点退化（如共线的点拟合圆）或内点不够时，节点显示警告且不输出，下游因缺少输入而报错

参数

参数 默认值 说明
形状 直线 直线至少 2 点，圆 3 点，椭圆 5 点；最小外接矩形包住全部点，不区分内点与离群点
方法 RANSAC 点干净用最小二乘，少量离群点用 Huber，离群点多（毛刺、杂点）用 RANSAC。最小外接矩形不显示
拟合容差 2 内点的最大距离（RANSAC）或开始降权的距离（Huber），单位同输入点；最小二乘只用它统计内点。最小外接矩形不显示
Note

单位跟随输入：接像素坐标得到像素，接像素转机械坐标之后的结果得到 mm，拟合容差按同一单位填写

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Found 是否拟合成功
X / Y 中心坐标，直线为内点范围中点
Angle 方向（度，-90 ~ 90）：直线方向、椭圆长轴、矩形长边，圆为 0
Width 直线长度、圆直径、椭圆长轴、矩形长边
Height 圆直径、椭圆短轴、矩形短边，直线为 0
Radius 圆的半径
Size 主尺寸，同主尺寸输出
Rms 残差均方根，矩形为 0
Inliers 内点数
Outliers 离群点数
Points 输入点数

典型搭配

场景 链路
法兰分布圆 轮廓分析（拟合圆）→ 点集拟合（圆，RANSAC）→ 数值判定
多段边拟合 卡尺找线 ×N → 列表合并 → 点集拟合（直线 / 圆）
