两点距离

两点（或两圆心）的距离、方向与中点；两个都是圆时给出边缘间隙

端口

方向 名称 类型 说明
输入 点 A 定位 取定位结果的 X、Y；带半径时当圆
输入 点 B 定位 同点 A
输出 距离 数值 两点之间的距离，可接数值判定
输出 中点 定位 两点的中点，角度为 A 指向 B 的方向
Important

输入只收单个定位。上游输出定位列表时，先用取元素指定取第几个

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Distance 两点距离
DX / DY B − A 的 X、Y 分量
Angle A 指向 B 的方向（度，-180 ~ 180）
Gap 两圆边缘间隙，即距离减去两个半径，为负表示相交；不是两个圆时等于距离
MidX / MidY 中点坐标
Note

单位跟随输入：接像素坐标得到像素，接像素转机械坐标之后的结果得到 mm

Note

只有两个输入都带半径（圆定位、卡尺找圆、点集拟合的圆等）时 Gap 才是边缘间隙

典型搭配

场景 链路
孔距 圆定位 → 列表排序 → 取元素 ×2 → 两点距离 → 数值判定
两圆间隙 卡尺找圆 ×2 → 两点距离（Gap）
