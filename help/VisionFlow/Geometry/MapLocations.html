坐标映射

用坐标变换把定位结果换到另一个坐标系，如把 ROI 裁剪图上的结果还原到原图

端口

方向 名称 类型 说明
输入 定位列表 定位列表 待映射的定位结果；单个定位也可直接接入
输入 坐标变换 坐标变换 接 ROI 选择器、定位转正等节点的「坐标变换（输出→原图）」，或位置补正的补正变换
输出 定位列表 定位列表 映射后的全部结果，顺序与输入相同
输出 定位 定位 映射后的第一个结果
Warning

输入为空列表时，定位列表输出空列表，定位不输出，节点显示警告

Note

只换算位置和角度，半径、宽高、面积等保持原值。接缩放的变换时，这些尺寸仍是缩放图上的像素

参数

参数 默认值 说明
逆变换 不勾选 反向映射，例如从原图坐标换到 ROI 裁剪图坐标

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Count 个数
X / Y 第一个映射后的坐标
Angle 第一个映射后的角度（度）
Items 映射后的全部结果

典型搭配

场景 链路
ROI 内定位还原 ROI 选择器 → 定位 → 坐标映射 → 像素转机械坐标
转正后精测 定位 → 定位转正（裁剪）→ 精测 → 坐标映射
先缩小再精测 缩放 → 粗定位 → 坐标映射 → 原图精测
