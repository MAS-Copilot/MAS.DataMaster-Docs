数值判定

判断测得的数值是否在合格范围内，数值原样输出

端口

方向 名称 类型 说明
输入 值 数值 待判定的数值，如距离、夹角、直径
输出 值 数值 输入数值原样输出

参数

参数 默认值 说明
下限（含） 勾选，0 勾选后小于下限判不合格；不勾选则不限下限
上限（含） 不勾选，0 勾选后大于上限判不合格；不勾选则不限上限
不合格时中止 关闭 开启时超出范围管道失败；关闭则只提示警告，结果数据 IsOk 为 false
Warning

默认不合格只警告，管道照常完成，下游继续执行。需要不合格时停止后续换算与下发，开启不合格时中止，或在管道脚本里按 IsOk 处理

Note

上下限都含端点，等于上限或下限算合格

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Value 输入数值
IsOk 是否在合格范围内

典型搭配

场景 链路
尺寸测量 定位 → 两点距离 / 点线距离 / 两线关系 → 数值判定
分布圆直径 轮廓分析 → 点集拟合（圆）→ 数值判定（主尺寸）
卡尺精测 卡尺 / 卡尺找圆 → 数值判定
