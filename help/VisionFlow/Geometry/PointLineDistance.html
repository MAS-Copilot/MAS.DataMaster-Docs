点线距离

点到直线的垂直距离与垂足，如孔心到板边的距离

端口

方向 名称 类型 说明
输入 点 定位 取定位结果的 X、Y
输入 直线 定位 当作过该点、沿其角度的无限长直线，直接接直线定位、卡尺找线的输出
输出 距离 数值 点到直线的垂直距离，可接数值判定
输出 垂足 定位 点在直线上的投影，角度与直线相同
Warning

直线输入只用定位结果的位置和角度。圆定位这类结果角度为 0，接到直线输入会被当成一条水平线，要接能给出直线方向的定位

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Distance 点到直线的距离
SignedDistance 带符号距离。点在直线方向转 +90° 的一侧为正，可用来判断点在线的哪一侧
FootX / FootY 垂足坐标
Note

单位跟随输入：接像素坐标得到像素，接像素转机械坐标之后的结果得到 mm

典型搭配

场景 链路
孔到边距离 圆定位 → 取元素 + 卡尺找线 → 点线距离 → 数值判定
