相机

打开相机，每次执行抓取一帧

端口

方向 名称 类型 说明
输出 图像 图像 本次抓取的一帧
Warning

相机断线后执行失败，下次运行自动重新打开相机

使用

  1. 打开设置窗口，在相机提供者配置中选择驱动
  2. 点 刷新（卡片上为搜索设备按钮）查找相机，在下拉框中选中设备
  3. 点卡片上的 打开，预览区开始出图。管道运行时相机未打开会自动打开
  4. 按触发方式选择采集模式；触发模式下按节拍设置触发超时(ms)
  5. 相机打开后，直接在模块卡片上调整曝光、增益；设置窗口的基本设置用于调整亮度等参数，相机旋转用于旋转画面

参数

参数 默认值 说明
相机提供者配置 VideoCapture 相机驱动。VideoCapture 为通用视频捕获（本地摄像头等），HikMvs 为海康 MVS 工业相机。切换后相机关闭
相机 — 选中的设备，随工程保存。卡片上的下拉框在相机打开期间不可更改
采集模式 连续采集 连续采集取缓冲区最新一帧，可能是触发之前拍的。软触发每次执行下发软触发并等待这一帧。外部触发取上次执行之后相机由 IO 触发拍的帧
触发超时(ms) 1000 等待触发出图的时间，范围 10 ~ 60000，相机会再加上曝光时间。仅触发模式显示
亮度 / 对比度 / 清晰度 / 饱和度 相机当前值 范围 0 ~ 100，相机打开后才可调。打开相机时读回相机当前值，驱动不支持时提示「不受支持的操作」
曝光 相机当前值 在模块卡片上直接调整，相机打开后可用。支持小数；MVS 单位为微秒（μs），VideoCapture 单位由驱动决定，可能为负值。手动调整前先在相机配置中关闭自动曝光。编辑完成离开输入框后下发，失败时恢复实际值；随工程保存，重新打开时在开流前恢复
增益 相机当前值 在模块卡片上直接调整，相机打开后可用。支持小数，单位和范围由相机决定。手动调整前先在相机配置中关闭自动增益。编辑完成离开输入框后下发，失败时恢复实际值；随工程保存，重新打开时在开流前恢复
相机旋转 无旋转 可选 右 90°、左 90°、180°、无旋转，相机打开后才可调。驱动不支持时提示并恢复原值
取景网格 关 在卡片预览上叠加辅助线：三分构图法、黄金比率、交叉线、正方形。只影响显示
显示帧率 开 在卡片预览左上角显示实时帧率
Important

外部触发要求相机触发源为 IO 线（如 Line0），触发源、延时、去抖以 MVS 中保存的相机配置为准。触发源为 Software 时无法切换到外部触发，需在 MVS 中修改并保存到用户参数集

Warning

连续采集取的是缓冲区里的最新一帧，可能早于触发时刻。必须拍到触发之后画面的场合用软触发或外部触发

Warning

两次执行之间来了多次外部触发时只交出最新一帧，节点显示警告

Note

VideoCapture 驱动不支持真正的软触发，选软触发时每次执行丢弃在途帧后取新帧，属于尽力而为；也不支持外部触发

参数访问

参数名 含义 类型 范围 / 可选值 访问
Brightness 亮度 short -32768～32767 Get/Set
Contrast 对比度 short -32768～32767 Get/Set
Sharpness 清晰度 short -32768～32767 Get/Set
Saturation 饱和度 short -32768～32767 Get/Set
Exposure 曝光 double? 驱动规定；null 保留相机配置 Get/Set
Gain 增益 double? 驱动规定；null 保留相机配置 Get/Set
AcquisitionMode 采集模式 枚举 Continuous、SoftwareTrigger、ExternalTrigger Get/Set（需停管道）
TriggerTimeoutMs 触发超时(ms) int 10～60000 ms Get/Set

普通参数可在两轮之间修改；标为「需停管道」的参数先停止管道，驱动和采集模式还需先关闭相机。调用方式与限制
