图像源

从文件、文件夹（最新一张）或网络地址读取图像

端口

方向 名称 类型 说明
输出 图像 图像 读取到的图像

使用

  1. 打开设置窗口，选择来源：从文件加载、从文件夹加载 或 从网络加载
  2. 文件、文件夹用右侧按钮选择路径，网络来源直接填写地址；卡片上的选择按钮选的是文件
  3. 文件、网络来源点 加载图片 立即读取并预览；文件夹来源每次执行时才读取，无需加载
  4. 文件夹来源要逐张处理时，打开读取后移走

参数

参数 默认值 说明
从文件加载 选中 读取一个图片文件。加载成功后原图存一份到工程：原路径在就读原路径，文件内容变了会更新副本；工程拷到别的电脑找不到原路径时读这份副本
从文件夹加载 — 只看文件夹本身，不含子目录，支持 bmp、png、jpg、jpeg。默认每次读写入时间最新的一张，不改动任何文件
读取后移走 关 文件夹来源可用。打开后按写入时间从早到晚逐张处理：每张先移到该文件夹下的 Processed 子目录再读取，重名时追加序号，不会删除
从网络加载 — 从网络地址下载图像，超时 15 秒
Warning

文件夹里没有图像时节点执行失败，连续运行前确认有图可读

Warning

打开读取后移走时，已移走但解码失败的图留在 Processed 里，本次报错

Note

打开读取后移走时，正在写入、被占用或已被别处取走的图跳过，留到下一次，同一张不会处理两次

Note

网络来源只在初始化（或点 加载图片）时下载一次，之后每次执行输出同一张图

Note

文件来源在调试时会发现外部改过的图片并重新读取；管道运行中不检查文件变化

典型搭配

场景 链路
离线调试 图像源（文件夹）→ 后续检测流程
金样逐张建模 图像源（文件夹，读取后移走）→ 形状匹配 → 定位转正 → 金样比对
