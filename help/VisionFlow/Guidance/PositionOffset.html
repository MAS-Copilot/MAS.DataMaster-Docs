示教对位

输出当前定位相对示教基准的 ΔX、ΔY、Δθ

端口

方向 名称 类型 说明
输入 定位 定位 当前的定位结果
输出 偏移 偏移 相对基准的 ΔX、ΔY、Δθ 与单位
Warning

尚未示教基准时只报警告，不输出偏移

使用

  1. 上游接定位节点，工件放在标准位置，运行一次
  2. 点卡片上的 设为基准，把最近一次的定位结果设为示教基准
  3. 需要按毫米输出时，在卡片上填写像素当量
  4. 换工件运行，读取偏移下发

基准也可以在设置窗口里直接填写基准 X、基准 Y、基准角度，并打开已示教基准

参数

参数 默认值 说明
像素当量 0 每像素对应的毫米数，0 表示按像素输出
已示教基准 禁用 点 设为基准 后自动启用；禁用时不输出偏移
基准 X / 基准 Y 0 基准位置，单位与输入定位一致（通常为像素）
基准角度 0 基准角度（°），范围 -180 ~ 180

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
DX / DY 当前位置减基准位置，单位见 Unit
DAngle 当前角度减基准角度（度，-180 ~ 180）
Unit 偏移单位：px 或 mm
IsReferenceSet 是否已示教基准
Note

ΔX、ΔY 是参考点位置的直接差值，不含绕某个中心旋转的补偿

Note

Unit 只由像素当量决定：上游已换成机械坐标时像素当量保持 0，数值即机械单位，但 Unit 仍显示 px

Tip

需要按旋转修正整组点位时用位置补正

Tip

脚本里先判断 IsReferenceSet，再读取偏移

典型搭配

场景 链路
二维引导 相机 → 形状匹配 → 示教对位
机械坐标对位 相机 → 形状匹配 → 像素转机械坐标 → 取元素 → 示教对位
