姿态解算

根据 ArUco / ChArUco 标记求平面相对相机的位姿

端口

方向 名称 类型 说明
输入 图像 图像 拍到标记的图像
输出 图像 图像 输入原图直通，供下游算法使用
输出 位姿结果 姿态结果 平面相对相机的位姿与解算质量；失败时也输出，IsSuccess 为 false
输出 标注图 标注图 叠加平面坐标轴与姿态角，仅供查看
Warning

解算失败不中止管道，节点只显示警告；下游手眼坐标转换会因位姿无效而报错，手眼标定则跳过该次采样

使用

  1. 在卡片上选择与实物一致的字典类型
  2. 选择内参来源：Resource 时在资源键中填写相机标定生成的内参资源键；上游接有畸变校正时，内参自动取自该节点，卡片不再显示这两项
  3. 打开设置窗口，选择姿态解算模式，按实物填写标记尺寸
  4. 运行，在结果数据中查看 IsSuccess 与重投影误差
  5. 修改参数或更换场景后，点卡片上的 重置求解 清空姿态滤波的历史帧

参数

卡片

参数 默认值 说明
字典类型 DICT_6X6_100 ArUco 字典，须与打印的标记一致
内参来源 Resource Resource：使用相机标定生成的内参资源；Default：按图像尺寸生成近似内参。Camera、Manual 暂未实现
资源键 空 内参来源为 Resource 时使用的相机内参资源，如 CameraIntrinsics-Main
Important

内参来源为 Resource 而资源键为空或资源不存在时节点报错，先运行相机标定

Tip

Default 内参只是近似值，精度要求高时不要使用

标定设置

参数 默认值 说明
姿态解算模式 基于单个 ArUco Marker 解算姿态 单个 Marker 模式取画面中面积最大的 Marker；另一选项为基于 ChArUco Board 解算姿态
姿态稳定滤波所使用的窗口帧数 1 对连续帧的旋转姿态做窗口均值滤波，抑制抖动与瞬时跳变。1 为不滤波
在解算前对图像去畸变处理 启用 上游已做畸变校正时按校正后的相机矩阵解算，此项不生效

轴方向对齐

参数 默认值 说明
实际 X 轴 相机 Z 轴正方向（相机朝前） 实际坐标系的 X 轴对应相机坐标系的哪个方向
实际 Y 轴 相机 X 轴正方向（图像向右） 同上
实际 Z 轴 相机 Y 轴负方向（图像向上） 同上。三个轴须来自不同的轴方向，构成右手坐标系

相机坐标系：X 沿图像水平向右，Y 沿图像垂直向下，Z 沿光轴指向场景前方

Note

轴方向对齐只影响欧拉角输出；手眼标定与手眼坐标转换使用相机坐标系下的原始位姿

检测与过滤阈值（单个 ArUco Marker）

参数 默认值 说明
Marker 物理边长 (mm) 20 标记的实际边长
最小 Marker 数 1 检测到的 Marker 少于该值时本次解算失败
最大重投影误差 (px) 2 重投影误差超过该值时本次解算失败

检测与过滤阈值（ChArUco Board）

参数 默认值 说明
棋盘沿 X 方向的方格数量 5 标定板 X 方向方格数
棋盘沿 Y 方向的方格数量 7 标定板 Y 方向方格数
棋盘单个方格边长(mm) 25 方格实际边长
单帧至少需要的角点数量 12 检测到的 ChArUco 角点少于该值时本次解算失败
ArUco Marker 边长(mm) 20 方格内 Marker 的实际边长

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
IsSuccess 姿态解算是否成功
PlaneToCameraEulerDeg 平面相对于相机的欧拉角（Yaw / Pitch / Roll，度）
CameraToPlaneEulerDeg 相机相对于平面的欧拉角（Yaw / Pitch / Roll，度）
ElapsedMs 解算耗时（毫秒）
DetectedMarkerCount 检测到的 ArUco Marker 数量
ReprojectionErrorPx 重投影误差（像素，越小越好）
ImageWidth / ImageHeight 参与解算的图像尺寸（像素）
UsedMarkerIndex 用于姿态解算的 Marker 索引
UsedMarkerAreaPx2 用于姿态解算的 Marker 面积（像素²）
Rvec 旋转向量 [rx, ry, rz]（弧度）
Tvec 平移向量 [tx, ty, tz]（mm）
ErrorMessage 失败原因

典型搭配

场景 链路
三维引导 相机 → 姿态解算 → 手眼坐标转换
手眼标定采样 相机 → 姿态解算 → 手眼标定（接机器位姿）
先校正再解算 相机 → 畸变校正 → 姿态解算
