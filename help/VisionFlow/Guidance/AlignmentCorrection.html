位置补正

拍基准 Mark 求工件相对示教位置的平移与旋转（ΔX、ΔY、Δθ 与变换矩阵），用于修正整组点位

端口

方向 名称 类型 说明
输入 Mark 定位列表 当前拍到的 Mark，顺序与基准一一对应。单个定位也可直接接入
输入 待修正点位 定位列表 可选。示教时的整组点位
输出 修正后点位 定位列表 待修正点位经补正变换后的结果，未接待修正点位时无输出
输出 补正变换 坐标变换 基准 → 当前的刚体变换
Important

单个 Mark 时旋转角取两次定位的角度之差，必须用能给出角度的定位（形状匹配、特征匹配、直线定位）；两个及以上 Mark 只按位置拟合。圆形 Mark 没有角度，补正用两个 Mark

Warning

当前 Mark 的数量与顺序必须与基准一致，数量不符时节点报错

Warning

尚未示教基准时只报警告，不输出结果

Tip

多个 Mark 时先用列表排序固定顺序

使用

  1. 上游接 Mark 定位，通常先经像素转机械坐标换成轴坐标
  2. 工件放在标准位置（与下位机点位对应），运行一次
  3. 点卡片上的 设为基准，记下当前 Mark 作为基准；卡片列出各基准 Mark 的坐标与角度。旁边的按钮为 清除基准
  4. 设置最大偏移与最大角度（°），防止异常结果下发
  5. 换工件运行，按结果数据下发补正量，或直接使用修正后点位

参数

参数 默认值 说明
最大偏移 0 基准中心的平移量超过该值时中止，单位跟随输入。0 表示不限
最大角度（°） 0 旋转角超过该值时中止。0 表示不限
Warning

偏移或角度超出上限时节点失败、管道中止，不会下发异常的补正量

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
IsValid 本次补正是否有效（已示教且计算成功）
DX / DY 基准中心的平移量（以基准中心为旋转中心）
DAngle 旋转角（度，-180 ~ 180）
CenterX / CenterY 旋转中心，即基准 Mark 中心
A / B / C / D 变换矩阵：x' = A·x + B·y + TX，y' = C·x + D·y + TY
TX / TY 变换矩阵的平移项
MaxResidual 多 Mark 拟合的最大残差。过大说明识别错或工件变形
MarkCount 基准 Mark 数量

脚本里可直接 RigidTransform.ApplyOffset(new Point(DX, DY), DAngle, new Point(CenterX, CenterY), points) 修正点位

典型搭配

场景 链路
点位整体补正 相机 → 形状匹配 → 像素转机械坐标 → 位置补正
双 Mark 补正 相机 → 圆定位 → 像素转机械坐标 → 列表排序 → 位置补正
