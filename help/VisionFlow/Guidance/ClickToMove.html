点图移动

在实时画面上点一下，机构就移到那里，用于快速示教与调试

端口

方向 名称 类型 说明
输入 图像 图像 相机或图像源的实时画面

使用

  1. 先完成「2D 标定（九点）」，相机或图像源接到本节点的图像输入
  2. 打开设置窗口，在通信中填写下位机的 IP 地址、端口、从站地址与命令 / 状态地址；不填 IP 时按通讯设备名称使用数据采集里的设备
  3. 选择对准方式与2D 标定资源，在安全中设置单次最大移动与软限位
  4. 点 切换运行状态 开始持续取图
  5. 点 开启引导，确认安全提示。状态显示「就绪，点击画面移动」后，点击画面即移动；点动微调按所选位移量移动 X / Y / Z
  6. 用完点 关闭引导；关闭设置窗口时引导也会自动关闭
Note

持续取图只运行本节点及其上游；所在管道连续运行或正在生产触发时自动让位，画面改由管道送来

参数

对准方式

参数 默认值 说明
对准方式 相机对准 相机对准：点到的目标移到画面中心，仅适用于相机随轴运动；针尖对准：针尖移到点到的目标上，需已示教针尖偏置
2D 标定资源 PlaneCalibration 「2D 标定（九点）」节点写入的资源键

通信

参数 默认值 说明
IP 地址 空 下位机 Modbus TCP 地址
端口 502 Modbus TCP 端口
从站地址 1 Modbus 从站地址
通讯设备 空 数据采集设备名，未填 IP 时使用
命令地址 7600 保持寄存器，共 8 个：序号(int16)、命令(int16，1=绝对移动)、X、Y、Z(float32)
状态地址 7610 保持寄存器，共 10 个：应答序号、结果(0=到位)、允许、保留(int16)，当前 X、Y、Z(float32)

通信参数只能在引导关闭时修改

Caution

下位机协议：每次点击序号 +1（1 ~ 32767 循环，不用 0）；下位机发现序号变化即执行，完成后把同一序号写回应答并给出结果

Note

点击画面只移动 X、Y，Z 保持当前值；状态中的「允许」为 0 时不发送

安全

参数 默认值 说明
单次最大移动(mm) 50 超过该距离的点击直接拒绝；0 表示不限
到位超时(s) 10 下位机应答与到位后等待新画面的超时，范围 1 ~ 120
到位稳定(ms) 100 到位后再等待的时间，范围 0 ~ 5000
软限位 不勾选 勾选后目标超出 X / Y / Z 范围时不发送。默认范围 X、Y 为 0 ~ 500，Z 为 -100 ~ 100
Note

每次移动后，界面锁住到下位机应答、到位稳定时间结束，并收到到位之后拍的新画面才解锁，防止连点

点动微调

参数 默认值 说明
位移量(mm) 1 每次点动的移动量，可选 0.01 ~ 10

参数访问

参数名 含义 类型 范围 / 可选值 访问

Set 不开放，请用专用设置界面修改。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
AxisX / AxisY / AxisZ 当前轴位置（引导开启时）
Target 最近一次的目标位置
