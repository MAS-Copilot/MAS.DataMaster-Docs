像素转机械坐标

用 2D 标定把定位结果换算成针尖要去的轴位置

端口

方向 名称 类型 说明
输入 定位列表 定位列表 像素坐标下的定位结果。单个定位也可直接接入
输入 机器位姿 位姿 拍照时的轴位置。相机随轴运动时必须接入，相机固定时可不接
输出 针尖位置 位姿 第一个目标的针尖坐标，Z 取拍照时的轴位置 Z（未接机器位姿时为 0），偏航角为目标方向
输出 针尖位置列表 定位列表 全部目标的针尖坐标，与输入同顺序
Warning

输入为空列表时只报警告，不输出针尖位置

Note

宽度、高度、半径、面积按标定的像素当量近似换算；圆度等无量纲属性保持不变

参数

参数 默认值 说明
2D 标定资源 PlaneCalibration 「2D 标定（九点）」节点写入的资源键
Warning

相机随轴运动时，2D 标定里未示教针尖偏置会提示「未示教针尖偏置，坐标只有相对意义」，此时结果不能直接作为针尖目标位置

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Count 换算的目标个数
X / Y 第一个目标：针尖要去的轴位置
Angle 第一个目标在机械坐标系里的方向（度）
PixelX / PixelY 第一个目标的像素坐标
Items 全部目标的针尖坐标，与输入同顺序

典型搭配

场景 链路
龙门打螺丝 / 点胶 阈值二值化 → Blob 分析 → 列表筛选 → 像素转机械坐标 → 列表排序 → 计数判定
点位整体补正 相机 → 形状匹配 → 像素转机械坐标 → 位置补正
