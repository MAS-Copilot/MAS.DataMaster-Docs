手眼坐标转换

把相机坐标系下的目标位姿换算到机器人基座坐标系

端口

方向 名称 类型 说明
输入 相机下目标 姿态结果 姿态解算输出的目标位姿
输入 机器位姿 位姿 拍照时的机器人位姿。眼在手上时必须接入，眼在手外时不使用
输出 基座下目标 位姿 目标在机器人基座坐标系下的位姿
Warning

姿态解算本次失败时，本节点报「目标位姿无效」并中止，不会输出上一次的结果

Note

换算使用相机坐标系下的原始位姿；姿态解算里的轴映射只影响其自身的欧拉角输出，不影响本节点

参数

参数 默认值 说明
手眼模式 眼在手上 相机装在机器人末端选眼在手上，相机固定选眼在手外。须与手眼标定时的模式一致
手眼标定结果 空 手眼标定节点写入的资源键，如 RigidTransform3D-EyeInHand
Important

手眼标定结果默认为空，须填写手眼标定节点「最后一次生成的键」，否则节点报错「找不到手眼标定资源」

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
X / Y / Z 基座坐标系下的位置（mm）
Yaw 偏航角（度）
Pitch 俯仰角（度）
Roll 横滚角（度）
Pose 完整位姿

典型搭配

场景 链路
三维引导（眼在手上） 相机 → 姿态解算 → 手眼坐标转换（接机器位姿）
三维引导（眼在手外） 相机 → 姿态解算 → 手眼坐标转换
