卡尺找圆

一圈径向卡尺各取一个边缘点，剔除离群点后拟合圆，精测孔径与圆心

端口

方向 名称 类型 说明
输入 图像 图像 待测量的图像
输入 跟随定位 定位 可选。接上并设跟随基准后，搜索区随工件平移、旋转
输出 图像 图像 输入原图直通，供下游算法使用
输出 定位 定位 拟合的圆心，带半径与直径；角度固定为 0，得分为内点占卡尺数的比例
输出 定位列表 定位列表 参与拟合的边缘点（内点），角度为该处的切线方向
输出 直径 数值 拟合圆的直径（像素）
输出 标注图 标注图 叠加各卡尺、边缘点与圆，仅供查看
Warning

未找到时（内点少于最少内点数）不输出定位与直径，节点显示警告，下游节点因缺少输入而报错

使用

  1. 上游接好相机或图像源，运行一次，让设置窗口拿到一帧图像
  2. 打开设置窗口，在图上拖动搜索圆环并调整内外半径，使要找的圆周落在内外半径之间；也可在搜索区分组里直接输入数值。只看到部分圆周时，用起始角与扫过角度限定圆弧
  3. 设置搜索方向与边缘极性。极性按搜索方向看，亮底上的暗孔由内向外为暗到亮
  4. 按 F5 或标题栏的运行按钮运行到此节点。图上每个小框为一个沿径向的卡尺，绿色十字为参与拟合的边缘点，橙色斜十字为拟合剔除的离群点（毛刺、缺口、划痕）
  5. 在剖面卡尺里选择要查看的卡尺（从 1 开始，仅供查看，不随工程保存），对照剖面图调整最小对比度与平滑 σ：上半为沿搜索方向的平均灰度，下半为对比度曲线，灰色虚线为 ± 最小对比度，左端为搜索起点；橙色虚竖线为找到的边缘，绿色竖线为该卡尺选中的边缘。要找的边的峰越过虚线才会被找到
  6. 工件位置会变时，把上游定位接到跟随定位；工件在示教位置运行一次后，在节点卡片上点 设为跟随基准，之后搜索区随定位平移、旋转。点旁边的删除按钮（清除跟随基准）恢复固定搜索区
Warning

接了跟随定位但未设基准时，节点显示警告「尚未设跟随基准，ROI 固定不动」；设了基准后上游本次没有结果，管道失败，不在错误的位置测量

Note

跟随时设置窗口里的画面映射回示教姿态，与搜索区对齐

参数

搜索区

参数 默认值 说明
中心 X / 中心 Y 200 / 200 圆环中心（像素）
半径 120 px 圆环外半径，最小 2 px。卡尺长度 = 外半径 − 内半径
内半径 60 px 圆环内半径，最小 0 px。要找的圆周应落在内外半径之间
起始角 0° 圆弧起点，0° 为 +X，顺时针为正，范围 -360° ~ 360°
扫过角度 360° 圆弧扫过的角度，范围 1° ~ 360°。360 为整圆
搜索方向 由内向外 由内向外或由外向内，即卡尺的箭头方向；极性与取哪个都按这个方向看
Important

极性随搜索方向反转：同一个孔边，由内向外为暗到亮时，由外向内就是亮到暗。改了搜索方向要同时检查边缘极性

边缘

参数 默认值 说明
边缘极性 任意 沿搜索方向（箭头）看：暗到亮、亮到暗 或 任意
取哪个 第一个 每个卡尺有多个候选时取沿搜索方向的第一个、最后一个，或对比度最强的
最小对比度 20 边缘两侧灰度差的下限，低于它的边缘忽略，范围 1 ~ 65535。在剖面图上看对比度曲线的峰是否越过虚线
平滑 σ 1 px 剖面的高斯平滑，范围 0.5 ~ 20 px。越大越抗噪，但相邻的边缘也越难分开

卡尺与拟合

参数 默认值 说明
卡尺数量 24 在圆弧上均匀排布的卡尺个数，范围 3 ~ 360。越多越稳，耗时也越多
卡尺宽度 5 px 每个卡尺沿边缘方向取平均的宽度，范围 1 ~ 500 px。越宽越抗噪，但弯曲的边会变模糊
拟合容差 2 px 边缘点偏离拟合圆超过它就当离群点剔除，范围 0.1 ~ 100 px
最少内点数 3 参与拟合的边缘点少于它时视为没找到，范围 2 ~ 360

ROI 随动（节点卡片上，接了跟随定位才显示）

参数 默认值 说明
跟随旋转 勾选 取消则只跟随平移，用于定位结果没有可靠角度时（如圆定位）
Tip

跟随定位没有可靠角度时（如圆定位、Blob 分析）取消跟随旋转

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Found 是否找到圆
X / Y 圆心坐标（像素）
Radius 半径（像素）
Diameter 直径（像素）
Rms 内点到圆周距离的均方根（像素），可作圆度参考
Inliers 参与拟合的边缘点数
Points 找到边缘的卡尺数
Calipers 卡尺数

典型搭配

场景 链路
孔径检测 相机 → 卡尺找圆 → 数值判定
定位后精测 相机 → 形状匹配 → 卡尺找圆（跟随定位）→ 数值判定
孔到边距离 卡尺找圆 + 卡尺找线 → 点线距离
