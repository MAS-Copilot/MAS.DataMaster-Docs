Blob 分析

查找连通区域，按面积、圆度过滤，输出质心与角度

端口

方向 名称 类型 说明
输入 图像 图像 二值图或灰度图
输出 图像 图像 输入原图直通，供下游算法使用
输出 定位 定位 排序后的第一个区域（质心与最小外接矩形角度）
输出 定位列表 定位列表 全部区域，每个元素带面积、宽高与圆度
输出 标注图 标注图 叠加各区域与数量，仅供查看
Warning

没有区域通过时不输出定位，节点显示警告，下游节点因缺少输入而报错；定位列表输出空列表

Tip

节点内部固定用大津法自动二值化，输入已是二值图时结果不变。光照不均或需要固定阈值时，上游先接阈值二值化

Tip

角度取自最小外接矩形，不能当可靠的方向使用；接 ROI 选择器随动时取消「跟随旋转」

参数

参数 默认值 说明
找暗目标 不勾选 目标比背景暗时打开，例如亮色工件上的孔
最小面积 100 小于该面积的区域被过滤，单位为像素²
最大面积 0 0 表示不限，单位为像素²
最小圆度 0 范围 0 ~ 1，正圆为 1，调高后只保留接近圆形的区域
排序 面积从大到小 另有从左到右、从上到下
最多数量 50 按排序最多保留的区域数，范围 1 ~ 500，在设置窗口中修改
排除贴边区域 启用 外接框碰到图像边缘的区域被过滤，在设置窗口中修改
Tip

只统计每个连通区域的外轮廓，区域内部的孔不单独计数；需要取孔或更多筛选条件时用轮廓分析

参数访问

参数名 含义 类型 范围 / 可选值 访问
IsDarkBlob 找暗目标 bool true / false Get/Set
MinArea 最小面积 double ≥ 0 px²（有限数值） Get/Set
MaxArea 最大面积 double ≥ 0 px²（有限数值） Get/Set
MinCircularity 最小圆度 double 0～1（有限数值） Get/Set
Sort 排序 枚举 AreaDescending、LeftToRight、TopToBottom Get/Set
MaxCount 最多数量 int 1～500 Get/Set
IsExcludeBorder 排除贴边区域 bool true / false Get/Set

连续运行时可在两轮之间修改，执行中返回失败需重试。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Count 区域数量
X / Y 第一个区域的质心坐标（像素）
Area 第一个区域的面积（像素²）
Angle 第一个区域最小外接矩形的角度（度）
Circularity 第一个区域的圆度（正圆为 1）
Items 全部区域

典型搭配

场景 链路
定位孔位 滤波去噪 → 阈值二值化 → 形态学 → Blob 分析（最小圆度 0.8）
龙门打螺丝 / 点胶 阈值二值化 → Blob 分析 → 列表筛选 → 像素转机械坐标 → 列表排序 → 计数判定
