颜色识别

统计 HSV 范围内的像素，按数量或占比判定有无指定颜色

端口

方向 名称 类型 说明
输入 图像 图像 HSV 图像，上游接颜色空间转换（BGR to HSV）
输出 图像 图像 输入原图直通，供下游算法使用
输出 标注图 标注图 叠加像素数与占比，仅供查看
Important

输入必须是 HSV 图像。直接接相机的彩色图不会报错，但统计结果没有意义

使用

  1. 上游接颜色空间转换（BGR to HSV），需要只统计局部时再接 ROI 选择器裁出目标区域
  2. 运行一次，让节点拿到一帧输入
  3. 在卡片上选颜色预设；或点颜色预设旁的提取按钮（提示「从当前缓存输入图像自动提取 HSV 颜色范围」），按当前输入自动生成范围并切到自定义
  4. 选自定义时可拖动 H / S / V 的上下限微调
  5. 打开设置窗口，在先决条件里选 像素量 或 像素百分比，填写对应阈值
Important

新建节点的自定义范围全为 0，只会统计纯黑像素。使用前先选预设或从输入提取

Note

提取在管道运行中点击时，改为在下一帧上执行；调试时未运行过上游会提示「请先运行上游节点获取输入图像」

Tip

自动提取按整幅输入图统计，图中混有背景时范围会被拉宽。先用 ROI 选择器裁到只含目标颜色

参数

参数 默认值 说明
颜色预设 自定义HSV颜色空间 内置黑、灰、白、红、橙、棕、黄、绿、青、蓝、紫、粉与红色 (High) 预设。选预设时 H / S / V 不可编辑
H min / H max 0 / 0 色调范围，0 ~ 180
S min / S max 0 / 0 饱和度范围，0 ~ 255
V min / V max 0 / 0 亮度范围，0 ~ 255
先决条件 像素量 像素量 按范围内像素数判定，像素百分比 按其占整幅图的比例判定
像素量阈值 5201314 范围内像素数超过该值即检测到，单位 px
像素百分比阈值 20 范围内像素占比超过该值即检测到，范围 0.1 ~ 100，单位 %
Tip

红色的色调跨 0 与 180 两端，一个范围只覆盖一端，按实际颜色选 红色 - 预设 | 色调范围 (0-10) 或 红色 (High) - 预设 | 色调范围 (160-180)

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
IsDetected 是否检测到指定颜色。未检测到时节点不报警告，管道照常继续
DetectedPixels 范围内的像素数
TotalPixels 总像素数
DetectedPercentage 范围内像素占比（%）
ThresholdMode 判定方式，Pixels 或 Percentage
PixelThreshold 像素量阈值（按像素量判定时）
PercentageThreshold 像素百分比阈值（按像素百分比判定时）
LowerHsv / UpperHsv HSV 下限 / 上限
ImageWidth / ImageHeight 输入图像尺寸（像素）
ElapsedMs 耗时（毫秒）

典型搭配

场景 链路
颜色有无 / 错料 相机 → 颜色空间转换 → ROI 选择器 → 颜色识别，脚本读 IsDetected
