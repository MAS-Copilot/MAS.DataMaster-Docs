直线定位

查找图中最明显的直边，亚像素拟合

端口

方向 名称 类型 说明
输入 图像 图像 待搜索的图像
输出 图像 图像 输入原图直通，供下游算法使用
输出 定位 定位 直线的中点与角度，可当直线接几何测量节点
输出 标注图 标注图 叠加直线、角度与长度，仅供查看
Warning

未找到直线时不输出定位，节点显示警告，下游节点因缺少输入而报错

Note

角度表示直线方向，不分首尾，45° 与 -135° 视为同一方向

参数

参数 默认值 说明
期望角度 0° 要找的边的大致角度，范围 -90° ~ 90°。0 为水平，顺时针为正
角度容差 90° 只考虑与期望角度相差在此范围内的直线，范围 0° ~ 90°。90 表示不限方向
最短长度 100 px 短于它的线段不参与，范围 10 ~ 5000 px
低阈值 50 边缘检测的低阈值，范围 0 ~ 1000。介于高低阈值之间的点只在与边缘相连时保留
高阈值 150 边缘检测的高阈值，范围 0 ~ 1000。高于它的点直接判为边缘

低阈值、高阈值在设置窗口中调整，其余参数在节点卡片上

Note

边上有较大缺口时会被分成几段，每段都要达到最短长度才参与

Tip

只输出一条直线：满足角度条件的候选中最长的一条。图中有多条边时，用期望角度与角度容差排除其它方向的边，或先用 ROI 选择器缩小范围

Tip

需要量尺寸、按极性取边时改用卡尺找线

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Found 是否找到直线
X1 / Y1 起点坐标（像素）
X2 / Y2 终点坐标（像素）
CenterX / CenterY 中点坐标（像素）
Angle 角度（度，-90 ~ 90，顺时针为正）
Length 长度（像素）
Inliers 参与拟合的边缘点数

典型搭配

场景 链路
定位边缘 相机 → 滤波去噪 → 直线定位
定位后精测 相机 → 直线定位 → 定位转正 → 卡尺
