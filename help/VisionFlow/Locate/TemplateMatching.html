模板匹配

在源图像中查找模板图像，按相似度判定是否匹配，只处理平移

Tip

只搜索平移，目标有旋转或缩放时得分明显下降。需要角度时改用形状匹配或特征匹配

端口

方向 名称 类型 说明
输入 源图像 图像 待搜索的图像，须为 8 位灰度图
输入 模板图像 图像 要查找的模板，须为 8 位灰度图
输出 图像 图像 源图像直通，供下游算法使用
输出 标注图 标注图 叠加匹配区域与最佳值，仅供查看
Important

两路输入都必须是 8 位灰度图，彩色图会报错「图像类型必须是灰度图像」。相机出图为彩色时先接颜色空间转换（BGR to Gray）

Note

未匹配时节点不报警告，管道照常继续，按 IsMatched 判定结果

参数

参数 默认值 说明
相似度 0.85 判定阈值，范围 0 ~ 1。平方差类方式最佳值不大于它即匹配，其余方式最佳值不小于它即匹配
匹配方式 归一化相关系数 (CCoeffNormed) 可选平方差、相关、相关系数及各自的归一化方式。归一化方式的值在 0 ~ 1 之间，与相似度可比
Warning

非归一化方式的匹配值不在 0 ~ 1 之间，相似度无法给出有效判定，一般使用归一化方式

参数访问

参数名 含义 类型 范围 / 可选值 访问
MatchingValue 相似度 double 0～1（有限数值） Get/Set
MatchMode 匹配方式 枚举 SqDiff、SqDiffNormed、CCorr、CCorrNormed、CCoeff、CCoeffNormed Get/Set

连续运行时可在两轮之间修改，执行中返回失败需重试。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
IsMatched 是否匹配成功
MatchMode 匹配方式
Threshold 判定使用的相似度
BestValue 最佳匹配值，用于判定
MinValue / MaxValue 匹配结果图中的最小值 / 最大值
BestX / BestY 最佳匹配区域左上角坐标（像素）
TemplateWidth / TemplateHeight 模板尺寸（像素）
SourceWidth / SourceHeight 源图像尺寸（像素）
ElapsedMs 匹配耗时（毫秒）
Summary 摘要信息
Note

BestX / BestY 是匹配区域左上角，不是中心

典型搭配

场景 链路
有无判定 相机 → 颜色空间转换 → 模板匹配（模板图像接图像源），脚本读 IsMatched
