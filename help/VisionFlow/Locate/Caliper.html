卡尺

在旋转矩形搜索区内沿箭头方向找边缘或边缘对（宽度、间隙），亚像素

端口

方向 名称 类型 说明
输入 图像 图像 待测量的图像
输入 跟随定位 定位 可选。接上并设跟随基准后，搜索区随工件平移、旋转
输出 图像 图像 输入原图直通，供下游算法使用
输出 定位 定位 找边时为选中的边缘，角度为边缘走向，可当直线用；边缘对时为选中边缘对的中点
输出 定位列表 定位列表 全部边缘；边缘对模式为全部边缘对
输出 测量值 数值 找边时为离搜索起点的距离，边缘对时为宽度（像素）
输出 标注图 标注图 叠加搜索区、边缘点与结果，仅供查看
Warning

未找到时不输出定位与测量值，节点显示警告，下游节点因缺少输入而报错

使用

  1. 上游接好相机或图像源，运行一次，让设置窗口拿到一帧图像
  2. 打开设置窗口，在图上拖动、旋转搜索区，使箭头横跨要找的边。箭头为搜索方向，要找的边与箭头垂直；也可在搜索区分组里直接输入数值
  3. 在边缘分组选择模式与边缘极性；量宽度、间隙时选边缘对，再设第二边缘极性
  4. 按 F5 或标题栏的运行按钮运行到此节点。图上绿色十字为选中的边缘，橙色斜十字为未选中的边缘；边缘对模式下两个边缘点之间的连线即量到的宽度
  5. 对照下方剖面图调整最小对比度与平滑 σ：上半为沿搜索方向的平均灰度，下半为对比度曲线，灰色虚线为 ± 最小对比度，左端为搜索起点；橙色虚竖线为找到的边缘，绿色竖线为选中的结果。要找的边的峰越过虚线才会被找到
  6. 工件位置会变时，把上游定位接到跟随定位；工件在示教位置运行一次后，在节点卡片上点 设为跟随基准，之后搜索区随定位平移、旋转。点旁边的删除按钮（清除跟随基准）恢复固定搜索区
Warning

接了跟随定位但未设基准时，节点显示警告「尚未设跟随基准，ROI 固定不动」；设了基准后上游本次没有结果，管道失败，不在错误的位置测量

Note

跟随时设置窗口里的画面映射回示教姿态，与搜索区对齐

参数

搜索区

参数 默认值 说明
中心 X / 中心 Y 200 / 200 搜索区中心（像素）
搜索长度 160 px 沿箭头方向的长度，最小 3 px
投影宽度 30 px 垂直于箭头方向取平均的宽度，最小 1 px。越宽越抗噪，但要找的边要与箭头垂直
搜索角度 0° 箭头方向，0° 为 +X，顺时针为正
Tip

投影宽度越宽越抗噪，但要求边与箭头垂直；边倾斜时，加宽投影宽度会让边缘变模糊

边缘

参数 默认值 说明
模式 找边 找边取单个边缘；边缘对按两个极性配对，量亮带宽度选暗到亮 + 亮到暗，量暗缝选亮到暗 + 暗到亮，台阶选两个同极性
边缘极性 任意 沿搜索方向（箭头）看：暗到亮、亮到暗 或 任意。边缘对模式下为第一个边缘
第二边缘极性 任意 边缘对中第二个边缘的极性，仅边缘对模式
期望宽度 0 px 仅边缘对模式。0 表示不限，取紧随第一个边缘之后符合极性的边缘；设了之后只取宽度在容差内的边缘对
宽度容差 5 px 仅边缘对模式，设了期望宽度时生效
取哪个 第一个 有多个候选时取沿搜索方向的第一个、最后一个，或对比度最强的
最小对比度 20 边缘两侧灰度差的下限，低于它的边缘忽略，范围 1 ~ 65535。在剖面图上看对比度曲线的峰是否越过虚线
平滑 σ 1 px 剖面的高斯平滑，范围 0.5 ~ 20 px。越大越抗噪，但相邻的边缘也越难分开

ROI 随动（节点卡片上，接了跟随定位才显示）

参数 默认值 说明
跟随旋转 勾选 取消则只跟随平移，用于定位结果没有可靠角度时（如圆定位）
Tip

跟随定位没有可靠角度时（如圆定位、Blob 分析）取消跟随旋转

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Found 是否找到
Count 找到的边缘数（边缘对模式为边缘对数）
X / Y 结果坐标（像素；边缘对为中点）
Angle 边缘走向（度，与搜索方向垂直）
Position 离搜索起点的距离（像素；边缘对为第一个边缘）
Width 边缘对宽度（像素）
Contrast 对比度。找边时正为暗到亮、负为亮到暗；边缘对为较弱一侧的强度
Measurement 测量值输出：边缘对为宽度，找边为离搜索起点的距离

典型搭配

场景 链路
宽度 / 间隙检测 相机 → 卡尺（边缘对）→ 数值判定
定位后精测 相机 → 形状匹配 → 卡尺（跟随定位）→ 数值判定
孔到边距离 卡尺（找边）+ 卡尺找圆 → 点线距离
