形状匹配

用产品自身的轮廓定位。基于边缘梯度方向建模，抗旋转、亚像素，可同时找多个目标

端口

方向 名称 类型 说明
输入 图像 图像 待搜索的图像
输出 图像 图像 输入原图直通，供下游算法使用
输出 定位 定位 得分最高的目标
输出 定位列表 定位列表 全部目标，按得分从高到低
输出 标注图 标注图 叠加目标轮廓与参考点，仅供查看
Warning

未找到目标时不输出定位，节点显示警告，下游节点因缺少输入而报错

使用

  1. 上游接好相机或图像源，运行一次，让设置窗口拿到一帧标准产品图
  2. 打开设置窗口，切到模板区，在图上框出产品上轮廓清晰、不会变化的部分
  3. 点 学习模板。模板图随工程保存，不依赖外部文件
  4. 需要输出特定位置时，切到参考点在图上点选；参考点可以在模板区外，点 居中 恢复为模板中心
  5. 切到搜索区，框出目标可能出现的范围
  6. 运行，在结果表里查看坐标、角度与得分，按需调整搜索参数
Tip

模板应选轮廓稳定、特征不对称的区域；圆形等旋转对称的模板无法给出可靠角度

Note

学习后再改模板区，界面会提示「模板区已改，点「学习模板」生效」，在重新学习之前仍使用旧模板。搜索区限定的是模板中心的位置，不是整个目标的范围

参数

模板

参数 默认值 说明
边缘对比度 30 学习模板时取边缘点的灰度差下限，范围 1 ~ 255。修改后按已保存的模板图重建，无需重新取图
金字塔层数 0 0 为自动，范围 0 ~ 6。层数多搜索更快，但小特征可能丢失
参考点 X / Y 模板中心 定位结果输出的点，单位为示教图像素

搜索

参数 默认值 说明
最低得分 0.7 低于该值不算找到，范围 0.3 ~ 1。常有遮挡时适当调低
角度下限 / 角度上限 -30° / 30° 相对模板的旋转范围，顺时针为正；上下限相等即不旋转。范围越大越慢
最多数量 1 最多输出的目标数，范围 1 ~ 100
最大重叠 0.5 两个目标重叠超过该比例时只保留得分高的
极性 同极性 背景时亮时暗、边缘明暗可能反转时选忽略极性
最小对比度 10 搜索时边缘两侧灰度差的下限，低于它的边缘被忽略
贪婪度 0.8 越大越快，但部分遮挡的目标更容易漏检

参数访问

参数名 含义 类型 范围 / 可选值 访问
MinScore 最低得分 double 0.3～1（有限数值） Get/Set
AngleMin 角度下限 double -180～180 °（有限数值） Get/Set
AngleMax 角度上限 double -180～180 °（有限数值） Get/Set
MaxCount 最多数量 int 1～100 Get/Set
MaxOverlap 最大重叠 double 0～1（有限数值） Get/Set
Polarity 极性 枚举 Same、Ignore Get/Set
MinContrast 最小对比度 double 1～255（有限数值） Get/Set
Greediness 贪婪度 double 0～1（有限数值） Get/Set

连续运行时可在两轮之间修改，执行中返回失败需重试。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Found 是否找到
Count 找到的目标数
X / Y 第一个目标参考点坐标（像素）
Angle 第一个目标相对模板的旋转角（度，顺时针为正）
Score 第一个目标的得分（0 ~ 1）
ModelPoints 模板第 0 层的边缘点数
Levels 金字塔层数
TopCandidates 金字塔顶层候选数
TimeMs 匹配耗时（毫秒）
Items 全部目标
Tip

TopCandidates 为 0 说明粗搜阶段就没有候选，可降低最低得分或最小对比度

典型搭配

场景 链路
二维引导 相机 → 形状匹配 → 像素转机械坐标 → 位置补正
定位后精测 相机 → 形状匹配 → 定位转正 → 卡尺 / 金样比对
ROI 随动 相机 → 形状匹配 → ROI 选择器（跟随定位）→ 后续检测
