边缘检测

Canny 边缘检测，输出二值边缘图

端口

方向 名称 类型 说明
输入 图像 图像 待处理的图像，彩色图先转灰度
输出 图像 图像 8 位单通道边缘图，边缘为 255，其余为 0

参数

参数 默认值 说明
低阈值 50 边缘强度阈值，范围 0 ~ 1000。介于高低阈值之间的点只在与边缘相连时保留
高阈值 150 边缘强度阈值，范围 0 ~ 1000。高于它的点直接判为边缘；小于低阈值时按低阈值处理
L2 梯度 禁用 在设置窗口中切换。梯度幅值更准确，略慢

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
EdgePixels 边缘像素数
