ChArUco 角点定位

按 ID 定位 ChArUco 标定板的内角点（亚像素），可作九点标定的 Mark

端口

方向 名称 类型 说明
输入 图像 图像 拍到标定板的图像
输出 图像 图像 输入原图直通，供下游算法使用
输出 定位 定位 目标角点的亚像素位置，角度为棋盘 X 方向
输出 标注图 标注图 叠加检出的角点并突出目标角点，仅供查看
Important

目标角点在相机移动过程中要始终在视野内，且旁边至少能看到 2 个码，否则该角点没有 ID，视为未找到

Warning

未找到时不输出定位，节点显示警告，下游节点因缺少输入而报错

Note

定位角度取目标角点与同一行相邻角点的连线方向（ID 增大方向）；同一行相邻角点都没检出时角度为 0

参数

参数 默认值 说明
字典类型 DICT_6X6_100 标定板所用的 ArUco 字典，须与实物一致
角点 ID 9 要输出的内角点。内角点从左上角起按行编号，每行（X 方向方格数 - 1）个，共（X - 1）×（Y - 1）个
棋盘沿 X 方向的方格数量 5 范围 2 ~ 99，在设置窗口中修改
棋盘沿 Y 方向的方格数量 7 范围 2 ~ 99，在设置窗口中修改
棋盘单个方格边长 20 范围 0.1 ~ 1000。只用方格与码的比例，单位不限，打印误差不影响定位
ArUco Marker 边长 14 范围 0.1 ~ 1000，必须小于方格边长
Important

字典类型与方格数必须与实物标定板一致

Warning

码边长不小于方格边长时节点报错

参数访问

参数名 含义 类型 范围 / 可选值 访问
Dictionary 字典类型 string ArUco 字典名，候选来自当前字典列表 Get/Set
SquaresX 棋盘沿 X 方向的方格数量 int 2～99 Get/Set
SquaresY 棋盘沿 Y 方向的方格数量 int 2～99 Get/Set
SquareLength 棋盘单个方格边长 double 0.1～1000 mm（有限数值） Get/Set
MarkerLength ArUco Marker 边长 double 0.1～1000 mm（有限数值） Get/Set
CornerId 角点 ID int 0～9999 Get/Set

连续运行时可在两轮之间修改，执行中返回失败需重试。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
IsFound 是否找到目标角点
CornerId 目标角点 ID
X / Y 目标角点坐标（像素，亚像素）
MarkerCount 检测到的 ArUco 码数量
CornerCount 检测到的内角点数量
Items 全部检出的角点

典型搭配

场景 链路
九点标定取 Mark 相机 → ChArUco 角点定位 → 2D 标定（九点），机器位姿接第二个输入
