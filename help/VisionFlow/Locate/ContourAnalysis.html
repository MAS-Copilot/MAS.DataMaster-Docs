轮廓分析

二值化后找轮廓，按面积、周长、圆度、凸度、矩形度、长宽比与参考形状筛选，按质心、外接矩形、椭圆或圆定位

端口

方向 名称 类型 说明
输入 图像 图像 灰度或彩色图像，彩色先转灰度
输出 图像 图像 输入原图直通，供下游算法使用
输出 定位 定位 排序后的第一个轮廓
输出 定位列表 定位列表 通过筛选的全部轮廓，每个元素带面积、宽高、半径与圆度
输出 标注图 标注图 叠加轮廓（未通过的另色显示）、定位几何与序号，仅供查看
Warning

没有通过的轮廓时不输出定位，节点显示警告，下游节点因缺少输入而报错；定位列表输出空列表

使用

  1. 上游接好相机或预处理节点，运行一次，设置窗口左侧显示图像与轮廓，下方为结果表
  2. 在二值化里调阈值、轮廓与找暗目标，直到目标轮廓完整
  3. 对照结果表的数值，在筛选里填各项下限 ~ 上限。图上通过的轮廓为绿色，未通过的为橙色，序号与结果表一致，结果列给出未通过的原因
  4. 只挑同一种形状时，在标准件上运行，让目标排在第一个，点 设为参考，再按需调整最大形状差异。参考形状随工程保存，点 清除 取消形状比较
  5. 在输出里选定位方式、排序与最多数量
Note

面积不到最小面积四分之一的轮廓按噪点直接跳过，不出现在结果表里。结果表的原因只列第一个不满足的条件；定位方式为拟合椭圆或拟合圆而拟合不成时，原因为「拟合失败」

Tip

结果表顶部显示「通过 N / 共 M 个轮廓 · 阈值 T」，阈值为本次实际使用的值，大津法自动时可据此改为固定阈值

参数

二值化

参数 默认值 说明
阈值 0 二值化阈值，范围 0 ~ 255，0 为大津法自动
轮廓 外轮廓 外轮廓 取每个目标区域的外边界，孔 取区域内部的孔边界（如板上的孔、垫圈内圈），全部 两者都取
找暗目标 不勾选 目标比背景暗时打开，例如亮色工件上的孔
排除贴边区域 勾选 外接框碰到图像边缘的轮廓不通过

筛选

每行为 下限 ~ 上限，0 为不限

参数 默认值 说明
面积 100 ~ 0 单位为像素²
周长 0 ~ 0 单位为像素
圆度 0 ~ 0 正圆为 1，调高下限只保留接近圆形的轮廓
长宽比 0 ~ 0 最小外接矩形 长边 ÷ 短边（≥ 1）
最小凸度 0 面积 ÷ 凸包面积，没有凹陷为 1
最小矩形度 0 面积 ÷ 最小外接矩形面积，矩形为 1

参考形状

参数 默认值 说明
最大形状差异 0.1 与参考形状的 Hu 矩差异上限，与位置、旋转、缩放无关。0 为完全相同，同一形状通常小于 0.05；设 0 不比较。未设参考形状时不生效
Tip

参考形状对圆、正方形这类高度对称的形状区分弱，挑这类形状改用圆度、矩形度

输出

参数 默认值 说明
定位方式 质心 每个轮廓的中心、角度与尺寸取自哪里：质心、最小外接矩形、拟合椭圆、拟合圆
排序 面积从大到小 另有从左到右、从上到下、最像的在前；最像的在前未设参考形状时按面积排序
最多数量 50 通过的轮廓按排序最多保留的个数，范围 1 ~ 500

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Count 通过筛选的轮廓数
Candidates 候选轮廓数（按轮廓设置过滤后，含噪点）
Threshold 实际使用的二值化阈值
X / Y 第一个轮廓的中心坐标（像素，按定位方式）
Angle 第一个轮廓的角度（度，-90 ~ 90）
Width / Height 第一个轮廓的宽 / 高（外接矩形长边 / 短边、椭圆长轴 / 短轴或圆直径）
Radius 第一个轮廓的拟合圆半径（定位方式为拟合圆时）
Area 第一个轮廓的面积（像素²）
Perimeter 第一个轮廓的周长（像素）
Circularity 第一个轮廓的圆度（正圆为 1）
Convexity 第一个轮廓的凸度
Rectangularity 第一个轮廓的矩形度
AspectRatio 第一个轮廓的长宽比
ShapeDistance 第一个轮廓与参考形状的差异（未设参考为 0）
Items 全部通过的轮廓
Tip

精度在像素量级，尺寸已补回半个像素（外轮廓 +1、孔 −1）；要亚像素尺寸用卡尺

典型搭配

场景 链路
按形状挑目标 相机 → 轮廓分析 → 列表筛选 / 计数判定
法兰分布圆 相机 → 轮廓分析（拟合圆）→ 点集拟合（圆，RANSAC）→ 数值判定
缺陷再筛 金样比对（缺陷区域输出）→ 轮廓分析
