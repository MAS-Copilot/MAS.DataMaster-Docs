特征匹配

用特征点定位模板，可应对旋转和缩放，输出模板中心的位置与旋转角

端口

方向 名称 类型 说明
输入 图像 图像 待搜索的图像
输入 模板 图像 要查找的模板图像
输出 图像 图像 输入原图直通，供下游算法使用
输出 定位 定位 模板中心在图像中的位置与旋转角
输出 标注图 标注图 叠加模板四角映射出的区域与中心，仅供查看
Important

模板需要有足够的纹理与角点。纯色面、光滑轮廓提取不到足够特征，改用形状匹配

Warning

未找到目标时不输出定位，节点显示警告，下游节点因缺少输入而报错

Note

换算出的缩放超出 0.2 ~ 5 倍，或模板四角映射后不是凸四边形时，同样视为未找到

参数

参数 默认值 说明
匹配比值 0.75 比值检验阈值，范围 0.5 ~ 0.95。越小越严格，常用 0.7 ~ 0.8
最少内点数 12 几何一致的匹配少于此数视为未找到，范围 4 ~ 500
特征点数量 1000 模板与输入图各自最多提取的特征点数，范围 100 ~ 5000，在设置窗口中修改

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Found 是否找到
X / Y 模板中心坐标（像素）
Angle 相对模板的旋转角（度，顺时针为正）
Scale 相对模板的缩放
Inliers 几何一致的匹配数（内点数）
GoodMatches 通过比值检验的匹配数
Tip

GoodMatches 很少时可调大匹配比值或特征点数量；GoodMatches 足够而 Inliers 不足说明误匹配多

典型搭配

场景 链路
单 Mark 补正 相机 → 特征匹配 → 像素转机械坐标 → 位置补正
定位后精测 相机 → 特征匹配 → 定位转正（裁剪）→ 卡尺 → 坐标映射
