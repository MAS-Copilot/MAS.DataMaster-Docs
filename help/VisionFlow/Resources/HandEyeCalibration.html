手眼标定

成对采集相机与机器位姿，求手眼关系

端口

方向 名称 类型 说明
输入 相机位姿 姿态结果 姿态解算输出的标定板位姿
输入 机器位姿 位姿 拍照时的机器人位姿
Note

姿态解算失败或缺少机器位姿时，本次不采样

使用

  1. 连线：相机 → 姿态解算 → 相机位姿输入；机器位姿 → 机器位姿输入。姿态解算须使用相机标定的内参
  2. 在卡片或设置窗口选择标定模式
  3. 机器人带着相机（眼在手上）或标定板（眼在手外）移动到不同位置与姿态，每到一处触发执行一次，记一组样本，卡片显示采样进度。位姿可用位姿生成节点按下位机请求给出
  4. 样本数达到最少样本数后开始计算并写入资源，之后每个新样本都会重新计算
  5. 需要重新标定时点卡片上的 重置

标定结果写入资源 键前缀-标定模式，默认 RigidTransform3D-EyeInHand，供手眼坐标转换引用；资源随工程保存

Warning

样本不随工程保存，也不会自动停止：重新打开工程后再运行会从头采集，并在达到最少样本数后覆盖原有资源。标定完成后不要再触发本节点

参数

基本设置

参数 默认值 说明
稳定窗口数量 1 上游模块连续输出 N 次后，仅使用第 N 次结果参与标定采样，用于等待滤波或姿态收敛完成，范围 1 ~ 99

手眼标定配置

参数 默认值 说明
标定模式 EyeInHand EyeInHand 为眼在手上（相机装在机器人末端），EyeToHand 为眼在手外（相机固定）
最少样本数 15 达到该数量后开始计算，范围 5 ~ 999
最大样本数 50 只用最近的这么多个样本计算，范围 5 ~ 999
标定算法 两步法手眼标定算法 可选自动选择最优算法、对偶四元数手眼标定算法、正交矩阵分解手眼标定算法、改进型解耦手眼标定算法、单位四元数手眼标定算法。只在眼在手上时可选，眼在手外时不使用
Warning

修改任一手眼标定配置都会清空已采集的样本

检测与质量

参数 默认值 说明
Auto模式下平移误差评分权重 1 自动选择算法时平移误差的评分权重，范围 0 ~ 100
Auto模式下旋转误差评分权重 10 自动选择算法时旋转误差的评分权重，范围 0 ~ 100
最小旋转激励跨度（deg） 10 样本间的旋转跨度低于该值时标定失败，提示增加多方向转动样本，范围 1 ~ 180
最小平移激励跨度（mm） 20 样本间的平移跨度低于该值时标定失败，提示增加跨范围移动样本，范围 1 ~ 2000
启用异常样本剔除 勾选 按残差剔除异常样本
异常样本剔除的最大平移残差阈值（mm） 2 范围 0.1 ~ 50
样本剔除的最大旋转残差阈值（deg） 0.5 范围 0.1 ~ 10

资源设置

参数 默认值 说明
键前缀 RigidTransform3D 资源键为「键前缀-标定模式」
最后一次生成的键 — 只读，显示最近写入的资源键
Important

手眼坐标转换的手眼模式须与这里的标定模式一致，其资源键填写本节点「最后一次生成的键」

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
IsCalibrated 是否已完成标定
ResourceKey 标定结果资源键
SampleCount 已采样本数
Summary 标定摘要，含使用的样本数与平移、旋转残差

典型搭配

场景 链路
手眼标定 相机 → 姿态解算 → 手眼标定（接机器位姿）
标定后引导 相机 → 姿态解算 → 手眼坐标转换
