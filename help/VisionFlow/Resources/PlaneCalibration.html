2D 标定（九点）

龙门/XY 平台用：采集 Mark 像素与轴位置，求像素到机械坐标的映射（九点标定）

端口

方向 名称 类型 说明
输入 定位 定位 Mark 的定位结果（圆定位、模板匹配等）
输入 机器位姿 位姿 拍照时的轴位置

使用

  1. 连线：Mark 定位 → 定位输入；机器位姿 → 机器位姿输入。有相机内参时在设置窗口选择畸变校正内参
  2. 选择相机安装方式与映射模型
  3. 在台面放一个 Mark（与工件同高），点 开始采样，让龙门按 3×3 网格逐点移动并触发执行。每次执行记一个样本，采满目标样本数后自动计算并停止采样
  4. 在样本表里看残差：一般应在 1 ~ 2 个像素当量以内。个别偏大的用 删除最后一个样本 或 清空样本 后重采，再点 立即计算
  5. 示教针尖偏置（相机随轴运动时必需）：拍到 Mark 后点 ① 记录拍照位；把针尖点动到同一个 Mark 正上方，单独运行一次机器位姿节点读取当前轴位置，再点 ② 记录针尖位置
  6. 之后用像素转机械坐标、点图移动引用标定结果

标定结果写入资源（默认 PlaneCalibration），随工程保存

Note

只在轴位置与上一个样本不同时才记新样本；Mark 定位或轴位置缺失的那次执行不采样

参数

参数 默认值 说明
相机安装方式 相机随轴运动（装在机头上） 随轴运动：拍台面上固定不动的 Mark；相机固定：拍机头带着走的 Mark
映射模型 仿射（相机垂直，推荐） 相机基本垂直于工作面用仿射（至少 3 点，最稳定）；明显倾斜用单应性（相机倾斜）（至少 4 点）
目标样本数 9 采满后自动计算并停止采样，范围 3 ~ 100。推荐 9 点（3×3 网格），网格尽量覆盖实际使用的视野范围
畸变校正内参 空 选择相机标定生成的内参资源后，像素坐标先做畸变校正再换算；留空表示不校正
资源键 PlaneCalibration 标定结果写入的资源键
针尖偏置 X / 针尖偏置 Y 0 相机看到的位置到针尖（螺丝批头）的偏置。示教后自动填入，手动填写也立即生效
Important

重新标定后针尖偏置数值保留但失效，须重新示教，否则提示「未示教针尖偏置，坐标只有相对意义」

Warning

上游已有畸变校正节点时须清空畸变校正内参，否则 Mark 坐标会被重复校正，计算直接失败

参数访问

参数名 含义 类型 范围 / 可选值 访问
Mounting 相机安装方式 枚举 OnMovingAxis、Fixed Get
Model 映射模型 枚举 Affine、Homography Get
TargetSampleCount 目标样本数 int 3～100 Get
IntrinsicsKey 畸变校正内参 string 相机内参资源键，候选来自当前工程资源 Get
ResourceKey 资源键 string 文本，无额外长度限制 Get
ToolOffsetX 针尖偏置 X double 有限数值，无额外上下限 Get
ToolOffsetY 针尖偏置 Y double 有限数值，无额外上下限 Get

Set 不开放，请用专用设置界面修改。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
IsCalibrated 是否已完成标定
ResourceKey 标定结果资源键
SampleCount 已采样本数
MeanError / MaxError 平均 / 最大残差（机械单位）
PixelSize 像素当量（机械单位/像素）
Rotation 图像 X 方向在机械坐标系里的角度（度）
Skew 非正交角（度）
ToolOffsetX / ToolOffsetY 针尖偏置
IsToolOffsetTaught 是否已示教针尖偏置
CameraOffsetX / CameraOffsetY 相机偏移（拍照位 = 针尖坐标 − 相机偏移）
IsCameraOffsetTaught 相机偏移是否有效
Summary 标定摘要

典型搭配

场景 链路
九点标定 相机 → 圆定位 → 2D 标定（九点）（接机器位姿）
标定后引导 相机 → Blob 分析 → 像素转机械坐标（引用标定资源）
