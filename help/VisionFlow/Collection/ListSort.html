列表排序

按行/列（可蛇形）、按属性或按到参考点的距离排序，决定逐个处理的顺序

端口

方向 名称 类型 说明
输入 定位列表 定位列表 待排序的目标；单个定位也可直接接入
输出 定位列表 定位列表 排序后的目标

参数

参数 默认值 说明
排序 按行（逐行从左到右） 见下方排序方式
行/列容差 20 按行、按列及蛇形时显示。坐标差不超过该值的目标归为同一行（列），单位同坐标
排序属性 得分 按属性值时显示，从小到大排列
参考点 X / Y 0 / 0 按到参考点的距离时显示，从近到远排列
整体反向 不勾选 把排序结果整体倒过来，例如从最后一行开始

排序方式

选项 说明
按行（逐行从左到右） Y 相近的归为一行，行按 Y 从小到大，行内按 X 从小到大
行蛇形（走位最短） 同按行，第 2、4、6…… 行反向，相邻目标首尾相接
按列（逐列从上到下） X 相近的归为一列，列按 X 从小到大，列内按 Y 从小到大
列蛇形 同按列，第 2、4、6…… 列反向
按属性值 按排序属性从小到大
按到参考点的距离 按到参考点的距离从近到远
Note

换算成机械坐标后再排序，顺序就按机械坐标走；容差与参考点也按机械坐标填写

Tip

行/列容差要大于同一行的高低差、小于行距；过大会把相邻两行并成一行

Tip

按属性值固定从小到大，要按得分从高到低等降序排列时勾选整体反向

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Count 个数
Items 排序后的目标

典型搭配

场景 链路
孔阵列逐个处理 Blob 分析 → 列表筛选 → 像素转机械坐标 → 列表排序 → 计数判定
取最大的目标 轮廓分析 → 列表排序（按属性值：面积，整体反向）→ 取元素
