列表筛选

按面积、圆度、坐标等属性范围保留目标，可只保留前 N 个

端口

方向 名称 类型 说明
输入 定位列表 定位列表 待筛选的目标；单个定位也可直接接入
输出 定位列表 定位列表 保留的目标，保持输入顺序
Note

筛完为空时输出空列表，不报错。个数是否合格交给计数判定

参数

参数 默认值 说明
筛选属性 面积 按哪个属性筛选：X、Y、角度、得分、面积、半径、宽度、高度、圆度、类别序号
下限（含） 勾选，0 勾选后属性值小于下限的剔除；不勾选则不限下限
上限（含） 不勾选，0 勾选后属性值大于上限的剔除；不勾选则不限上限
最多保留个数 0 筛选后只保留前 N 个（按输入顺序），0 表示不限
Warning

上游没有给出的属性按 0 计（类别序号为 -1），下限设为大于 0 时会把它们全部剔除

Tip

最多保留个数按输入顺序取前 N 个。要保留得分最高或最大的几个，先接列表排序

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
InputCount 输入个数
Count 保留个数
RejectedCount 剔除个数
Items 保留的目标

典型搭配

场景 链路
按形状挑目标 相机 → 轮廓分析 → 列表筛选 → 计数判定
龙门打螺丝 阈值二值化 → Blob 分析 → 列表筛选 → 像素转机械坐标 → 列表排序 → 计数判定
