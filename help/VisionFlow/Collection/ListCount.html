计数判定

检查目标个数是否在范围内（如一块板应有 24 个孔），列表原样输出

端口

方向 名称 类型 说明
输入 定位列表 定位列表 待计数的目标；单个定位也可直接接入
输出 定位列表 定位列表 输入列表原样输出

参数

参数 默认值 说明
最少数量 1 个数少于它判不合格
最多数量 0 个数多于它判不合格，0 表示不限
不合格时中止 开启 个数不在范围内时管道失败，后面的换算与下发都不执行；关闭则只提示警告并继续
Warning

默认开启中止，与数值判定的默认相反。只想记录数量、不想因此停止管道时关闭它，在管道脚本里按 IsOk 处理

参数访问

参数名 含义 类型 范围 / 可选值 访问
MinCount 最少数量 int 0～2147483647 Get/Set
MaxCount 最多数量 int 0～2147483647；0 表示不限 Get/Set
IsAbortOnFailure 不合格时中止 bool true / false Get/Set

连续运行时可在两轮之间修改，执行中返回失败需重试。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Count 个数
IsOk 个数是否在范围内

场景 链路
