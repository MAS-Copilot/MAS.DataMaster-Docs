列表合并

把最多 4 路列表或单个结果按输入顺序合成一个列表

端口

方向 名称 类型 说明
输入 列表 1 定位列表 第一路，单个定位也可直接接入
输入 列表 2 定位列表 第二路
输入 列表 3 定位列表 第三路
输入 列表 4 定位列表 第四路
输出 定位列表 定位列表 按列表 1 ~ 4 的顺序首尾相接
Warning

任一路上游被条件执行跳过时，本节点也随之跳过。不同工位分支的结果不要汇到同一个合并节点

Note

没接线或本次没有数据的输入直接跳过，不报错

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Count 合并后的个数
Items 合并后的目标

典型搭配

场景 链路
多段边拟合 卡尺找线 ×N → 列表合并 → 点集拟合（直线 / 圆）
多 ROI 汇总 ROI 选择器 ×N → 定位 → 坐标映射 → 列表合并 → 列表排序
