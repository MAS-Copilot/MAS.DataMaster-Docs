取元素

从列表中取第 N 个，接到只收单个定位结果的节点

端口

方向 名称 类型 说明
输入 定位列表 定位列表 来源列表
输出 定位 定位 取出的目标
Note

列表不能直接连到只收单个定位的输入，取哪一个必须在这里明确；反过来单个定位可以直接连列表输入

参数

参数 默认值 说明
序号 1 从 1 开始；负数从末尾数，-1 为最后一个
Warning

序号为 0 或超出列表个数时，节点显示警告「序号 N 超出范围（共 M 个）」且不输出，下游因缺少输入而报错

参数访问

参数名 含义 类型 范围 / 可选值 访问
Index 序号 int -2147483648～2147483647；从 0 开始 Get/Set

连续运行时可在两轮之间修改，执行中返回失败需重试。调用方式与限制

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Count 列表个数
IsFound 序号是否有效
X / Y 所取目标的坐标
Angle 所取目标的角度（度）
Score 所取目标的得分

典型搭配

场景 链路
孔距 圆定位 → 列表排序 → 取元素 ×2 → 两点距离
取最大的目标 轮廓分析 → 列表排序 → 取元素 → 定位转正
