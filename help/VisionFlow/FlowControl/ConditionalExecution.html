条件执行

变量等于放行值时透传，否则本节点与下游全部跳过

端口

方向 名称 类型 说明
输入 图像 图像 要按条件放行的图像，通常接相机等共享节点
输出 图像 图像 放行时输入原图原样输出；未放行时不输出

使用

  1. 在「更多 → 变量配置」中添加条件变量，例如整数变量 Station
  2. 每个分支在共享节点之后接一个条件执行，分支内的节点都接在它的下游
  3. 打开设置窗口，在执行条件中选择条件变量，填写放行值。卡片显示条件摘要，如 Station = 3
  4. 管道脚本在触发时写变量，例如工位 1 到位时写 Station = 1
  5. 选中条件执行节点时，画布用外框标出受它控制的下游节点，据此检查分支是否接全
Warning

条件未配置完整时，设置窗口提示「条件未配置完整，运行时会失败」，卡片上的摘要显示为红色

Note

下游节点只要有一路输入来自被跳过的节点就一并跳过；只接共享节点的节点每次都执行

参数

参数 默认值 说明
条件变量 未选择 只列出整数、Bool、String 变量。按变量标识引用，变量改名不影响
放行值 空 变量等于该值时执行下游。整数按数值比较，Bool 填 true / false（也可填 1 / 0），字符串区分大小写
Warning

未选择变量、变量已删除、变量类型不支持或放行值无效时运行失败，不会按跳过处理。除 String 外放行值不能为空

Note

String 的放行值前后空格也参与比较

Note

变量取管道开始执行那一刻的快照，执行途中脚本再改变量不影响本轮。处理结果时从运行结果的 Variables 读本轮的值，不要读变量的当前值

输出结果

管道脚本按「节点标题 + 结果键」取值，标题与键都不区分大小写；运行后也可在输出查看窗口的「结果数据」页查看

结果键 说明
Passed 本轮是否放行。未放行时节点被跳过，取不到任何结果
Variable 条件变量名称
Value 本轮快照里的变量值
ReleaseValue 放行值
Note

跳过不算失败，管道照常完成。被跳过的节点显示跳过原因，不保留上一次的输出，脚本取不到它们的结果；运行结果的 SkippedNodes 列出本轮跳过的节点

典型搭配

场景 链路
一台相机多个工位 相机 → 条件执行（Station = 1）→ 工位 1 的节点；相机 → 条件执行（Station = 2）→ 工位 2 的节点
