Remarks

采样：打开「采样」后每次执行（Mark 定位 + 轴位置都有效、且轴位置与上一个样本不同）记一个样本，达到目标数自动计算并停止采样； 轴可以由下位机程序走 3×3 网格并逐点触发，也可以手动点动后单次运行

针尖偏置（相机随轴时必需）：① 拍到 Mark 后点「记录拍照位」；② 把针尖点动到同一个 Mark 上，运行一次读取轴位置后点「记录针尖位置」
