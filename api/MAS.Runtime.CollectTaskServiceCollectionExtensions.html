AddCollectTask<TData, TEntity, TMapper>(IServiceCollection, string, string, Action<HandshakeOptions>)

注册采集任务：下位机触发后读取数据结构体，映射为实体并写入数据库，保存成功后回写完成值

public static IServiceCollection AddCollectTask<TData, TEntity, TMapper>(this IServiceCollection services, string deviceName, string databaseName, Action<HandshakeOptions> configure) where TData : struct where TEntity : class, new() where TMapper : class, IDataMapper<TData, TEntity>

Parameters

services IServiceCollection

要添加服务的 IServiceCollection

deviceName string

设备名称，须已通过 AddPlc 注册

databaseName string

数据库名称，须已通过 AddDatabase 注册

configure Action<HandshakeOptions>

配置握手区地址和时间参数的委托

Returns

IServiceCollection

同一个 IServiceCollection，用于链式调用

Type Parameters

TData

PLC 数据结构体类型

TEntity

数据库实体类型

TMapper

结构体到实体的映射器类型，构造函数参数由依赖注入提供

Remarks

只用触发区、完成区和数据区，没有应答区。可恢复的写库失败或超时不回写完成值，按重试间隔重做同一触发值；唯一键重复等数据不合法的写库错误丢弃本条并照常回写； 映射器抛出 ReplyRejectedException 时数据不入库，记录警告并照常回写完成值。 数据结构体带 CRUD 操作位（IsCreate/IsUpdate/IsDelete/IsAddOrUpdate）时按位入库，更新、删除、插入或更新按实体唯一键定位；没有操作位时固定插入。 启动时会自动为 TEntity 建表
