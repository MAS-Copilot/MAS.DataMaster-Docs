Remarks

触发信号返回 true（或手动触发、运行到此节点）的那一刻：本轮的条件执行与节点都只读这份快照， 执行途中脚本再改变量不影响本轮。处理结果时请从 Variables 读本轮是哪个工位， 而不是读变量的当前值（可能已被下一轮改掉）
