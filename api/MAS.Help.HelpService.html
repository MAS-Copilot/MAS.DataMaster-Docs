Remarks

帮助窗口运行在独立的 STA UI 线程上：宿主主线程弹出 ShowDialog 模态窗口时， Win32 只禁用同线程的顶层窗口，帮助窗口不受影响，仍可滚动、跳转、查阅。 全局只保留一个帮助窗口，已打开时切换到新文档并激活。可在任意线程调用。
