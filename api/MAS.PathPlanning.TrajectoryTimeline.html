Remarks

段划分与 TrajectoryVelocityPlanner 一致：相邻两点一段，三点圆弧在中间点拆成两段。 每段的耗时与分析页剖面耗时逐段一致——前瞻启用时用点上的 Velocity/EndVelocity 与加减速参数， 未启用时按点上 Velocity 匀速。

姿态取首末点的 Rx/Ry/Rz（ZYX 欧拉角，单位度）按路程比例球面插值。
