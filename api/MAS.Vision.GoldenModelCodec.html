Remarks

均值取整到整数灰度（误差不超过 0.5，远小于容差）；标准差乘 DEVIATION_SCALE 存，分辨率 0.25 灰度， 超过 63.75 的截断：这样的像素按 3 倍算容差已近 200，截断不影响判定

只有一张样本时不存标准差
