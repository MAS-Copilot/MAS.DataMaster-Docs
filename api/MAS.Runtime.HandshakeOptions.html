Remarks

触发值与完成值都是 16 位整数（PLC 的 INT）。下位机写好请求后把触发值加 1； 上位机处理完成后把完成值写成与触发值相同。触发值为 0 视为复位，不处理，完成值回写 0 作为确认。 地址含义同 IPlc：S7 为 DB 号 + 字节偏移，MC/Modbus 为起始寄存器
