Remarks

item.json 描述模板：标题、说明、所需参数（device、database）、所需地址与插入 Startup 的注册行

其余每个文件生成项目中的一个文件，首行 //#path: 相对路径 指定生成位置； 第二行为 //#once 的是同类任务共用的文件（如 TaskExecution 结构体），只在不存在时创建。 item.json 的 inserts 把若干行插入共用文件的标记之上（如每个任务一个触发字段）。 在 Items 下添加一个文件夹即可新增一种任务模板
