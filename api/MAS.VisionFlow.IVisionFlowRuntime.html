public interface IVisionFlowRuntime

DynamicViewVariableWriteExtensions.ToVariableValues(object)

Remarks

不依赖视觉工作台页面：工程加载后即可由动态视图脚本、Agent 等外部触发。 构造函数注入本接口即可使用，例如在动态视图全局脚本中：

var result = await _vision.TriggerAsync("颜色检测", token);
if (result.TryGetValue("颜色识别", "IsDetected", out bool isDetected)) { ... }
