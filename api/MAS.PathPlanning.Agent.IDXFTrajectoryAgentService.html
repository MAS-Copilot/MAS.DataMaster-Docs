Interface IDXFTrajectoryAgentService

Namespace
MAS.PathPlanning.Agent
Assembly
MAS.PathPlanning.dll

DXF 图纸配方的 Agent 协作服务接口：分析已有轨迹、试算重新生成、按批次修改轨迹点与扩展点

public interface IDXFTrajectoryAgentService

Remarks

与界面共用同一份内存工作区：

  • 脚本任务不处于 Stopped 时，任何写入一律拒绝
  • 写入只允许落在当前配方，跨配方只读
  • 不创建、不删除、不切换图纸配方，也不绑定标定配方，这些都归用户
  • 只能改已生成的轨迹，不新增图层、不删除轨迹、不写生成参数
  • 整批要么全部生效要么全部放弃，落盘时机仍是保存工程
