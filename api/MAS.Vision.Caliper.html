Remarks

搜索区摆正（亚像素双线性采样）→ 沿投影方向取平均得到 1D 灰度剖面（抑噪）→ 高斯平滑 → 一阶导数 → 按极性与对比度找峰 → 抛物线插值得亚像素边缘

导数按有效模糊尺度换算成“对比度”：清晰的阶跃边缘峰值约等于两侧的灰度差（成像本身模糊时会小一些），阈值不随 σ 变化； 峰位用高斯插值（对数抛物线），亚像素偏差远小于普通抛物线

搜索区超出图像时边界像素按复制处理，不会在图像边缘造出假边
