Remarks

Parameters

project MasProject

要运行的项目

deviceRegistry IDeviceProtocolRegistry

平台设备目录。项目运行期间，项目中的 PLC 会登记到该目录，供其他模块按设备名称使用。可为 null

secretProtector ISecretProtector

用于解密配置中加密值（如数据库密码）的服务，由平台提供。可为 null

protocolManager IProtocolManager

平台协议管理器。给出时项目中的 PLC 按租约共用平台实例：与组态通讯等连同一地址时只有一条连接，项目停止只归还租约。 为 null 时每台 PLC 自建独占连接，此时不能再给 deviceRegistry 传平台目录（平台目录只登记管理器中的实例）
