RigidTransform2D ProcessROI(Mat input, ROICoordinates roi, Mat output, RigidTransform2D? follow)

Parameters

input Mat

输入图像

roi ROICoordinates

示教时的 ROI

output Mat

裁剪结果写入的图像

follow RigidTransform2D

示教姿态 → 当前姿态的变换（见 Follow(Location2D, Location2D, bool)），为空表示不跟随

Returns

RigidTransform2D

输出图上的点经此变换即为输入图上的点（下游定位结果据此还原到原图）

Remarks

跟随时把当前图像按变换反向映射回示教姿态再按 ROI 取图（亚像素双线性插值），六种形状一致： 输出与示教时的取景一致，下游节点看到的工件总是示教时的位置和方向；超出图像的部分填黑
