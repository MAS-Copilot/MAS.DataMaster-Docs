Remarks

容差 = max(灰度容差, 标准差倍数 × 标准差)；上限 = 均值 + 容差、下限 = 均值 − 容差，再按对位容差分别取邻域最大、最小

只与模型和三个容差参数有关，参数不变时可反复使用（比对时只做减法与连通域）
