Remarks

比 Blob 分析多：固定阈值、取孔、更多筛选条件、参考形状、拟合定位；简单找孔用 Blob 分析即可

定位列表为通过筛选的全部轮廓（带面积、宽高、半径、圆度），定位结果为第一个；精度在像素量级，量尺寸要亚像素时用卡尺
