动态视图配方服务

public interface IDynamicViewRecipeService

Remarks

配方数据由配方结构体所引用的普通结构体承载

保存即采集引用结构体当前值的快照，装载即把快照写回引用结构体

界面、脚本与通讯任务共用本服务，同一配方结构体的操作按顺序串行执行

Task<DynamicViewRecipeOperationResult>

异步操作任务，配方操作结果

Remarks

按当前引用配置逐个投影快照：结构体先按标识匹配、失配回退名称； 字段先按标识匹配、失配回退名称；配方中不存在的引用和字段保持当前值不变

引用是逐个写入的，中途失败即停止且不回滚： 失败前已写入的引用保持新值，失败序号由 FailedReferenceIndex 给出， 是否补偿由调用方决定
