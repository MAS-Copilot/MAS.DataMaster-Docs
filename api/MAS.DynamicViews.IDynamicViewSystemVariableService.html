Interface IDynamicViewSystemVariableService

Namespace
MAS.DynamicViews
Assembly
MAS.DynamicViews.dll

动态视图系统变量服务接口

public interface IDynamicViewSystemVariableService

Remarks

  • 系统结构体的唯一写入口：控件与下位机都不能写入这些字段
  • 时间、心跳、运行时长、设备计数等字段由本服务在每次下发前自行刷新
  • 画面、运行状态、错误码等字段由各业务模块调用本服务的方法上报
  • 工程中不存在系统结构体时，所有更新方法静默返回，不产生副作用
