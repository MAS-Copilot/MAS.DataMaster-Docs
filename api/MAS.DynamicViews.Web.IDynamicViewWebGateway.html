public interface IDynamicViewWebGateway
Extension Methods
DynamicViewVariableWriteExtensions.ToVariableValues(object)

Remarks

网关是 Web 前端访问变量的唯一入口： 读取来自变量中心 IDynamicViewVariableValueProvider， 写入一律经过 IDynamicViewVariableWriteService，从不直接改变量缓存或访问通讯协议。 组态视图与 Web 视图共用同一个变量中心，因此任意一端写入后其余各端都会收到更新
