Remarks

根据模型反射结果和描述符注册表生成属性架构，不单独维护具体属性。 MAS.DynamicViews.Schema.DynamicViewModelSchemaFactory.ValueKinds 和 MAS.DynamicViews.Schema.DynamicViewModelSchemaFactory.CompositeStructTypes 是需要显式维护的类型映射表。 新增属性的类型已注册时，架构将自动包含该属性；未注册类型将标记为 Unsupported 并设为只读，以便及时识别映射缺失

Remarks

架构指纹覆盖全部资源种类和控件类型的属性路径、值类型及可写性。 模型属性发生变化时，指纹同步变化，调用方可据此判断缓存架构是否失效。
