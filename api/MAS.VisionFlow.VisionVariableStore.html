Remarks

管道脚本在构造函数里注入它，用 Get<T>(string) 取一次强类型变量存为字段，之后读写不分配内存。 定义的增删改走 UpdateVariables(IReadOnlyList<VisionVariableDefinition>)（有管道在运行时拒绝）；当前值随时可改，不落盘，打开工程时恢复为默认值
