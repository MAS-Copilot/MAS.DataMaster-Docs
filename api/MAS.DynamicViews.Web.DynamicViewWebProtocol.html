Remarks

协议是 WebSocket 文本帧上的 JSON 消息，每条消息带 type。

  • 客户端 → 服务端：hello / subscribe / unsubscribe / write / query / resync / ping / login / logout
  • 服务端 → 客户端：welcome / subscribed / unsubscribed / snapshot / patch / writeResult / queryResult / loginResult / logoutResult / auth / runtime / pong / error

snapshot 与 patch 共用一个按连接递增的 sequence，客户端发现 patch 序号不连续时发送 resync 取回完整快照。 登录成功先回 loginResult 再推 auth；写入前身份有变化时 auth 先于 writeResult。 同一连接的 write / login / logout 按到达顺序串行处理；query 独立并发执行（每连接有并发上限），不阻塞写入
