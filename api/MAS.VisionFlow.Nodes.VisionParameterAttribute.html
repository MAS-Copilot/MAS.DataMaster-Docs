Remarks

描述参数本身的含义、取值范围及运行时修改策略。 VisionParameterSchema 按它描述参数并校验写入；参数要随工程保存，属性还需要 [JsonProperty]， 标注在 ICommand 属性上表示一个可调用的操作

嵌套配置对象里的成员标注在节点类上并指定 Path（如 ImageSourceModel.FilePath）， 配置类型所在的程序集（MAS.Vision）不必引用本特性
