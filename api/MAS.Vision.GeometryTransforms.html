Remarks

像素坐标按 OpenCV 约定：像素 (i, j) 的中心为 (i, j)；角度为度，从 +X 转向 +Y 为正（图像坐标系下即顺时针），与定位结果的角度同向

仿射类变换统一用“输出图 → 输入图”的 RigidTransform2D 描述（WarpInverseMap）， 该变换同时作为节点的变换输出：下游在输出图上的测量结果经它换回输入图坐标

结果写进调用方给的 dst：尺寸与类型不变时 OpenCV 复用其内存；src 与 dst 不能是同一个 Mat
