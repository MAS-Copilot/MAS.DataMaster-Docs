Remarks

事件有两种载荷形态：

  • 结构体级：由通讯轮询等批量提交产生，FieldId 与 FieldName 为 null， OldValue 与 NewValue 是“字段标识 → 值”的字典
  • 字段级：由单字段提交产生，FieldId 与 FieldName 指向该字段， OldValue 与 NewValue 是该字段的标量值

因此 FieldId 描述的是载荷形态而不是“哪个字段变了”， 脚本中请优先使用 GetNewValue<T>(string)、IsRisingEdge(string) 等方法读取字段， 它们对两种形态一致工作，且支持直接使用字段名称
