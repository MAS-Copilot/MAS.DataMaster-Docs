Remarks

显示：缩小时高质量插值；放大后按最近邻显示，放大档位为整数倍（按物理像素计），色块大小一致（pixel-perfect）； 放大到 8 倍起叠加像素网格，格子装得下时在格子里显示像素值（彩色为 R/G/B 三行），文字颜色随像素亮度取黑或白

视图：滚轮以指针为中心逐档缩放；左键或中键拖动平移；F 适应窗口，1 为 1:1（一个图像像素对应一个屏幕物理像素）

图像来自 Preview（执行结果，需 MaxSize = null 保持原尺寸）或 Source； 同尺寸的新帧不改变视图，尺寸变化时重新适应窗口

单击（没有拖动）图像时触发 ImagePointClicked，给“指哪打哪”的视觉引导这类场合用
