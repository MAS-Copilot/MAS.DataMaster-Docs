选择 ONNX Runtime 原生库：装了 GPU 运行时就从它的目录加载（带 CUDA 提供程序），否则用程序目录里随程序发布的 CPU 版

Remarks

GPU 运行时（ORT GPU 原生库 + CUDA / cuDNN 运行库）在 runtimes/onnxruntime-gpu/win-x64，由依赖组件页一键安装。 GPU 版 onnxruntime.dll 同样能跑 CPU 推理，选 CPU 的节点不受影响

原生库一进程只加载一次：Configure() 必须在任何 ONNX Runtime 调用之前执行，装好或换版本后要重启程序才生效。 运行中重新安装解压到 win-x64.pending，下次启动时再换上
