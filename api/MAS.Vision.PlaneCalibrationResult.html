Remarks

平面映射 h：像素（畸变校正后）→ 机械平面，Matrix 为 3×3 行优先，仿射时末行为 0 0 1

换算到针尖（工具）坐标：工具坐标 = (相机随轴 ? 拍照时轴位置 : 0) + h(像素) + 工具偏置。 相机随轴时样本按 h(像素) = −轴位置 拟合，Mark 的绝对位置由工具偏置补上（示教：针尖对准 Mark 后记录）

只对标定时那个高度的平面成立；工作面高度不同（板厚变化）会带来缩放误差，标定时 Mark 应放在与工件同高的位置
