Remarks

矩形直接裁剪；旋转矩形摆正后输出宽 × 高；圆、椭圆、圆环、多边形裁剪到外接矩形，形状外置黑

随动：接入“跟随定位”（如工件 Mark、边的定位结果），工件在示教位置时运行一次并点「设为跟随基准」；之后按定位的平移、旋转把当前图像映射回示教姿态再裁剪， 输出与示教时取景一致，下游卡尺、差分、精测不用再管工件放偏。跟随定位没有结果时管道失败，不会裁到错的地方

第二个输出是“输出图 → 输入图”的坐标变换：下游在裁剪图上的定位结果经「坐标映射」还原到原图（不跟随时同样适用，替代手工加 OffsetX/OffsetY）
