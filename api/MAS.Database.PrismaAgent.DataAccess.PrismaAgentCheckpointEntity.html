Remarks

每个会话一条，整体覆盖写。它与 PrismaConversationEventEntity 记录的是不同的东西： 事件表记录"界面上发生了什么"且不受压缩影响，本表记录"模型下一轮会看到什么"， 压缩会真的删掉其中的早期内容
