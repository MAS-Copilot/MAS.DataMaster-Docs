Remarks

最常见的二维引导方式：示教时记下工件的位置与角度作为基准，运行时算出偏移交给机器人补偿。 像素到毫米按单一比例换算（相机垂直于工作面、已知像素当量）；需要精确的像素到机械坐标映射时用 N 点标定
