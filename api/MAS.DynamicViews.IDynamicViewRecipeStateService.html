动态视图当前配方状态查询服务

public interface IDynamicViewRecipeStateService

Remarks

用于查询运行期间各配方结构体当前关联的配方状态

每个配方结构体独立维护当前配方状态，不同结构体之间互不影响； 同一个工程中可以同时存在多个配方结构体，并分别关联不同配方。

清除指定配方结构体的当前配方状态

bool ClearCurrentRecipe(string structureId)

Parameters

structureId string

配方结构体唯一标识

Returns

bool

状态存在并成功清除返回 true；否则返回 false

Remarks

仅清除运行期间维护的状态记录：

  • 不会修改结构体运行值；
  • 不会删除配方文件或配方数据；

状态实际移除后触发 CurrentRecipeChanged
