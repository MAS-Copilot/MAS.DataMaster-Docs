Remarks

模块结构体由 DynamicViewModuleDefinition 定义并维护，字段布局和访问模式由模块统一管理。 模块结构体支持在应用升级后同步新增字段，不修改已有字段，以保持现有界面绑定和工程配置的兼容性

Remarks

应用升级后，模块定义可能包含新增字段。同步时仅追加定义中存在而结构体中缺少的字段 不删除、重命名或修改已有字段，以保持现有界面绑定和工程配置不变 未注册对应模块的结构体保持原有内容

Remarks

每个工程中同一模块仅允许创建一个模块结构体。已注册模块时，结构体名称和访问模式必须与模块定义一致， 字段必须属于模块定义且保持名称和类型不变。 结构体允许暂时缺少模块定义中的字段，以兼容应用升级后的旧工程；缺少的字段可通过 Reconcile(IEnumerable<DynamicViewVariableModel>) 补充
