Remarks

输入 0 为图像，输入 1 为“跟随定位”（可选）；输出 0 标注图、1 定位结果、2 定位列表，派生类可再加输出

随动与 ROI 选择器一致：工件在示教位置运行一次后点「设为跟随基准」，之后搜索区随定位平移、旋转； 跟随定位没有结果时管道失败，不在错误的位置测量。设置窗口里的画面与结果标记映射回示教姿态，与编辑的搜索区对齐
