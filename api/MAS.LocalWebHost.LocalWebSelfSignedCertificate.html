Remarks

局域网 IP 没法申请公共证书，浏览器首次访问需要手动信任；证书私钥只保存在本机目录，不随工程复制。 Windows 的 SChannel 不支持内存临时密钥，加载证书会在当前用户的密钥存储里留下一份， 因此同一进程只加载一次并缓存
