Remarks

定位结果为圆心（Radius 为半径、Width/Height 为直径），测量值为直径；定位列表为参与拟合的边缘点（角度为该处切线方向）。 由内向外找孔边时，暗孔亮底是暗到亮；只能看到部分圆周时用起始角 + 扫过角度限定圆弧
