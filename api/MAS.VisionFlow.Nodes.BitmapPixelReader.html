Remarks

直接支持 Gray8、Gray16、Bgr24、Rgb24、Bgr32、Bgra32、Pbgra32；其它格式先转换（灰度类转 Gray8，其余转 Bgra32）

只在界面线程使用。WriteableBitmap 原地更新时不用重建：每次读取都拿当前内容
