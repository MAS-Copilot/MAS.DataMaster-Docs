Interface ISpeechService

Namespace
MAS.DynamicViews
Assembly
MAS.DynamicViews.dll

语音播报服务

public interface ISpeechService

Remarks

  • 基于 Windows 本机 TTS 引擎（SAPI5），完全离线，不依赖任何云端服务
  • 播报按“优先级优先、同级先进先播”的顺序串行执行，同一时刻只会有一条语音在播，规则见 SpeechPriority
  • 待播队列有容量上限（QueueCapacity），队列已满时优先牺牲最低优先级中最晚入队的一条
  • 另有一组循环播报条目（StartLoop(string?, string?, SpeechPriority)），在待播队列空闲时被反复播出，直到显式停止
  • 发音人、音量、语速均沿用 Windows 的默认设置，不提供逐条指定
  • 本接口的所有成员都不会阻塞调用线程去等语音播完，可安全地在 UI 线程调用

StartLoop(string?, string?, SpeechPriority)

开始循环播报指定文本

bool StartLoop(string? key, string? text, SpeechPriority priority = SpeechPriority.Normal)

Parameters

key string

条目标识，用于更新和停止播报

text string

播报文本

priority SpeechPriority

播报优先级

Returns

bool

登记成功返回 true；参数无效、语音不可用或循环条目达到上限时返回 false。

Remarks

条目将重复播报，直到调用 StopLoop(string?) 或 StopAllLoops() 停止

调度时优先处理普通播报队列；队列空闲后按优先级和登记顺序依次播报循环条目。 循环播报可被新的播报请求中断，并在后续调度中继续执行。

重复使用同一 key 时，仅更新对应条目的文本和优先级

TestSpeakAsync(string?, CancellationToken)

Task<bool> TestSpeakAsync(string? text, CancellationToken token = default)

Parameters

text string

待播报的文本

token CancellationToken

Returns

异步操作任务，播报未失败返回 true

Remarks
