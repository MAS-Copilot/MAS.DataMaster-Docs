Interface ISpeechService

Namespace
MAS.DynamicViews
Assembly
MAS.DynamicViews.dll

语音播报服务

public interface ISpeechService

Remarks

  • 基于 Windows 本机 TTS 引擎（SAPI5），完全离线，不依赖任何云端服务
  • 播报按“优先级优先、同级先进先播”的顺序串行执行，同一时刻只会有一条语音在播，规则见 SpeechPriority
  • 待播队列有容量上限（QueueCapacity），队列已满时优先牺牲最低优先级中最晚入队的一条
  • 发音人、音量、语速均沿用 Windows 的默认设置，不提供逐条指定
  • 本接口的所有成员都不会阻塞调用线程去等语音播完，可安全地在 UI 线程调用
