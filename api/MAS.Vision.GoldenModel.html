Remarks

只有一张金样时标准差全为 0，比对只按固定灰度容差；多张好件建模后，正常就会变化的像素（边缘、纹理、反光）标准差大，容差随之放宽

模型只读；释放由持有者负责（换模型时先确认没有比对正在使用它）
