Remarks

首次使用（或图像尺寸变化）时按图像尺寸准备：内参按标定时的图像尺寸等比换算到当前尺寸， 用 GetOptimalNewCameraMatrix 求新相机矩阵，再预计算 InitUndistortRectifyMap 的映射表（CV_16SC2，定点、最快）

校正后的像素坐标对应 NewCameraMatrix，不再是原内参；下游要用像素坐标换算物理量时按新矩阵算

只在一个线程上使用；内参或 alpha 变了请新建实例
