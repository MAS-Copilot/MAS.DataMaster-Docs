语音播报优先级

public enum SpeechPriority
Extension Methods

Fields

High = 2

高：严重故障，插队并打断正在播报的更低优先级语音

Low = 0

低：提示类信息

Normal = 1

普通：一般告警

Remarks

调度规则为“优先级优先、同级先进先播”：

  • 高优先级排在所有低优先级之前，同一优先级内保持入队顺序
  • High 入队时会打断正在播报的更低优先级语音，被打断的那条直接丢弃，不重播
  • 队列满时优先牺牲最低优先级中最晚入队的一条，保证高优先级挤得进来
