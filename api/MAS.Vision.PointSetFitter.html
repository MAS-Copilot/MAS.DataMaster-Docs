Remarks

直线、圆、椭圆的数学在 RobustFit2D（最小二乘 / Huber / RANSAC）；外接矩形用 OpenCV minAreaRect，包住全部点。 单位跟随输入：像素坐标得到像素，经「像素转机械坐标」后得到 mm
