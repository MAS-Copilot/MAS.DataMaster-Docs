Remarks

角度为度，从 +X 转向 +Y 为正（右手坐标系即逆时针为正），与 MAS.PathPlanning.RigidTransform 一致： ToMatrix() 得到的 3×3 矩阵可直接交给 PointTransform 变换轨迹点

视觉（定位、ROI 随动、位置补正）与图纸导入共用这一类型，模块间传偏移不用再转换
