Remarks

整幅图模式：绕定位点旋转，使目标方向等于“目标角度”；勾选“固定位置”时再把定位点平移到目标位置，这样每次输出里目标都在同一处（金样差分前的对齐）

裁剪模式：输出宽 × 高的局部图，窗口中心在目标坐标系里相对定位点偏移（偏移 X、Y 沿目标方向量），目标在输出里为“目标角度”。 定位结果没有可靠角度时（Blob、圆）角度按 0 算，只跟随平移

第二个输出是“输出图 → 输入图”的坐标变换：下游测量结果经「坐标映射」换回原图坐标。定位没有结果时管道失败
