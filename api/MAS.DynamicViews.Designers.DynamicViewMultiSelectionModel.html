Remarks

用户改动缓冲区中的任意属性时按属性名反射下发到全部选中控件。 属性分节（Layout / Appearance / Text / Icon…）与节内属性都靠反射发现， 新增属性无需改动本类；个别不该批量下发的属性用 DynamicViewNoBatchEditAttribute 排除
