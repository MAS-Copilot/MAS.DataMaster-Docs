Remarks

四个角点在设置窗口的图上点选（多边形，恰好 4 点）；也可接“角点定位”输入，用定位列表的前 4 个点（如四个 Mark）每次自动取角。 默认按几何自动排成左上、右上、右下、左下，四边形接近 45° 倾斜时关掉自动排序按点选顺序给

输出宽、高为 0 时按四边形边长自动估计（约等于不缩放）。透视不是刚体变换，没有变换输出；单应矩阵在结果数据里
