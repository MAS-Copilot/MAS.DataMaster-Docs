Remarks

统一设计器与 Agent 的图元构造规则：包围盒图元由布局确定形状， 顶点图元使用页面绝对坐标，并归一化为「布局包围盒 + 相对顶点」， 与 MAS.DynamicViews.Designers.DesignerShapePointHelper 的编辑规则保持一致
