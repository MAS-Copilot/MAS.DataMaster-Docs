Remarks

规划分四步：

  1. 按运动阶段、最大速度、圆弧曲率给每段定指令速度
  2. 按拐角容差、曲率、强制停顿给每个点定通过速度上限
  3. 反向扫描：保证按最大减速度来得及降到后面每个点的速度（受前瞻段数限制）
  4. 正向扫描：保证按最大加速度能从前一个点的速度加上来

规划离线进行，手里有整条轨迹，因此前瞻段数为 0 时得到的是全局最优解
