public interface IAgentCheckpointService

Remarks

展示历史与推理上下文是两份东西：前者记录"界面上发生了什么"且不受压缩影响， 后者记录"模型下一轮会看到什么"。只恢复前者，重启后会得到一个看得见却接不上的对话
