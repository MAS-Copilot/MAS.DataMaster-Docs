Remarks

待检图须与金样对齐：前面接 定位 → 定位转正（裁剪），金样也在转正后的图上学；剩下一两个像素的对位误差由对位容差吸收

金样是节点资产（PNG 文件，不进设置与参数表，Agent 看不到）；编码推迟到保存工程时
