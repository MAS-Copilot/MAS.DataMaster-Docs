Remarks

实体解析、路径段与生成过程这三份数据只在生成的那一刻存在，最终轨迹里反算不出来。 生产环境需要追溯已下发轨迹是怎么生成的，因此把它们按图层持久化到配方目录， 重新打开工程即可查看，只有重新生成轨迹才会覆盖
