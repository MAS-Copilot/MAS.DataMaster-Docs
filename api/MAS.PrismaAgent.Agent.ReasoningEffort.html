Remarks

对应 Responses 请求体的 reasoning.effort。 推理等级越高，通常耗时和费用越高，也会占用更多输出预算。 全局生效，所有会话继承。 若端点不支持某个取值（如部分网关不支持 XHigh）， 传输层会在收到 400 后于当前进程内停发该参数，并回退为模型默认行为。
