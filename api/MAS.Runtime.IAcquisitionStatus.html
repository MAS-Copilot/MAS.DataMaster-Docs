Interface IAcquisitionStatus

Namespace
MAS.Runtime
Assembly
MAS.Runtime.Abstractions.dll

采集项目自启动以来的运行状态：成功与错误计数、当前错误码、最近一次错误

public interface IAcquisitionStatus
Extension Methods
DynamicViewVariableWriteExtensions.ToVariableValues(object)

Remarks

运行时自动注册为单例，握手任务（采集、应答、单向）每次处理后自动上报； 用户代码可注入后自行上报，也可读取后写入 PLC 的系统区（见模板的 SystemWorker）

Properties

ErrorCode

获取当前错误码：0 表示所有来源都正常；否则为仍处于失败状态的来源中最近一次的错误码，该来源下次成功后清除

short ErrorCode { get; }

short

ErrorCount

获取自启动以来的错误次数，每次失败都计一次（包括同一请求的重试）
