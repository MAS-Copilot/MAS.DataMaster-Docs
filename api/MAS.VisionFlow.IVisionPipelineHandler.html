Remarks

管道启动后按 FixedIntervalMs 循环： TriggerSignalAsync(CancellationToken) 返回 true 时执行一次管道， 然后依次调用 HandleResultAsync(VisionRunResult, CancellationToken) 与 CompleteAsync(CancellationToken)。 构造函数可注入应用中注册的任意服务（例如 IProtocolManager）

Properties

FixedIntervalMs

获取或设置循环间隔（毫秒）

int FixedIntervalMs { get; set; }

Property Value

int

Remarks

0：不等待，跑完立即进入下一轮（连续运行，会占满一个线程，适合自由运行或高速轮询触发信号）； 大于 0：每轮之间等待该时长，Windows 计时精度约 15.6 ms，1~15 实际约为 16 ms
