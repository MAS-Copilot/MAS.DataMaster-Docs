Remarks

原图直通不复制，下游算法接它永远拿到干净的图；标注图只供查看。 派生类须在构造函数末尾调用 AddAnnotatedOutput()。 没找到目标时不写定位结果（下游取不到输入会报输入无效），本节点报告警告
