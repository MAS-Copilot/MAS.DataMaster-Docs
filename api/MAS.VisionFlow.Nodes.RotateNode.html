Remarks

角度从 +X 转向 +Y 为正（画面上顺时针），与定位结果的角度同向；默认绕图像中心转，也可指定中心。 勾选“保留整幅图”时输出会放大到能装下转完的整幅输入（四角不被裁掉），此时输出紧贴内容，平移不起作用

第二个输出是“输出图 → 输入图”的坐标变换：下游在输出图上的定位结果经「坐标映射」换回原图坐标。 要按定位结果转正请用「定位转正」
