展示事件的统一入口

public interface IConversationJournal

Remarks

所有会改变聊天界面的行为都必须经由本接口记录，界面更新是记录的副产物而不是并行的另一条路径。 这样实时渲染与历史还原消费的是同一份事件，"完全一致"由结构保证而非靠两套渲染逻辑对齐
