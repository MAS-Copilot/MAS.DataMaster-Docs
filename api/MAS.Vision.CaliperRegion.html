Remarks

坐标为 OpenCV 约定（像素 (i, j) 的中心为 (i, j)）；角度为度、图像坐标系下顺时针为正，与 ROI 的旋转矩形一致： 搜索方向是旋转矩形的宽度轴（ROI 编辑器里的箭头），找到的边缘与它垂直
