Remarks

  • 相机对准：目标 = 轴位置 + h(点击点) − h(准心)，h 为 2D 标定的像素 → 平面映射
  • 针尖对准：目标 = ToMachine(PlaneCalibrationResult, Point2d, Point2d?)（含针尖偏置）

点击用的画面必须与标定时同一像素坐标系（同一相机、同一分辨率，中间不裁剪、不缩放）
