Remarks

每个角点有唯一 ID，相机随轴移动也始终锁定同一个物理点，可直接当九点标定的 Mark（复用相机标定用的 ChArUco 板）

定位结果角度为棋盘 X 方向（ID 增大方向）在图像中的角度，Score 为角点 ID；全部角点在结果数据 Items 里
