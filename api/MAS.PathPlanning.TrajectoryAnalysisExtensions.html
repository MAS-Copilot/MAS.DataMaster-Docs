对轨迹执行一次概览统计与诊断扫描

public static TrajectoryAnalysisResult Analyze(this TrajectoryPath path, TrajectoryParameters? parameters = null, TrajectoryGenerationSnapshot? generation = null)

Parameters

path TrajectoryPath

待分析的轨迹路径

parameters TrajectoryParameters

该图层的生成参数，缺失时与参数相关的统计和诊断会被跳过

generation TrajectoryGenerationSnapshot

该图层的生成过程记录，缺失或已过期时依赖它的诊断会被跳过

Returns

TrajectoryAnalysisResult

轨迹分析结果

Remarks

概览与大部分诊断都基于最终轨迹点反算，轨迹被手动增删或编辑之后重新调用即可得到最新结果。 大轨迹请改用 AnalyzeAsync(TrajectoryPath, TrajectoryParameters?, TrajectoryGenerationSnapshot?, CancellationToken)，避免阻塞调用线程
