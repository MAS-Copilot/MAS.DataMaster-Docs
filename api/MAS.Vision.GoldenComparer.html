Remarks

待检图须已与金样对齐（同尺寸、同取景），通常在前面接 定位 → 定位转正（裁剪）； 剩下的零点几到一两个像素的对位误差由容差带的对位容差吸收

流程：亮超出 = 灰度 − 上限、暗超出 = 下限 − 灰度（饱和减法）→ 按极性取 → 二值化 → 可选开运算去噪 → 8 连通域 → 按最小面积筛选
