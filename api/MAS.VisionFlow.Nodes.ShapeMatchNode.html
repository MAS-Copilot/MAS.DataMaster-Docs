Remarks

示教：在标准产品图上框模板区、放参考点，点「学习模板」；模板图（PNG）随工程保存，不依赖外部文件。 只在搜索区内找（限定的是模板中心的位置）

定位结果为参考点在当前图里的位置，角度为相对模板的旋转（图像坐标系顺时针为正），得分 0~1； 宽高为模板尺寸。单个目标带角度即可接「像素转机台」→「位置补正」
