GetProtocol<TProtocol>(IPlc)

获取底层协议实例，用于结构体之外的非标读写（按字、按位等）

public static TProtocol GetProtocol<TProtocol>(this IPlc plc) where TProtocol : class, IProtocol

Parameters

plc IPlc

PLC

Returns

TProtocol

与 plc 共用同一条连接的协议实例

Type Parameters

TProtocol

协议接口，如 IS7Protocol、IMcProtocol、IModbusProtocol

Remarks

逃生口，常规读写请走 IPlc：直接调用协议时的失败与断开 IPlc 感知不到， 其连接状态要等它自己下一次读写失败后才会纠正

不要对返回的实例调用 Disconnect/Dispose，连接归运行时管理，平台其它模块也在共用

Exceptions

NotSupportedException

plc 不是运行时创建的设备

InvalidOperationException

设备协议与 TProtocol 不匹配
