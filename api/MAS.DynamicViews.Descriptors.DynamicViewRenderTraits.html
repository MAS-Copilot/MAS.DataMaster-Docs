Fields

None = 0

无特征，按包围盒常规摆放

NumericTextChannel = 8

文本通道承载的是数值而不是文本

数值框复用文本绑定通道，但只接受数值变量，也不提供显示小数位与格式化； 文本内容由控件自身的数值编辑决定，属性面板相应隐藏文本内容编辑项

PointGeometryShape = 1

顶点几何图元，按自身几何渲染并使用顶点控制点

StateTextMapping = 4

多状态映射同时驱动显示文本

不具备该特征的控件（如数值状态灯）只用状态映射切换画刷， 属性面板相应隐藏文本编辑项，避免给出不会生效的配置

StretchToBounds = 2

需要拉伸填充包围盒，一般是装饰容器

TextContentAlignment = 16

文本可在控件内自行排版对齐

其它控件的文本由模板摆放，逐实例设置对齐不会生效

Remarks

描述控件的摆放方式与渲染方式，与控件的具体配色无关
