Remarks

画刷 Key 在类型上就是字符串，反射无法与普通文本区分。标记此特性后， 模型架构会将该属性标注为画刷 Key，Agent 写入时也会校验 Key 是否存在， 避免写入 #FFE8E8E8 这类颜色值产生解析不到的悬空引用。 对于 [ObservableProperty] 字段，应使用 [property: DynamicViewBrushKey] 将特性应用于生成的属性。
