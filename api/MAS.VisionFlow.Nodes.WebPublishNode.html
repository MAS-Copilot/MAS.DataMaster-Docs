Remarks

只发布不判定：是否合格由网页按数据自己判断。图像缩小后 JPEG 编码，只给展示用； 结果数据在整轮结束后按「节点标题.结果键」取，可以引用同一管道里任何节点。 连续运行时没人订阅就不编码图像，订阅时按帧率限流
