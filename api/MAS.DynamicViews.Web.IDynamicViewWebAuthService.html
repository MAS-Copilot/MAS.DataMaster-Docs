Interface IDynamicViewWebAuthService

Namespace
MAS.DynamicViews.Web
Assembly
MAS.DynamicViews.dll

Web 视图认证服务接口

public interface IDynamicViewWebAuthService

Remarks

复用宿主 IAuthenticationService 的用户与角色，不维护独立账号。 宿主联动会话与宿主登录状态双向同步；独立会话使用宿主账号登录并通过令牌维持会话， 角色变更和账号删除同步到对应会话
