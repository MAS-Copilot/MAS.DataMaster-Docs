Remarks

画面号是内容（页面、窗口、背景）面向下位机的短标识，工程内唯一， 默认按类型前缀顺序分配：页面 P1、窗口 W1、背景 B1

下位机侧多为 ASCII 通道，因此只接受 ASCII 字母、数字与下划线，且必须以字母开头
