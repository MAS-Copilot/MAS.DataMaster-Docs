Remarks

多个卡尺各取一个边缘点，RANSAC 剔除毛刺、缺口、划痕造成的离群点后最小二乘拟合。 与霍夫变换的直线/圆定位相比，只看指定区域、按极性取边、亚像素，适合尺寸测量
