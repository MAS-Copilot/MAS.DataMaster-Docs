Remarks

迁移类当前必须编译到 MAS.Database 程序集，其他程序集中的迁移不会被扫描。 MySQL DDL 会隐式提交，无法整体回滚；因此每条操作必须可重复执行，且建议一个迁移只完成一件事。 初始化器会先创建当前版本缺失的实体表，再执行历史迁移，因此迁移可以引用本版本新增的实体表； 若迁移本身也创建该表，创建语句仍必须保持幂等。 迁移失败后不会写入历史表，修复失败原因后可重新启动并重试；无法安全重试时需先由维护人员核对数据库实际结构
