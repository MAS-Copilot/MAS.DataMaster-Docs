Interfaces

IAgentEventSink

Agent 事件下发通道。MAS.PrismaAgent.Agent.AgentLoop 通过它发布思考、工具时间线与收尾事件，由具体实现决定如何呈现

IAgentLoop

Agent 推理循环。负责规划、调用工具、观察结果、继续推理并最终回答。 自身无状态：跨轮会话记忆（对话历史、已激活工具、已执行 callId）由会话存储按会话标识承载

IAgentPlanService

计划决策服务。agent-plan 工具执行时向用户展示分步决策卡片并等待逐步选择结果

IAgentProtocol

Agent 协议适配器。负责在「统一工具编排」与「原生 function-calling 模型交互形态」之间转换

IConversationDriver

对话驱动器接口。本身不持有任何会话状态，每次调用都显式指定会话， 对话历史存于会话存储；因此多个会话可以并发驱动而互不干扰

IConversationStreamView

助手流式输出的展示通道。MAS.PrismaAgent.Agent.AgentLoop 通过它增量输出助手文本、 在重连前回滚未完成输出并展示/隐藏重连状态

IReasoningEffortPolicy

IToolApprovalService
