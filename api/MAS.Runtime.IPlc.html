Remarks

地址含义随协议而定：S7 的 address 是 DB 号、offset 是字节偏移； MC/Modbus 的 address 是起始寄存器，offset 直接叠加到起始地址上

首次读写时自动连接；读写失败会断开连接并抛出异常，下一次读写自动重连
