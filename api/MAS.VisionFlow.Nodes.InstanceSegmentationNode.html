Remarks

定位列表按掩码量：中心为质心，面积为掩码像素数，宽高、角度为掩码的最小外接矩形（量缺陷长度、面积用这个，不是检测框）

输出 3 为全部目标合成的掩码（单通道 0/255），可接 Blob、轮廓分析做进一步测量
