鲁棒拟合：先用 RANSAC 挑出内点（剔除离群点），再对内点做最小二乘

Remarks

假设数不多时穷举全部点对（三元组），结果确定、可复现；超过上限时用固定种子随机抽样，同样可复现

假设按 MSAC 代价选（内点距离平方和 + 外点按容差封顶），内点数相同时更贴合的胜出
