Remarks

系统结构体固定占用 REGISTER_LENGTH 个寄存器，由上位机单向维护并下发，控件与脚本只读。 末尾预留 RESERVED_FIELD_COUNT 个寄存器，用于后续扩展且不影响既有字段地址
