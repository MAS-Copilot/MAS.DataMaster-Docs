Remarks

角点由周围检出的 ArUco 码插值得到 ID，再在原图上做亚像素细化；目标角点相邻的码至少要看到 2 个

相机随轴移动时按 ID 锁定同一个物理点，不会像普通棋盘格那样跳到相邻角点，适合做九点标定的 Mark
