Remarks

取值数量超过 INLINE_LIMIT 的属性视为大词表（例如图标枚举有近万个取值）。 大词表不随架构整体返回，调用方先从架构中获取取值总数和样例，再按关键词检索所需取值， 避免一次性传输全部取值。判定只依据取值数量，因此新增的大枚举属性自动适用该机制。
