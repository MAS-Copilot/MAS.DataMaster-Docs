MAS.DynamicViews.WebView.Sdk

dynamic-views.js 是 Web 视图页面访问变量中心的唯一方式，由 DataMaster 在 /_sdk/dynamic-views.js 提供。SDK 封装了 WebSocket、握手、断线重连、快照与增量、序号断档恢复、登录令牌和请求回执关联，页面代码只需要使用别名读写变量。

SDK 文件位于工程的 Web/_sdk/dynamic-views.js（Web 目录创建后由 DataMaster 放入，已有则不覆盖），和图标 Web/_shared/icons/ 一样是工程里的普通文件，页面按相对路径引用

<link rel="stylesheet" href="/assets/theme.css">
…
<script src="/_sdk/dynamic-views.js"></script>
<script>
    (async () => {
        const dv = await DynamicViews.connect();
        await dv.subscribe(["motor.speed", "motor.running"], values => {
            document.querySelector("#speed").textContent = values.get("motor.speed");
        });
    })();
</script>
Note

服务端广播的值是唯一可信状态。SDK 不做乐观更新：写入成功后，新值由变量中心再次广播到达；写入失败时界面保持服务端的值。

连接

DynamicViews.connect(options?)

返回 Promise<client>，收到服务端 welcome 后完成。

选项 默认值 说明
bind true 连接后自动扫描 document.body 的 data-dv-* 声明式绑定
loginUi true 页面或应用需要登录、或写入返回 LOGIN_REQUIRED 时，自动弹出内置登录框
loginScope "browser" 独立登录的保持范围："browser" 同一浏览器的所有标签页共享登录（其他标签页登录/登出后本页自动重新握手）；"tab" 只在当前标签页有效，适合共用终端
timeout 0 首次连接超时毫秒数（只约束首次连接，连上后不再生效）；0 表示一直重试直到服务可用，适合常驻终端
page 当前 location.pathname 页面路径，仅用于页面级登录提示与日志

工程没有 Web/manifest.json 时返回的 Promise 以 PAGE_NOT_FOUND 拒绝。

断线后按 0.5 秒到 5 秒的退避间隔自动重连，重连后自动恢复订阅并取回快照。15 秒心跳，45 秒收不到任何消息视为半开连接并主动重连。

客户端 API

状态

成员 说明
state connecting / open / reconnecting / closed
runtime 通讯运行状态 { state: running/starting/stopping/stopped, mode: online/offline }
app { title, entry }
page 当前页面 { path, title, icon, viewRole, registered }
pages 登记页面列表，路径为根相对地址，可直接生成导航
auth { viewRole, writeRole, hostLinked }
user 当前用户 { name, role }，未登录为 null
variables 可用变量：{ 别名: { access, type, readable, writable, readRole, writeRole, structure, field, description } }
unavailable 已声明但不可用的变量：{ 别名: 原因 }

变量

方法 说明
subscribe(aliases \| "*", callback) 订阅变量，返回 Promise<subscription>。回调 (values, changes) 先以当前值调用一次，之后每次变化调用；无读取权限的变量在登录或提权后自动补订
unsubscribe(subscription) 取消订阅，也可调用 subscription.unsubscribe()
get(alias) / get(prefix, field) 读取已订阅变量的当前值；超出 ±(2^53−1) 的 64 位整数以十进制字符串给出（需要精确运算时用 BigInt(value)），写入时也可传字符串
getStructure(prefix) 读取以 prefix. 开头的全部已订阅变量，返回 { 字段: 值 }
write(alias, value) / write(prefix, field, value) 写入单个变量，返回 Promise<{ success: true }>，失败以 DynamicViewsError 拒绝
writeField(prefix, field, value) 同 write(prefix, field, value)
writeMany({ 别名: 值 }) 一次写入多个变量，同一结构体的字段在服务端合并为一次写入；不同结构体逐个写入、不回滚，失败时 error.written 列出已写入的别名
writeStructure(prefix, { 字段: 值 }) 以 prefix.字段 为别名调用 writeMany
resync() 取回完整快照

后端查询

成员 说明
queries 清单声明的查询：{ 别名: { description, readRole, rowLimit, available, unavailable, parameters: { 名称: { type, required, default, description } } } }
query(alias, parameters?, { timeout? }) 执行清单 queries 里声明的查询，返回 Promise<QueryResult>；失败时 reject DynamicViewsError。Date 参数按声明的类型格式化（date → 本地 yyyy-MM-dd，其余 → ISO 8601）；参数的转换与校验在服务端按声明进行。默认最多等待 70 秒
canQuery(alias) 前端提示用：已声明、可用且当前用户角色满足；最终以服务端判定为准

QueryResult 包含 query、columns、rows、rowCount、truncated（被 rowLimit 截断）、elapsedMs，以及三个便利成员：

  • records：每行一个 { 列名: 值 } 对象，首次访问时生成并缓存
  • column(name)：取一列的全部值，可直接交给图表；列不存在时抛 BAD_REQUEST
  • scalar()：第一行第一列（如 COUNT(*)），没有数据时为 undefined

超过 ±(2^53−1) 的 64 位整数以十进制字符串返回；日期时间列以 yyyy-MM-dd HH:mm:ss（服务器本地时间）字符串返回；二进制列为 null。查询是一次性的请求，没有实时推送，需要刷新时重新调用。

const dv = await DynamicViews.connect();
const result = await dv.query("alarmHistory", { from: new Date(Date.now() - 86400000), level: 2 });
chart.setOption({ xAxis: { data: result.column("time") }, series: [{ type: "bar", data: result.column("count") }] });
if (result.truncated) note.textContent = "结果已达上限，请缩小时间范围";

订阅后的第一次回调总是带上本订阅当前可读的全部值（即使部分别名已被声明式绑定等其他订阅取到），之后只带变化的部分。回调中的 values 是本订阅的只读视图（不是 Map），提供 get(alias)、has(alias)，以及只列出已收到值的别名的 keys()、size、entries()、forEach((value, alias) => …)、toObject()；changes 为 [{ variable, value, previous, source }]，variable 即别名，previous 为本客户端此前持有的值（首次为 undefined），source 取值 snapshot、communication、local、binding、action。

写入值只接受布尔、数字与字符串，服务端按字段类型转换，无法转换时返回 TYPE_MISMATCH。

账号

账号与角色来自 DataMaster 宿主。在 DataMaster 内打开的窗口中，登录与登出直接作用于宿主。

方法 说明
login(username, password) 登录，返回 Promise<user>；失败为 LOGIN_FAILED、LOGIN_LOCKED 或 AUTH_UNAVAILABLE
logout() 登出
showLogin({ title?, required? }) 显示内置登录框，返回登录后的用户，取消返回 null
hasRole(role) 当前用户是否具备角色
canRead(alias) / canWrite(alias) 当前用户能否读 / 写某个变量，仅用于界面提示，最终以服务端判定为准
onUserChanged(callback) 用户变化回调 (user, reason)，reason 取值 welcome、login、logout、host、roleChanged、expired

事件与其他

方法 说明
onConnectionStateChanged(callback) 连接状态变化，返回取消函数
onRuntimeChanged(callback) 通讯运行状态变化，返回取消函数
bind(root) 扫描动态创建的 DOM 中的声明式绑定，返回 { unbind() }
close() 永久断开
diagnostics() 诊断信息，供 Agent 的页面验证工具读取；bindingErrors 列出声明式绑定的写法错误（按钮缺少 data-dv-write-value、写入未声明的变量、! 用错位置、被拒绝的 data-dv-attr 等），不为空时验证不通过

静态方法

方法 说明
DynamicViews.hasRole(userRole, requiredRole) 角色比较，规则与宿主一致
DynamicViews.roles / DynamicViews.roleNames 角色级别与中文名称
DynamicViews.loadIcons(names) 按需加载图标，返回 Promise
DynamicViews.icon(name, { size, strokeWidth, className }) 返回图标 SVG 字符串（需已加载）
DynamicViews.renderIcons(root?) 渲染 [data-dv-icon]，无需连接
DynamicViews.current() 最近一次 connect() 创建的客户端（无则为 null），供验证探针复用页面自己的连接
DynamicViews.diagnostics() 最近一次连接的诊断信息（subscribed 为别名数组，subscribedCount 为数量；unknownAliases 为清单未声明的别名，accessDeniedAliases 为访问方式不允许的别名；loginPrompt 为内置登录框弹出次数与是否仍打开）

声明式绑定

connect() 默认自动扫描 document.body；之后动态创建的 DOM 调用 dv.bind(element)。声明式绑定只是 SDK 的辅助能力，复杂交互直接使用 API。

属性 效果
data-dv-text="alias" 显示文本；可配合 data-dv-digits="1"、data-dv-unit="rpm"、data-dv-map='{"true":"运行","false":"停止"}'、data-dv-placeholder
data-dv-value="alias" + data-dv-mode="two-way" 输入框 / 下拉框的值，change 时写入；输入框获得焦点时不被推送覆盖
data-dv-checked="alias" + data-dv-mode="two-way" 复选框
data-dv-class="on:alias alarm:!alias" 按真值切换样式类，! 取反
data-dv-show="alias" / "!alias" 显示 / 隐藏（同时写内联 display，不会被页面 CSS 覆盖）

! 取反只用于 data-dv-show 与 data-dv-class；data-dv-text / value / checked / write 只接受单个别名，写成 !alias 会在控制台报错且不绑定。 | data-dv-attr="value:alias" | 设置属性，适用于 <meter>、<progress> 等；事件属性（on*）、srcdoc，以及 href/src 等 URL 属性上的 javascript:/vbscript:/data: 值会被拒绝 | | data-dv-style="--speed:alias" | 设置 CSS 自定义属性，可驱动动画 | | data-dv-write="alias" + data-dv-write-value="true" | 点击写入固定值（按 JSON 解析，data-dv-write-value 必填）；data-dv-confirm="确认？" 先弹确认 | | data-dv-role="operator" | 角色不足时禁用；data-dv-role-mode="hide" 改为隐藏 | | data-dv-login / data-dv-logout | 登录按钮（未登录时显示）/ 退出按钮（已登录时显示） | | data-dv-user | 显示当前用户与角色 | | data-dv-icon="gauge" | Lucide 图标，按需加载 |

SDK 在写入过程中给元素加 dv-pending 类，写入失败加 dv-error 类并回到服务端的值；写入返回 LOGIN_REQUIRED 时自动弹出登录框。

<body> 上的状态类：

类名 含义
dv-connected / dv-disconnected 与变量网关的连接状态
dv-runtime-running / dv-runtime-stopped 通讯运行状态
dv-logged-in / dv-logged-out 登录状态
dv-role-{role} 当前用户角色

错误码

DynamicViewsError 包含 code、message、variables（失败涉及的别名）与 written（跨结构体 writeMany 部分失败时，已经写入成功的别名；其余情况为空数组）。

错误码 说明
NOT_DECLARED 变量未在清单中声明
NOT_READABLE / NOT_WRITABLE 清单未声明读取 / 写入
VARIABLE_UNAVAILABLE 已声明但当前不可用（结构体或字段不存在、停用、类型不符）
LOGIN_REQUIRED 需要登录
FORBIDDEN 已登录但角色不足
LOGIN_FAILED / LOGIN_LOCKED 用户名或密码错误 / 失败次数过多暂时锁定
AUTH_UNAVAILABLE 账号服务暂不可用（如宿主数据库无法访问），不计入失败次数，稍后重试
TYPE_MISMATCH 写入值与字段类型不匹配
READ_ONLY、STRUCTURE_NOT_FOUND、STRUCTURE_DISABLED、FIELD_NOT_FOUND、NO_WRITABLE_CHANNEL、DEVICE_WRITE_FAILED 来自变量写入服务
BUSY 单个连接同时进行的写入过多（上限 32）或查询过多（上限 4）
QUERY_UNAVAILABLE 查询已声明但不可用：数据源不存在、SQL 文件缺失、SQL 不是只读语句或用了未声明的参数
QUERY_FAILED / QUERY_TIMEOUT 数据库执行失败（消息已脱敏） / 超过数据源的查询超时时间
RESULT_TOO_LARGE 查询结果超过单条消息的大小上限（约 8 MB），请缩小范围或在 SQL 里先聚合
BAD_REQUEST 请求格式错误；对查询来说是缺少必填参数、传了未声明的参数、参数值无法按声明类型转换
TIMEOUT / DISCONNECTED 请求超时 / 连接已断开（客户端产生）
PAGE_NOT_FOUND / PROTOCOL_ERROR 没有 Web 工程 / 握手协议错误
INTERNAL_ERROR 服务端内部错误
TOO_MANY_CONNECTIONS 连接数超过上限（关闭码 4029），SDK 按退避间隔自动重连

传输协议

SDK 已完整实现协议，页面不应自行连接。本节供排查问题与扩展客户端时参考。

WebSocket 地址：ws://主机:端口/ws/dynamic-views，每条消息为一个 JSON 文本帧，带 type 字段。

客户端 → 服务端

type 字段 说明
hello page、token?、hostToken?、protocol 连接后第一条消息，10 秒内必须发送
subscribe requestId、variables（别名数组或 "*"） 订阅
unsubscribe requestId、variables 取消订阅
write requestId、values（{ 别名: 值 }） 写入
query requestId、query（查询别名）、parameters?（{ 名称: 值 }） 执行清单声明的查询；不占用写入的串行队列
login requestId、username、password 登录
logout requestId 登出
resync requestId? 取回完整快照
ping — 心跳

服务端 → 客户端

type 字段 说明
welcome sessionId、app、page、pages、auth、user、variables、queries、unavailable、runtime 握手结果
subscribed requestId、variables、rejected（别名 → 错误码） 订阅结果，随后发送快照
snapshot requestId?、sequence、values 已订阅变量的完整快照
patch sequence、changes 增量
writeResult requestId、success、code?、message?、variables?、written? 写入回执；written 为失败前已写入的别名
queryResult requestId、query、success、columns?、rows?、rowCount?、truncated?、elapsedMs?、code?、message? 查询回执；rows 每行与 columns 一一对应
loginResult requestId、success、token?、user?、code?、message? 登录回执；宿主联动会话不返回令牌
logoutResult requestId、success 登出回执
auth reason、user、hostLinked、revoked 身份变化；revoked 为因权限不足被撤销的订阅
runtime runtime 通讯运行状态变化
pong / error — / requestId?、code、message 心跳 / 请求错误

登录成功时服务端先发 loginResult 再发 auth；写入前刷新身份若发现变化，auth 先于 writeResult 到达。

示例：

{ "type": "snapshot", "sequence": 100, "values": { "motor.speed": 850, "motor.running": true } }
{ "type": "patch", "sequence": 101, "changes": [ { "variable": "motor.speed", "value": 860, "source": "communication" } ] }
{ "type": "write", "requestId": "r5", "values": { "motor.target": 1200 } }
{ "type": "writeResult", "requestId": "r5", "success": false, "code": "FORBIDDEN", "message": "…", "variables": ["motor.target"] }
