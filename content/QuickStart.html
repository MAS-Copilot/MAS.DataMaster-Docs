快速开始

本文介绍如何在一台全新的 Windows 电脑上安装并启动 DataMaster，按顺序完成以下步骤即可

Note

适用于 Windows 10 / 11，64 位系统选 x64 安装程序，32 位系统选 x86 安装程序。安装 DataMaster、运行时、数据库和配置系统环境变量需要管理员权限

  1. 下载安装程序

    从 GitHub Release 下载对应版本的安装程序，每个版本提供两种：

    安装程序 大小 适用场景
    MasDataMaster-Setup-win-x64-self-contained-<版本>.exe 较大 推荐。自带 .NET 运行时，下载后直接安装，可跳过第 2 步
    MasDataMaster-Setup-win-x64-<版本>.exe 较小 电脑已安装或准备安装 .NET 8 运行时，需完成第 2 步
    Tip

    不确定选哪个时选自包含版（文件名带 self-contained）

  2. 安装运行时环境

    Note

    使用自包含版安装程序时跳过本步骤

    DataMaster 基于 .NET 8 构建，框架依赖版需要先安装以下两个运行时：

    运行时 安装包 下载
    ASP.NET Core Runtime 8.0 aspnetcore-runtime-8.0.29-win-x64.exe 下载
    .NET Desktop Runtime 8.0 windowsdesktop-runtime-8.0.29-win-x64.exe 下载

    双击安装包按提示完成安装。安装完成后可在命令行中验证：

    dotnet --list-runtimes

    输出中包含 Microsoft.AspNetCore.App 8.0.x 与 Microsoft.WindowsDesktop.App 8.0.x 即表示安装成功

    Tip

    8.0 系列中更新的补丁版本同样可用，所有版本见 .NET 8.0 下载页。x86 安装程序需要对应的 x86 运行时

  3. 安装数据库

    DataMaster 使用 MySQL 存储数据，安装包为 mysql-8.4.11-winx64.msi，从 MySQL 官方下载页 选择 8.4 LTS 版本的 Windows 安装程序（MSI）下载

    按安装向导完成安装，过程中需要注意：

    • 端口保持默认的 3306
    • 牢记为 root 用户设置的密码，下一步配置环境变量时要用到
    Warning

    如果安装时提示缺少 Microsoft Visual C++ Redistributable x64，先下载安装 vc_redist.x64.exe，再重新运行 MySQL 安装包

    更多数据库相关说明见 如何使用

  4. 配置环境变量

    DataMaster 从环境变量 DB_PASSWORD 读取数据库密码，需要新建该变量：

    变量名 变量值
    DB_PASSWORD 上一步设置的数据库密码

    在 控制面板 → 系统 → 高级系统设置 → 环境变量 中新建变量，或在命令行中执行：

    setx DB_PASSWORD "数据库密码"

    新开一个 PowerShell 窗口验证，输出设置的密码即表示成功：

    echo $env:DB_PASSWORD
    Important

    变量名为 DB_PASSWORD，注意前后不要带空格。环境变量只对设置之后新启动的程序生效，设置完成后请重新打开命令行窗口或 DataMaster

  5. 安装并启动

    双击下载的安装程序，在弹出的用户账户控制窗口中点击 是，然后选择安装方式：

    安装方式 说明
    快速安装 安装到 C:\Program Files\MAS.DataMaster-win-x64，一键完成
    自定义安装 选择安装的磁盘与文件夹，所选文件夹不是 MAS.DataMaster-win-x64 时会自动在其下新建该文件夹

    安装完成后，完成页默认勾选 创建桌面快捷方式 和 立即启动，点击 完成 即启动 DataMaster

    Note

    安装只是把程序文件解压到安装目录。工程、配置等现场数据保存在初始化向导设置的全局存储路径下（<所选位置>\MAS.DataMaster），与安装目录相互独立，重新安装或升级不会丢失

  6. 初始化并登录

    首次启动会进入初始化向导，依次完成数据库设置、数据库初始化、创建管理员账号与设置全局存储路径，之后登录到系统即可开始使用

升级与卸载

  • 升级：DataMaster 支持在线更新，也可以下载新版本安装程序，安装到原来的目录覆盖安装。覆盖前请先关闭 DataMaster
  • 卸载：关闭 DataMaster 后删除安装目录与桌面快捷方式即可。现场数据位于全局存储路径，不随安装目录删除，确认不再需要后再手动删除

常见问题

双击安装程序或 DataMaster 时提示缺少 .NET 运行时

使用的是框架依赖版，检查第 2 步的两个运行时是否都已安装，可通过 dotnet --list-runtimes 确认；或改用自包含版安装程序

Windows 提示"Windows 已保护你的电脑"

点击 更多信息 → 仍要运行 即可继续安装

安装时提示"以下程序正在运行，请关闭后重试"

覆盖安装前需关闭安装目录中正在运行的 DataMaster，关闭后在安装程序中重新安装

自定义安装时提示"该目录不为空且不是已有的安装目录"

为避免程序文件混入其他文件，安装程序只接受空文件夹或已有的安装目录，请选择或新建一个空文件夹

无法连接数据库

  • 确认 MySQL 服务已启动，可在 服务（services.msc）中查看 MySQL84 服务状态
  • 确认 DB_PASSWORD 与 MySQL root 密码一致，且设置后已重新启动 DataMaster
