轨迹前瞻

轨迹前瞻负责规划每一段的速度。它根据加减速能力，为每一段算出指令速度，并算出段与段之间以多快的速度衔接。前瞻只改写轨迹点的速度字段，不改变几何。

在生成流程中的位置

轨迹生成共 7 个阶段，前瞻是第 6 个：

  • 组过滤
  • 几何提取
  • 几何清洗（参见 GeometryCleaning）
  • 路径排序与优化（参见 OptimizationPath）
  • 姿态生成（参见 CalculatingPose）
  • 速度规划（轨迹前瞻，本文档）
  • 结果组装

放在姿态生成之后，原因有两个：

  • 排序完成后才知道哪些段相邻、拐角在哪；安全转移点和回原点点也是排序阶段才插入的，它们同样要规划速度
  • 前瞻不改几何，放在后面不会被其他阶段打乱

前瞻与插补的分工

前瞻是段级的速度规划，插补是控制周期级的位置计算，两者分开：

  • 上位机负责前瞻：算出每段的指令速度、段末衔接速度和预计耗时
  • 下位机负责插补：按控制周期执行直线、圆弧等运动

圆弧仍以“起点 → 中间点 → 终点”三点表达，不需要上位机拆点。前瞻会用三点求出半径与切向，据此确定圆弧限速和与前后段的衔接速度。

  • 启用轨迹前瞻：关闭时轨迹点保持固定速度，与旧版本一致。旧配方读入后默认关闭
  • 前瞻段数：规划每个点时只向后看这么多段，并假定窗口末尾必须停住。0 表示看完整条轨迹，得到全局最优解；设成控制器实际的前瞻深度，可以让规划结果与设备行为一致
  • 加工 / 空移 / 下降速度：按运动阶段选用。初始定位、抬升、空移、回原点使用空移速度
  • 最大速度：所有速度的上限，校验时要求各阶段速度不超过它
  • 轨迹终点速度：整条轨迹最后一个点的速度，必须在 0 到加工目标速度之间
  • 最大加速度：同时作为圆弧与拐角的向心加速度上限
  • 最大加加速度：0 表示按梯形加减速规划，大于 0 时按 S 型加减速规划
  • 拐角容差：允许实际轨迹偏离理想拐角的距离，容差越大过弯越快。如果控制器每个点都精确到位，它只用于计算拐角速度
  • 最小拐角速度：仅对转角小于停止角度的拐角生效。前后段太短、来不及减速时仍会低于该值
  • 拐角停止角度：运动方向的转角达到该值时在拐角处停止。0° 为直行，180° 为原路折返

规划步骤

1. 指令速度

每一段的指令速度取以下各项的最小值：

  • 阶段速度：按段终点的描述选取加工、空移或下降速度
  • 最大速度
  • 圆弧向心限速 \(\sqrt{a \cdot R}\)：仅对三点圆弧生效

手动修改或新增的加工点沿用它自己的速度，便于对个别段单独限速。

2. 拐角速度上限

每个点的通过速度上限按以下规则确定：

  • 进出安全转移、点定位：必须停止
  • 转角达到停止角度：必须停止
  • 切向连续（直线接相切圆弧、圆弧中间点）：不限速
  • 其余拐角：取拐角容差模型与离散曲率限速中较小的一个，再用最小拐角速度兜底

拐角容差模型设想拐角处有一段与两条边相切、离拐点不超过容差 \(\delta\) 的过渡圆弧，以最大加速度作向心加速度时能保持的速度为：

\[ v^2 = \frac{a \cdot \delta \cdot s}{1 - s}, \quad s = \cos\frac{\theta}{2} \]

其中 \(\theta\) 是运动方向的转角。

样条、椭圆被离散成很短的直线，单看拐角容差会高估过弯速度。因此还会用相邻三点的外接圆半径 \(R\) 补一道 \(\sqrt{a \cdot R}\) 约束；真正的折角处外接圆很大，这道约束不起作用。

3. 反向扫描与正向扫描

  • 反向扫描：从终点往回，保证按最大减速度来得及降到后面每个点的速度
  • 前瞻窗口：前瞻段数大于 0 时，每个点还要能在窗口长度内停住
  • 正向扫描：从起点往前，保证按最大加速度能从前一个点的速度加上来

S 型剖面假定段与段衔接处加速度为 0，比控制器实际能做到的略保守，但保证规划出的速度一定跑得出来。

输出

规划结果写入每个轨迹点：

  • Velocity：到达该点这一段的指令速度
  • EndVelocity：到达该点时的规划速度，即上一段的段末速度、下一段的起始速度

生成记录中各轨迹段的耗时会改为按规划结果累加，已计入加减速与拐角降速。

Note

速度目前只用于分析和耗时估算，尚未写入下发给设备的点位缓冲。

改点后的重新规划

在界面上或通过 Agent 修改、插入、删除点位后，会按当前前瞻参数重新规划整条轨迹的速度，使衔接速度与新的几何对齐。

分析与诊断

启用前瞻后，分析页的耗时估算会按点上记录的指令速度与衔接速度重算加减速剖面。

诊断码 级别 含义
TRJ017 警告 速度与参数不一致
TRJ018 提示 加工拐角被规划为停止
  • TRJ017：轨迹可能是在启用前瞻或修改参数之前生成的，重新生成即可消除
  • TRJ018：转角达到停止角度，或前后段太短来不及减速。如需连续通过，可调大拐角停止角度或拐角容差

3D 仿真回放

轨迹动画窗口按 TrajectoryTimeline 回放：段划分、段耗时与分析页的剖面耗时同一口径，因此仿真总时长就是预计加工时长。

  • 前瞻启用时，段内按“加速 → 匀速 → 减速”展开（梯形或 S 型），拐角处可以看到降速
  • 前瞻未启用时，每段按点上的 Velocity 匀速
  • 工具姿态取首末点 Rx / Ry / Rz（ZYX 欧拉角）按路程比例球面插值
  • 已走过的轨迹按速度着色（慢蓝 → 快红，色带上限取加工段最高速度），空移段固定紫色

相机模式：

  • 自由：完全手动
  • 跟随：注视点锁定工具，仍可旋转、缩放
  • 追随：位于工具运动方向后上方
  • 俯视：工具正上方垂直向下

正常播放到终点才算完成仿真；拖动进度条到终点不算。

已知限制

  • 只约束平移速度，不约束姿态角（Rx / Ry / Rz）的角速度
  • 圆弧按 XY 平面解算，与 3D 预览口径一致
