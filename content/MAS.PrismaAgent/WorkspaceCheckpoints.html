本轮改动与撤销

每轮结束后，助手回复下方显示一张"本轮改动"卡片，列出本轮对工程做了哪些改动（新增、删除、修改，各自的路径和前后值），并支持撤销本轮、撤销到某轮之前和重做。宿主重启后仍能查看明细，也仍能撤销。

核心原则

  • 基于状态，不基于操作：只比较本轮开始前和结束后的两份状态，不关心中间调了哪些工具、怎么改的。
  • 模块只提供两件事：导出状态（JSON）、从状态恢复。存储、比对、展示、撤销全部是通用代码。
  • 工程明文不出加密边界：快照对象一律加密写盘；会话日志和发给模型的内容只包含路径，不包含值。
  • 撤销靠恢复整份快照：变更列表只用于展示和日志，换展示格式或比对算法都不影响快照和恢复。

架构

位置 组成
MAS.SharedLibrary/Workspace 参与者接口、两个基类、结构比对、对象库
MAS.DataMaster/NamedPipeIpc/Workspace 检查点服务与 checkpoint.* IPC
MAS.PrismaAgent/Workspace IPC 契约、客户端、快照范围解析、撤销通知
HTML/js/workspace-changes.js 改动卡片

存储与比对放在宿主：明文只存在于宿主进程，加密服务也在宿主，Agent 只拿到结构和打码后的值。宿主不可用时 Agent 侧所有功能静默关闭，对话不受影响。

拍快照的时机

  • 执行管线在审批通过之后、工具真正执行之前调用 checkpoint.ensure，每个模块每轮只拍一次。
  • 声明了 MutatesModules 的工具按模块拍；cli.write_file、cli.edit_file、cli.copy_file 按目标路径拍，路径到模块的映射在宿主里做。
  • cli.run、script.csharp、script.python 给所有目录类模块各拍一次，并在卡片上提示"脚本对内存模型的改动可能没有被记录"。
  • 被拒绝或校验失败的调用不触发；拍快照失败不阻断工具，卡片显示"快照失败"，该模块本轮不能撤销。
  • 声明了 device 的工具每次调用都计数，提示"另有 N 次设备写入，不可撤销"。
  • 脚本、设备写入、工程外文件这类快照覆盖不到的提醒收在卡片标题栏的提示图标里，悬停查看。

存储

会话目录在宿主数据目录下：<BasePath>/PrismaAgent/checkpoints/<sessionId>/，路径由宿主按会话标识自行计算，不从 IPC 接收。

文件 内容
objects/<sha256>.bin gzip 后加密的快照对象
turns/<turnId>.json 每轮清单，只有哈希和元数据
index.json 轮次顺序、撤销与重做记录
  • 引用是规范化 JSON（键排序、去空白）明文的 SHA-256；内容相同只存一份。
  • 目录参与者的文件内容、视觉流程的节点资产存成独立对象，状态 JSON 里只放 sha256:… 引用。
  • 保留上限默认 50 轮或 500 MB，超出时先清最早轮次的对象，被清的轮次只留结构，不能再撤销。删除会话时整个目录一并删除。

撤销与重做

  • 撤销从指定轮开始的全部未撤销轮次：每个模块恢复到最早一轮写入前的状态。
  • 当前状态与最近一轮结束时不一致（手动或其他会话改过）时提示冲突，列出不一致的路径，用户可以强制执行。
  • 当前打开的工程与快照所属工程不同时禁止执行。
  • 模块的写前守卫不通过时返回原因；多个模块中有一个恢复失败时，已恢复的模块回滚。
  • 撤销本身也是一条记录，只能重做最近一次尚未重做的撤销。
  • 内存模型恢复后标记为未保存，不自动存盘；目录类模块直接写盘。
  • 撤销、重做成功后往会话历史追加 [WORKSPACE_REVERTED] / [WORKSPACE_REDONE] 系统消息（只有模块、处数和路径），并随推理上下文检查点保存，重启后下一轮模型仍能看到。

IPC 协议

方法 用途
checkpoint.begin 开始一轮
checkpoint.ensure 写入前拍快照
checkpoint.end 结束一轮，返回只含结构的摘要
checkpoint.changes 取某轮带值的完整变更
checkpoint.revert 撤销到某轮之前
checkpoint.redo 重做一次撤销
checkpoint.delete 删除会话的全部检查点
  • checkpoint.ensure：{ sessionId, turnId, modules?, paths?, allDirectories }。
  • checkpoint.end：摘要含各模块增删改计数、每模块最多 50 条可读路径、快照失败、截断、超限文件、脚本标记、工程外文件与设备写入次数。
  • checkpoint.changes：快照已清理时返回 valuesUnavailable=true，前端保留结构、值显示"值不可用"、不能再撤销。
  • 宿主没连上时回推 isHostUnavailable=true：只说明这次没取到，卡片仍可撤销，并提供重试。
  • checkpoint.revert / checkpoint.redo 返回 ok、conflict、projectMismatch、guardFailed、unavailable 之一；会话运行中由 Agent 侧直接返回 running。

前端

会话事件见 WebView 事件与审批：workspace.changes 在 turn.ended 之前写入，被取消或失败的轮次同样有卡片；workspace.reverted / workspace.redone 让卡片切换到已撤销或恢复正常。

  • 卡片渲染时只有结构；展开或首次进入可视区时发 loadWorkspaceChanges，宿主回推 fillWorkspaceChanges，值不写进日志。
  • 最新一轮显示"撤销本轮"，更早的轮次显示"撤销到此轮之前"，确认在卡片内完成并写明会一起回退的轮次数。
  • 撤销、重做发 revertWorkspace / redoWorkspace，结果经 applyWorkspaceActionResult 回推；冲突时卡片列出路径并提供"仍然撤销"。
  • 会话运行中所有撤销、重做按钮禁用。

扩展指南

新增一个模块

  1. 继承 JsonModelParticipant<T>（内存模型）或 DirectoryParticipant（磁盘目录），实现取模型和提交模型（或提供根目录）；在 CreateDiffOptions 里配置键字段、显示字段和忽略路径。需要存二进制内容时直接实现 IWorkspaceParticipant。
  2. 恢复必须复用模块现有的写前守卫，守卫不通过时返回失败原因，不能部分恢复；恢复后让界面刷新并把工程标记为未保存。
  3. 在 DI 中注册为 IWorkspaceParticipant。
  4. 给这个模块的写入类工具声明 MutatesModules。

新增一个工具：会改工程状态就声明 MutatesModules，不声明的改动不会被记录；会写设备就声明 device。

禁止事项

  • 不要按属性手写比对代码，统一走 JsonStructuralDiff。
  • 不要为某个模块写专门的卡片界面。
  • 不要把变更的值写进会话日志或发给模型。
  • 工具里不要直接调用参与者，拍快照只能由管线钩子触发。
  • 快照只能通过参与者的 CaptureAsync 获取，不要另写一套拷贝逻辑。

比对选项

选项 含义
KeyFields 数组元素对齐键，按序选第一个唯一且非空的
LabelFields 可读路径中显示的字段
IgnoredPaths 噪音路径
SensitivePaths 打码路径
TextThreshold 按行比对的长度阈值
DisplaySkipSegments 可读路径省略的外层段数
  • 路径规则以 / 分隔、不区分大小写，* 匹配一段，** 匹配任意多段。
  • 标了 [Sensitive] 的属性与名称形如口令、密钥的字段自动打码，值显示为 ***；快照本身仍保存完整值，否则无法恢复。
