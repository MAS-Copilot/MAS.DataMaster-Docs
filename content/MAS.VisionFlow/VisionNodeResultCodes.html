VisionFlow 节点结果码约定

结果结构与缓存

节点通过上下文报告结果，执行器统一更新执行状态、发布有效输出，并组装现有节点结果对象。管道汇总见管道结果码约定。

结果码及管道映射

编号 节点结果码 管道结果码 语义
0 Unknown Unknown 尚未执行、执行中或无法识别，不作为有效成功依据
1000 Success Success 正常完成；不影响业务有效性的警告和正常采样也属于此类
1001 ConditionNotSelected Success 条件未选中及其依赖跳过
2000 NoResult NoResult 无法进一步分类的必要业务结果缺失
2001 JudgementFailed JudgementFailed 有效数据未通过已配置的业务规则
2002 TargetNotFound NoResult 必要目标或匹配未找到
2003 InsufficientFeatures NoResult 有效点、角点等数量不足
2004 FitFailed NoResult 合法配置及输入下没有求得有效解
2005 GeometryUnavailable NoResult 本轮必要几何区域或交点不存在
3000 ConfigurationError Faulted 连线、参数、模型或标定等配置无效
3001 InputError Faulted 输入类型或上游输出违反契约
3002 DeviceError Faulted 设备不可用、停流或通信失败
3003 AcquisitionTimeout Faulted 未取得本轮图像，尚无明确断线证据
3004 ExecutionError Faulted 未分类的执行异常
4000 Cancelled Cancelled 主动中断，未形成完整业务结果

映射在 VisionResultCodeExtensions 中显式定义，不能强制转换。初始化不是单独的原因码：阶段由既有执行状态记录，例如初始化相机断线仍为 DeviceError，未知初始化异常为 ExecutionError。

报告方式

  • 正常算法结束且没有报告其他结果时，由执行器记录 Success。
  • context.ReportResult(code, message) 报告业务无结果或已知故障，并保留本轮有效输出。
  • context.ReportJudgementFailed(message, isDownstreamSkipped) 报告 NG，可阻止依赖下游；本节点测量数据仍保留。
  • context.Skip(message, code) 跳过本节点，默认表示条件未选中；业务跳过必须提供明确原因码。故障和取消不得伪装成跳过。
  • 未找到、特征不足、拟合无结果和业务 NG 不通过异常控制执行。SDK、配置边界和未预期异常仍有故障兜底，由执行器转换为结果码，不能吞掉后当作成功。

执行状态、依赖与有效数据

Status 表示是否执行、警告、跳过等，ResultCode 表示本轮业务原因。保留依据状态计算的 IsSkipped

  • 上游明确业务无结果且某个连接的输出没有产出时，需要该输入的下游跳过。原图和合法空列表等仍有效，不会被一并丢弃。
  • 已连接的可选跟随输入由节点按当前配置判断是否必要，例如尚未设置跟随基准时不能误当成正在跟随。
  • 因上游跳过的节点继承原始结果码及 SourceNodeId，不额外定义笼统的 Skipped 结果码。
  • Status=Skipped 表示没有完成本节点处理，可以是条件未选中、本节点自身几何不可用，或被上游原因阻断。业务含义读取 ResultCode；在本轮执行结果中，SourceNodeId 等于自身 NodeId 表示本节点产生原因，指向其他节点表示原因来自上游。追溯来源应使用本轮执行结果。
  • 未连接的必要输入或成功节点漏写必要输出属于故障，不自动当作正常未找到。
  • NG 的测量值仍可读取；无结果时数量、Found 等诊断项可以读取，不存在的坐标不可读取。
  • VisionResultValue.IsAvailable 标记单个数据项是否有效，TryGetValue、GetValue 和 Web 发布均遵守它。故障、跳过和取消不提供旧测量值，失败或未到达节点撤下旧输出。

脚本读取

本轮回调使用传入的管道结果：

var code = result.GetNodeResultCode("定位");
if (code == VisionNodeResultCode.Success
    && result.TryGetValue<double>("定位", "X", out var x)) {
    // 使用本轮有效坐标。
}

外部查询最近的结果码可以使用 _vision.GetNodeResultCode("定位")，该方法只读基类枚举字段，不生成数据字典或读取图像。它表示最近状态，不能替代脚本回调中所属轮次的结果。

分类边界与扩展

  • 定位、模板匹配未找到必要目标：TargetNotFound；缺陷检测得到空列表可以正常成功。
  • 几何拟合所需特征不足：InsufficientFeatures；合法列表数量不符合产品规则：JudgementFailed。
  • 随动 ROI 移出图像、确实需要交点但两线平行：GeometryUnavailable；静态 ROI 配置无效：ConfigurationError。只需要夹角的分支不因没有交点而失败。
  • 示教基准尚未取得时可以报告 NoResult，保留必要的示教输入；缺少运行必需模型或标定资源属于配置故障。
  • NoResult、ExecutionError 仅作为各自类别的兜底。新增码时必须同步定义输出有效性、管道映射和运行处置，不能仅增加枚举成员。
