VisionFlow 模块状态

VisionFlow 的模块状态与视觉结果通道分开提供。模块状态用于显示工程是否加载、管道启停、正在执行、最近结果和运行故障，不要求管道内存在 Web 发布节点。

创建与更新

在组态数据中心选择「新建 → 从模块创建 → VisionFlow 视觉流程」，生成只读结构体 VisionFlow_Status，以及管道明细使用的子结构体 VisionFlow_Status_VisionPipelineStatusEntry。

  • 字段从 VisionFlowStatusSnapshot、VisionPipelineStatusEntry 的公开属性生成，说明来自 [Description]，字符串长度来自 [MaxLength]，与 DXF 模块相同。
  • VisionFlowStatusReporter 使用单个后台循环合并事件请求，首次立即发布，事件更新最多每 200 毫秒一次，另外每秒补发当前状态。发布异常记录日志并重试，不影响视觉执行。
  • 发布内容是当前状态快照，不是状态变更日志。短于刷新间隔的单次执行可能不会显示中间忙碌态，完成后通过执行次数、最近结果与故障历史观察。
  • 宿主 VisionFlowStatusBridge 随应用启动，负责调用 IDynamicViewStatusPublisher；不依赖视觉页面打开、管道脚本或组态通讯启动。
  • 未加载组态工程、未创建模块结构体或结构体已停用时不写入。后创建、重新启用或切换组态工程后，周期补发会恢复当前状态。
  • 视觉工程重新加载后，执行统计、故障历史和结果全部重置；管道改名保持稳定标识。脱离图的管道不在列表内。
  • 状态不保存到工程文件、不参与 PLC 通讯、不允许 Web 或组态控件写回。应用升级时沿用模块结构体的新增字段同步机制，已有字段名和类型应保持兼容。

模块汇总

字段 含义
IsProjectLoaded 是否已加载视觉工程；没有管道的空工程也可以是已加载
HasLoadErrors / LoadError 未知节点、失效连线等工程加载错误
PipelineCount 当前有效管道数量
StartingCount / RunningCount / StoppingCount 连续运行生命周期的管道数量；Running 包含等待触发信号
ExecutingCount 正在初始化或执行节点的管道数量，包含单次执行和运行到节点
IsBusy 有管道在启停、连续运行或执行节点
FaultedCount 存在运行故障的管道数量，业务 NG 不计入
IsFaulted 存在工程加载错误或管道运行故障
LastFault / LastFaultAt 当前管道中最近一次运行故障及时间，恢复后保留；加载错误见 LoadError
Heartbeat / UpdatedAt 发布心跳与快照生成时间（服务器本地时间）
Pipelines 管道状态记录列表，按 Id 识别，不能依赖列表下标

普通组态控件可直接绑定上述标量汇总字段，例如用 IsBusy、IsFaulted 显示状态灯。管道列表可由 Web 和脚本读取；当前组态字段选择器不支持直接绑定列表内部成员，本次未扩展此类绑定。

管道明细

每条记录包含：Id、Name、State、IsExecuting、IsInitialized、IsFaulted、LastFault、LastFaultAt、HasResult、LastResultCode、LastError、LastElapsedMilliseconds、RunCount、LastRunAt。

State 仅表示连续运行生命周期：0=Stopped、1=Starting、2=Running、3=Stopping。单次执行时可以同时是 Stopped 和 IsExecuting=true；等待触发信号时可以是 Running 和 IsExecuting=false。

LastResultCode 使用 VisionFlow 汇总结果码：正常完成、无结果、业务 NG、运行故障、主动取消分别为 1000、2000、2001、3000、4000。正常完成不等于工件合格；无结果和 NG 不计为运行故障。

HasResult、结果码、次数、耗时和执行时间只统计完整管道执行。初始化失败的单次执行也产生故障结果和完成通知；「运行到节点」不覆盖完整执行结果、不增加次数，但运行故障仍上报。

启动初始化、触发信号、结果处理与完成回调的异常也会形成运行故障。故障标志在重新启动或下一次完整执行正常完成（包括业务 NG、无结果）后清除，最近故障说明与时间保留到工程重载。正常停止不会被当作新的故障。

RunCount 为十进制字符串，保留原始 Int64 计数精度；动态视图目前没有 Int64 标量字段。Web 需要精确运算时使用 BigInt(entry.RunCount)。耗时为 Double 毫秒；未执行时耗时为零、时间为空，应结合 HasResult 判断。状态读取原始统计，不受工作台 UI 刷新节流影响。

Web 使用

在 Web/manifest.json 的 variables 中声明变量，structureId 填创建出的主结构体标识。以下片段中的 实际结构体标识 需要替换：

"variables": {
  "vision.busy": {
    "structureId": "实际结构体标识",
    "fieldId": "IsBusy",
    "type": "bool",
    "access": "read"
  },
  "vision.pipelines": {
    "structureId": "实际结构体标识",
    "fieldId": "Pipelines",
    "type": "structure",
    "access": "read"
  }
}

const dv = await DynamicViews.connect();
await dv.subscribe(["vision.busy", "vision.pipelines"], values => {
    const busy = values.get("vision.busy");
    const pipelines = values.get("vision.pipelines") ?? [];
    const target = pipelines.find(p => p.Id === pipelineId);
    renderStatus(busy, target);
});

记录成员沿用快照字段的 PascalCase 名称。组态变量订阅与 subscribeVision() 的结果帧、图像订阅互不依赖；dv.runtime 仍表示组态通讯运行时，不表示视觉运行状态。页面应结合 SDK 连接状态与心跳判断状态是否仍在更新，不能把断线前缓存的值当成当前状态。
